# 개선 (15) — 실물 등록 화면 문구 수정 + 다음 등록번호 자동 입력

> 목표: ① "(최근 등록: 6)" 문구를 "(최근 등록된 번호 : 6)"으로 바꿉니다.
> ② 실물 등록 화면에 처음 들어오면, 등록번호 칸에 가장 최근 등록번호의
> 다음 번호가 미리 채워지게 만듭니다. (직접 수정도 가능해요.)
> 소요 시간: 약 12분

---

## 왜 조금 복잡한 수정이 필요한가요?

이 화면은 자료 정보를 불러오는 작업과, 최근 등록번호를 불러오는 작업이
**동시에(따로따로)** 진행돼요. 둘 중 어느 게 먼저 끝날지는 매번 달라질 수
있어서, 그냥 "등록번호 칸에 다음 번호를 넣어라"라고만 하면 어떤 때는
나중에 끝난 작업이 먼저 채운 값을 덮어써서 사라지는 문제가 생길 수 있어요.
그래서 두 작업이 어떤 순서로 끝나든 항상 올바른 값이 남도록 코드를 짰어요.

### 1. 다음 번호를 계산하는 도구 함수 추가

아래 부분을 찾으세요. (파일 위쪽, 컴포넌트 함수 시작 전 어딘가에 있는
다른 도구 함수들 근처가 좋아요. `EMPTY_FORM` 선언 아래쪽을 추천해요.)

```tsx
const EMPTY_FORM = {
  registrationNo: "",
```

이 줄이 포함된 `EMPTY_FORM = { ... };` 블록이 끝나는 곳(`};`) 바로 아래에
함수를 하나 추가하세요.

```tsx
// 가장 최근 등록번호의 다음 숫자를 계산합니다. (등록번호는 1,2,3... 순수 숫자입니다.)
function computeNextRegNo(latest: string | null): string {
  if (!latest) return "1";
  const n = parseInt(latest, 10);
  if (Number.isNaN(n)) return "";
  return String(n + 1);
}
```

### 3. 최근 등록번호를 불러오면서 다음 번호도 같이 채우기

아래 부분을 찾으세요.

```tsx
  async function loadLatestRegNo() {
    const token = localStorage.getItem("token");
    if (!token) return;
    const res = await fetch(`${API_URL}/copies/latest`, {
      headers: { Authorization: `Bearer ${token}` },
    });
    if (res.ok) {
      const data = await res.json();
      setLatestRegNo(data.registrationNo);
    }
  }
```

이렇게 바꿔주세요.

```tsx
  async function loadLatestRegNo() {
    const token = localStorage.getItem("token");
    if (!token) return;
    const res = await fetch(`${API_URL}/copies/latest`, {
      headers: { Authorization: `Bearer ${token}` },
    });
    if (res.ok) {
      const data = await res.json();
      setLatestRegNo(data.registrationNo);
      setForm((prev) => ({ ...prev, registrationNo: computeNextRegNo(data.registrationNo) }));
    }
  }
```

## 확인하기 — 약 5분

1. 실물 등록 화면에 처음 들어가면 "(최근 등록된 번호 : 6)"처럼 띄어쓰기가
   포함된 문구로 나오는지 확인합니다.
2. 등록번호 입력칸에 최근 등록번호보다 1 큰 숫자(예: 최근이 6이면 7)가
   자동으로 채워져 있는지 확인합니다.
3. 자동으로 채워진 번호를 직접 지우고 다른 값을 넣을 수도 있는지
   확인합니다.
4. 실물을 하나 등록한 뒤, 폼이 비워지면서 등록번호 칸에 그 다음 번호가
   다시 자동으로 채워지는지 확인합니다.
5. 아직 등록된 실물이 하나도 없는 자료라면(전체 도서관에 등록번호가
   하나도 없는 초기 상태) 등록번호 칸에 "1"이 채워지는지 확인합니다.
