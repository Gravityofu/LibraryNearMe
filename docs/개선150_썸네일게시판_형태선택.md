# 개선150. 게시판마다 목록형/썸네일형 선택 + 썸네일 비율(가로형/세로형) 선택

## 목표

1. 지금은 게시판마다 '목록형'/'썸네일형'이 코드에 고정되어 있는데, 이걸 설정 > 게시판 모달에서 직접 바꿀 수 있게 합니다.
2. 썸네일형을 고른 게시판은 썸네일 비율을 '가로형'(한 줄에 3개, 3줄 = 한 페이지 9개) 또는 '세로형'(한 줄에 4개, 2줄 = 한 페이지 8개) 중에서 고를 수 있게 합니다.
3. 사진은 지금처럼 상자 안에 꽉 차게 잘라서(object-cover) 보여주기 때문에, 원본 사진이 가로로 길든 세로로 길든 상자 모양은 항상 똑같아서 글자 카드 크기가 사진마다 달라지는 문제가 사라집니다.

> 참고: 지금까지 썸네일형 게시판은 전부 정사각형 상자(가로:세로 = 1:1)였습니다. 이번에 '가로형'/'세로형' 두 가지로 정리하면서, 기존 게시판들은 전부 기본값으로 **가로형**(한 줄 3개는 지금과 같고, 상자 모양만 정사각형에서 살짝 넓은 가로형으로 바뀝니다)이 됩니다. 마음에 들지 않는 게시판은 설정에서 언제든 '세로형'으로 바꾸실 수 있습니다.

## 확인하기

1. `cd C:\projects\LibraryNearMe\backend`에서 `npx prisma migrate dev --name board_thumbnail_ratio`가 성공적으로 실행되었는지 확인합니다.
2. 관리자 페이지 > 설정 > 게시판 메뉴에서 목록형 게시판(예: 참고서비스)을 눌러 '목록 스타일'을 '썸네일형'으로 바꾸고 저장해 보세요. 표의 '목록 스타일' 칸이 바뀌는지, 홈페이지에서 그 게시판이 카드형으로 보이는지 확인합니다.
3. 썸네일형 게시판(예: 컬렉션)을 눌러 '썸네일 비율'을 '세로형'으로 바꾸고 저장해 보세요. 홈페이지에서 한 줄에 4개씩, 사진 상자가 세로로 긴 모양으로 나오는지 확인합니다. 다시 '가로형'으로 바꾸면 한 줄에 3개씩 나오는지도 확인합니다.
4. '목록 스타일'을 '목록형'으로 바꾸면 '썸네일 비율' 선택지 자체가 화면에서 사라지는지 확인합니다.
5. 세로가 긴 사진과 가로가 긴 사진을 각각 첨부해서 글을 써보고, 두 글의 카드 크기가 서로 똑같이 나오는지 확인합니다.
6. 세로형으로 바꾼 게시판에서 글이 9개 이상 있으면, 한 페이지에 8개씩(4개×2줄) 나오고 페이지가 잘 넘어가는지 확인합니다.
