# 개선 54: 대출일 직접 입력 시 형식이 잘못되면 알림창으로 안내하기

## 목표

개선53에서 대출일 칸에 직접 숫자를 입력하면 자동으로 `YYYY-MM-DD` 형식이 되도록 했지만, 아직 두 가지 문제가 있습니다.

- `2025-07`처럼 일(day)까지 다 입력하지 않아도 그대로 값이 남을 수 있습니다.
- `2122-13-32`처럼 실제로는 존재하지 않는 달(13월)이나 날짜(32일)를 입력해도 그대로 값이 남습니다.

이번에는 관리자가 이 칸에 입력을 마치고 다른 곳을 클릭하는 순간(포커스가 빠져나가는 순간), 입력한 값이 `YYYY-MM-DD` 형식이면서 실제로 존재하는 날짜인지 확인합니다. 만약 형식이 틀리거나 존재하지 않는 날짜라면, 모달 알림창으로 "날짜 형식이 올바르지 않습니다"라고 안내하고, 입력 칸의 값은 마지막으로 정상적으로 입력했던 날짜로 되돌립니다.

### 2-1. 날짜가 실제로 존재하는 날짜인지 확인하는 도구 함수 추가하기

아래 부분을 찾으세요.

```tsx
// 사용자가 입력한 글자에서 숫자만 뽑아, "YYYY-MM-DD" 형태로 하이픈을 자동으로 넣어줍니다.
// 예: "20140212" -> "2014-02-12", "202402" -> "2024-02"
function formatDateInput(raw: string) {
  const digits = raw.replace(/\D/g, "").slice(0, 8);
  if (digits.length <= 4) return digits;
  if (digits.length <= 6) return `${digits.slice(0, 4)}-${digits.slice(4)}`;
  return `${digits.slice(0, 4)}-${digits.slice(4, 6)}-${digits.slice(6)}`;
}
```

이렇게 바꿔주세요.

```tsx
// 사용자가 입력한 글자에서 숫자만 뽑아, "YYYY-MM-DD" 형태로 하이픈을 자동으로 넣어줍니다.
// 예: "20140212" -> "2014-02-12", "202402" -> "2024-02"
function formatDateInput(raw: string) {
  const digits = raw.replace(/\D/g, "").slice(0, 8);
  if (digits.length <= 4) return digits;
  if (digits.length <= 6) return `${digits.slice(0, 4)}-${digits.slice(4)}`;
  return `${digits.slice(0, 4)}-${digits.slice(4, 6)}-${digits.slice(6)}`;
}

// "YYYY-MM-DD" 형식이면서, 실제로 존재하는 날짜인지 확인합니다.
// (예: "2122-13-32"는 형식은 비슷해 보여도 13월, 32일이 없으므로 false를 돌려줍니다.)
function isValidDateStr(str: string) {
  if (!/^\d{4}-\d{2}-\d{2}$/.test(str)) return false;
  const [y, m, d] = str.split("-").map(Number);
  const date = new Date(y, m - 1, d);
  return date.getFullYear() === y && date.getMonth() === m - 1 && date.getDate() === d;
}
```
