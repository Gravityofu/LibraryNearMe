# 개선17. '소장 부수 목록'의 등록 행을 더 잘 보이게 고치기

## 🎯 목표

지금 실물 등록 페이지의 '소장 부수 목록' 표를 보면, 맨 위에 검정 바탕에 하얀 글씨로 **"실물 자료 등록"**이라고만 적혀 있어요. 이 행을 누르면 "새 자료를 새로 등록하는 모드로 바뀐다"는 뜻인데, 지금 모습만 보면 그게 잘 안 느껴지죠.

그래서 이번에는

- 글자 앞에 동그란 **"+" 아이콘**을 붙이고
- 문구도 **"새 실물 자료 등록"**으로 바꿔서

"아, 여기를 누르면 새로 하나 추가하는 거구나!"라는 느낌이 확실히 들도록 고쳐볼게요.

### 그림으로 보면

```
[전]  ┌─────────────────────────────┐
      │ 실물 자료 등록                │   ← 그냥 제목처럼 보임
      └─────────────────────────────┘

[후]  ┌─────────────────────────────┐
      │ (+) 새 실물 자료 등록          │   ← "+" 아이콘이 있어서
      └─────────────────────────────┘        "누르면 추가되는구나" 하고 바로 느껴짐
```

이 "+" 동그라미는 별도의 아이콘 파일을 쓰지 않고, 글자만으로 동그라미 안에 "+" 하나 그려 넣는 아주 가벼운 방식이라 코드도 간단해요. 그리고 색깔은 지금 이 행의 글자 색을 그대로 따라가도록 만들어서, 선택된 상태(검정 바탕/하얀 글씨)든 선택 안 된 상태(하얀 바탕/검정 글씨, 검정 테두리)든 자동으로 잘 어울리게 만들 거예요.

## 1단계. 문구 바꾸기

**파일**: `frontend/src/lib/dictionary.ts`

이 파일 안에서 아래 줄을 찾아주세요. (한글 설정 부분에 하나, 영어 설정 부분에 하나, 총 두 군데 있어요.)

**한글 부분에서 찾기:**

```ts
    "materials.copies.newRegistrationRow": "실물 자료 등록",
```

**이렇게 바꿔주세요:**

```ts
    "materials.copies.newRegistrationRow": "새 실물 자료 등록",
```

**영어 부분에서 찾기:**

```ts
    "materials.copies.newRegistrationRow": "Register New Copy",
```

**이렇게 바꿔주세요:**

```ts
    "materials.copies.newRegistrationRow": "+ Register New Copy",
```

> 💡 영어 문구는 원래도 뜻이 명확해서(Register **New** Copy), 굳이 단어를 바꾸기보다 앞에 "+ "만 붙여줬어요.

## 2단계. "+" 아이콘 붙이기

**파일**: `frontend/src/app/admin/materials/copies/page.tsx`

이 파일 안에서 아래 코드를 찾아주세요. ('소장 부수 목록' 표의 맨 첫 번째 행 부분이에요.)

**찾기:**

```tsx
                <tr onClick={resetForm} className="cursor-pointer">
                  <td
                    colSpan={4}
                    className={`px-2 py-2 font-semibold ${
                      selectedCopyId === null ? "" : "border border-black text-black"
                    }`}
                    style={selectedCopyId === null ? { backgroundColor: "#000000", color: "#ffffff" } : undefined}
                  >
                    {t("materials.copies.newRegistrationRow")}
                  </td>
                </tr>
```

**이렇게 바꿔주세요:**

```tsx
                <tr onClick={resetForm} className="cursor-pointer">
                  <td
                    colSpan={4}
                    className={`px-2 py-2 font-semibold ${
                      selectedCopyId === null ? "" : "border border-black text-black"
                    }`}
                    style={selectedCopyId === null ? { backgroundColor: "#000000", color: "#ffffff" } : undefined}
                  >
                    <span className="inline-flex items-center gap-2">
                      <span
                        className="flex h-5 w-5 shrink-0 items-center justify-center rounded-full border text-xs leading-none"
                        style={{ borderColor: "currentColor" }}
                      >
                        +
                      </span>
                      {t("materials.copies.newRegistrationRow")}
                    </span>
                  </td>
                </tr>
```

### 무슨 코드인가요?

- `<span className="inline-flex items-center gap-2">`: "+" 동그라미와 글자를 나란히, 살짝 간격을 주면서 배치하는 감싸는 상자예요.
- 그 안의 작은 `<span>`: `h-5 w-5`(가로세로 20px 크기)에 `rounded-full`(완전히 둥글게)을 줘서 동그란 모양을 만들고, 그 안에 텍스트로 그냥 `+`를 넣었어요.
- `style={{ borderColor: "currentColor" }}`: 이 동그라미 테두리 색을 **지금 글자 색과 똑같이** 맞춰줘요. 그래서 이 행이 선택된 상태(하얀 글씨)면 테두리도 하얀색, 선택 안 된 상태(검정 글씨)면 테두리도 검정색으로 자동으로 바뀌어요. 색을 따로 하드코딩하지 않아도 되는 방법이에요.

## ✅ 확인하기

1. 백엔드(`npm run start:dev`)와 프론트엔드(`npm run dev`)를 둘 다 실행해주세요.
2. 관리자 페이지 → 자료 목록에서 아무 자료나 클릭해서 실물 등록 페이지로 들어가주세요.
3. '소장 부수 목록' 표 맨 위에 동그란 "+" 아이콘과 함께 **"새 실물 자료 등록"**이라는 글자가 보이면 성공이에요.
4. 기존 실물 자료 행을 하나 클릭해보세요. 그러면 '새 실물 자료 등록' 행의 검정 바탕이 사라지고 흰 바탕에 검정 테두리로 바뀌면서, "+" 동그라미 색도 자연스럽게 검정으로 바뀌는지 확인해주세요.
5. 다시 '새 실물 자료 등록' 행을 클릭하면 원래대로 검정 바탕/하얀 글씨/하얀 "+" 동그라미로 돌아오는지 확인해주세요.
