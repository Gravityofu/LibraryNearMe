# 개선 46: 자료(서지) 삭제 확인도 모달로 바꾸기

## 목표

개선45에서 실물 자료 삭제는 확인 모달로 바꿨는데, 자료(서지) 자체를 삭제하는 '이 자료 삭제' 버튼은 아직 브라우저 기본 알림창(`window.confirm`)을 쓰고 있었습니다. MARC를 쓰는 자료든 아니든 이 버튼은 같은 함수(`handleDeleteMaterial`)를 쓰고 있어서, MARC 자료 화면에서 버튼을 누르면 자바스크립트 경고창이 뜨는 것입니다. 이번 가이드에서는 이 확인창도 개선45와 같은 방식의 모달 팝업으로 바꿉니다. (MARC 자료 화면과 MARC를 쓰지 않는 자료 화면 모두 같은 함수를 쓰기 때문에, 한 번에 두 화면 모두 고쳐집니다.)

### 2. 자료 삭제 함수에서 브라우저 기본 확인창 없애기

아래 부분을 찾으세요.

```tsx
  // 자료(서지) 자체를 삭제합니다. 실물이 남아있으면 서버가 막고 이유를 알려줘요.
  async function handleDeleteMaterial() {
    if (!material) return;
    if (!window.confirm(t("materials.copies.deleteMaterialConfirm"))) return;
    const token = localStorage.getItem("token");
    if (!token) return;
    const res = await fetch(`${API_URL}/materials/${material.id}`, {
      method: "DELETE",
      headers: { Authorization: `Bearer ${token}` },
    });
    if (res.ok) {
      notify("✅ " + t("materials.copies.deleteMaterialSuccess"), "success");
      router.push("/admin/materials/list");
    } else {
      const data = await res.json().catch(() => null);
      notify("❌ " + (data?.message || t("materials.copies.deleteMaterialFail")), "error");
    }
```

이렇게 바꿔주세요.

```tsx
  // 자료(서지) 자체를 삭제합니다. 실물이 남아있으면 서버가 막고 이유를 알려줘요.
  // (삭제 확인 모달에서 '삭제'를 눌렀을 때 호출됩니다.)
  async function handleDeleteMaterial() {
    if (!material) return;
    const token = localStorage.getItem("token");
    if (!token) return;
    const res = await fetch(`${API_URL}/materials/${material.id}`, {
      method: "DELETE",
      headers: { Authorization: `Bearer ${token}` },
    });
    if (res.ok) {
      notify("✅ " + t("materials.copies.deleteMaterialSuccess"), "success");
      setShowDeleteMaterialConfirm(false);
      router.push("/admin/materials/list");
    } else {
      const data = await res.json().catch(() => null);
      setShowDeleteMaterialConfirm(false);
      notify("❌ " + (data?.message || t("materials.copies.deleteMaterialFail")), "error");
    }
```

## 확인하기

1. 프런트엔드 개발 서버를 재시작하거나 새로고침하세요. (백엔드와 dictionary.ts는 이번에 바뀐 것이 없습니다.)
2. '목록'에서 도서나 DVD처럼 MARC를 쓰는 자료를 클릭해서 들어가세요.
3. '이 자료 삭제' 버튼을 눌러보세요. 브라우저 기본 알림창이 아니라 모달 팝업이 뜨는지 확인하세요.
4. 모달에서 '취소'를 눌러서 그냥 닫히는지 확인하세요.
5. 실물이 등록된 자료라면, 모달에서 다시 '이 자료 삭제'를 눌렀을 때 실물이 있어서 삭제가 막히고 안내 메시지가 뜨는지 확인하세요.
6. MARC를 쓰지 않는 자료(예: 논문/기사 등) 화면에서도 마찬가지로 모달이 뜨는지 확인하세요.
7. 실물이 없는 자료로 삭제까지 진행해서 정상적으로 삭제되고 목록으로 돌아가는지 확인하세요.
