# 개선102: '목록' / '회원' / '대출이력' 상단 버튼 영역에 박스(테두리) 추가

## 목표

'예약' 탭과 '대출' 탭 상단은 버튼들이 테두리 있는 흰 박스 안에 들어있는데, '목록' / '회원' / '대출이력'은 상단 버튼들이 박스 없이 배경 위에 그냥 놓여 있었습니다. 이번 가이드는 이 세 화면의 상단 버튼 영역에도 같은 스타일의 박스(테두리 있는 흰 배경)를 추가해서, 네 화면 모두 상단 버튼 영역의 모양이 통일되게 합니다.

이번에도 각 파일에서 한 줄(상단 버튼들을 감싸는 `<div>`)의 스타일만 바뀌기 때문에, 그 줄만 찾아서 바꾸는 방식으로 안내드립니다.

---

## 1단계: '목록' 메뉴 상단 버튼 영역에 박스 추가

`frontend/src/app/admin/materials/list/page.tsx` 파일을 여세요.

아래 내용을 찾으세요.

```typescript
      {/* 상단 버튼 영역 */}
      <div className="flex items-center gap-2">
```

이 내용을 아래 내용으로 바꿔주세요.

```typescript
      {/* 상단 버튼 영역 */}
      <div className="flex items-center gap-2 rounded-lg border border-neutral-200 bg-white p-4">
```
