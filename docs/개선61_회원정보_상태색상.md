# 개선 61: '회원 정보' 박스의 상태 글자에 색상 넣기

## 목표

'대출/반납' 화면에서 회원을 검색하면 오른쪽 '회원 정보' 박스에 상태가 글자로 나옵니다. 이 글자에 상태별로 다른 색을 넣어서 한눈에 구분되도록 합니다.

- 대출가능(ACTIVE) → 파란색
- 대기(PENDING) → 노란색
- 정지(SUSPENDED) → 주황색
- 탈퇴(WITHDRAWN) → 빨간색

---

## 화면 수정하기: `page.tsx`

`C:\projects\LibraryNearMe\frontend\src\app\admin\loans\page.tsx` 파일을 여세요.

### 1. 상태별 색상을 정해주는 도우미 함수 추가하기

아래 부분을 찾으세요.

```tsx
// 회원 정보 박스 안에서 "라벨: 값" 한 줄을 보여주는 작은 부품입니다.
function InfoRow({ label, value }: { label: string; value: string }) {
  return (
    <div className="flex items-baseline justify-between gap-3 border-b border-neutral-100 py-1.5 text-sm last:border-b-0">
      <span className="shrink-0 text-neutral-500">{label}</span>
      <span className="text-right font-medium">{value}</span>
    </div>
  );
}
```

이렇게 바꿔주세요.

```tsx
// 회원 상태에 따라 글자 색을 다르게 보여주기 위한 도우미 함수입니다.
function statusColorClass(status: string | undefined) {
  switch (status) {
    case "ACTIVE":
      return "text-blue-600";
    case "PENDING":
      return "text-yellow-600";
    case "SUSPENDED":
      return "text-orange-600";
    case "WITHDRAWN":
      return "text-red-600";
    default:
      return "";
  }
}

// 회원 정보 박스 안에서 "라벨: 값" 한 줄을 보여주는 작은 부품입니다.
// valueClassName을 넘기면 값 글자에 추가로 스타일(예: 색상)을 입힐 수 있습니다.
function InfoRow({
  label,
  value,
  valueClassName,
}: {
  label: string;
  value: string;
  valueClassName?: string;
}) {
  return (
    <div className="flex items-baseline justify-between gap-3 border-b border-neutral-100 py-1.5 text-sm last:border-b-0">
      <span className="shrink-0 text-neutral-500">{label}</span>
      <span className={`text-right font-medium ${valueClassName || ""}`}>{value}</span>
    </div>
  );
}
```

### 2. 상태를 보여주는 부분에 색상 적용하기

아래 부분을 찾으세요.

```tsx
                  <InfoRow
                    label={t("members.form.field.status")}
                    value={selectedMember ? t(`members.status.${selectedMember.status}`) : "-"}
                  />
```

이렇게 바꿔주세요.

```tsx
                  <InfoRow
                    label={t("members.form.field.status")}
                    value={selectedMember ? t(`members.status.${selectedMember.status}`) : "-"}
                    valueClassName={statusColorClass(selectedMember?.status)}
                  />
```
