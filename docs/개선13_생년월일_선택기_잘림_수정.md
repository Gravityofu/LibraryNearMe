# 개선 (13) — 생년월일 선택기가 박스 밖에서 잘리는 문제 수정

> 목표: 년도 숫자패드, 월/일 버튼 목록이 화면의 좁은 박스(회원가입 박스,
> 회원 등록 모달 등) 바깥으로 나가면 잘려서 안 보이던 문제를 고칩니다.
> 소요 시간: 약 10분

---

## 왜 잘렸을까요?

지금 만든 선택기(숫자패드, 월/일 버튼)는 입력칸 바로 아래에 "그 칸을
둘러싼 박스 안에서" 나타나는 방식이었어요. 그런데 회원가입 박스나 회원
등록 모달처럼 **모서리를 둥글게 하려고 "박스 바깥으로 나가는 내용은
자른다"는 설정(`overflow-hidden`)**이 되어 있는 박스 안에 이 선택기가
들어있다 보니, 선택기가 박스 경계를 넘어가면 그 부분이 통째로 잘려버렸던
거예요.

오늘은 이 선택기가 나타날 때 **박스 안이 아니라 화면(문서) 맨 위 레이어에
따로 떠 있도록** 만들어서, 어떤 박스 안에 있든 잘리지 않게 고칩니다. (이런
방식을 "포털(portal)"이라고 불러요 — 화면의 다른 위치에 실제로 그려주는
방식이에요.)

## `birth-date-field.tsx` 전체 교체 — 약 10분

`frontend/src/components/birth-date-field.tsx` 를 엽니다. 파일 전체 내용을
아래로 통째로 바꿔주세요.

```tsx
"use client";

import { useEffect, useRef, useState } from "react";
import { createPortal } from "react-dom";

// 년/월/일을 각각 문자열로 담습니다. (예: {year:"1990", month:"03", day:"05"})
export type BirthDateValue = {
  year: string;
  month: string;
  day: string;
};

type Props = {
  value: BirthDateValue;
  onChange: (value: BirthDateValue) => void;
};

// 전화기 숫자패드처럼 1~9, 그리고 마지막 줄에 0과 지우기(⌫) 버튼이 있는 배열입니다.
const KEYPAD_ROWS = [
  ["1", "2", "3"],
  ["4", "5", "6"],
  ["7", "8", "9"],
  ["", "0", "⌫"],
];

const MONTHS = Array.from({ length: 12 }, (_, i) => i + 1); // 1~12
const DAYS = Array.from({ length: 31 }, (_, i) => i + 1); // 1~31

export function BirthDateField({ value, onChange }: Props) {
  const [open, setOpen] = useState<"year" | "month" | "day" | null>(null);
  const [panelPos, setPanelPos] = useState<{ top: number; left: number } | null>(null);

  const wrapRef = useRef<HTMLDivElement>(null);
  const panelRef = useRef<HTMLDivElement>(null);
  const yearRef = useRef<HTMLInputElement>(null);
  const monthRef = useRef<HTMLInputElement>(null);
  const dayRef = useRef<HTMLInputElement>(null);

  // 이 컴포넌트(입력칸)나, 화면 맨 위 레이어에 떠 있는 패널 바깥을 클릭하면 패널을 닫습니다.
  useEffect(() => {
    function handleOutside(e: MouseEvent) {
      const target = e.target as Node;
      if (wrapRef.current?.contains(target)) return;
      if (panelRef.current?.contains(target)) return;
      setOpen(null);
    }
    document.addEventListener("mousedown", handleOutside);
    return () => document.removeEventListener("mousedown", handleOutside);
  }, []);

  // 패널을 열 때, 그 입력칸이 화면 어디에 있는지 좌표를 계산해서 그 아래에 딱 붙여 띄웁니다.
  function openPanel(which: "year" | "month" | "day", inputEl: HTMLInputElement | null) {
    if (inputEl) {
      const rect = inputEl.getBoundingClientRect();
      setPanelPos({ top: rect.bottom + 4, left: rect.left });
    }
    setOpen(which);
  }

  function pressYearDigit(digit: string) {
    const next = (value.year + digit).slice(0, 4);
    onChange({ ...value, year: next });
    if (next.length === 4) setOpen(null);
  }

  function pressYearBackspace() {
    onChange({ ...value, year: value.year.slice(0, -1) });
  }

  function pickMonth(m: number) {
    onChange({ ...value, month: String(m).padStart(2, "0") });
    setOpen(null);
  }

  function pickDay(d: number) {
    onChange({ ...value, day: String(d).padStart(2, "0") });
    setOpen(null);
  }

  return (
    <div ref={wrapRef} className="flex items-center gap-1.5">
      {/* 년도 */}
      <input
        ref={yearRef}
        value={value.year}
        onChange={(e) => onChange({ ...value, year: e.target.value.replace(/\D/g, "").slice(0, 4) })}
        onFocus={() => openPanel("year", yearRef.current)}
        placeholder="YYYY"
        inputMode="numeric"
        maxLength={4}
        className="w-20 rounded-lg border px-3 py-2 text-center text-sm"
      />
      <span className="text-sm text-neutral-400">년</span>

      {/* 월 */}
      <input
        ref={monthRef}
        value={value.month}
        onChange={(e) => onChange({ ...value, month: e.target.value.replace(/\D/g, "").slice(0, 2) })}
        onFocus={() => openPanel("month", monthRef.current)}
        placeholder="MM"
        inputMode="numeric"
        maxLength={2}
        className="w-14 rounded-lg border px-3 py-2 text-center text-sm"
      />
      <span className="text-sm text-neutral-400">월</span>

      {/* 일 */}
      <input
        ref={dayRef}
        value={value.day}
        onChange={(e) => onChange({ ...value, day: e.target.value.replace(/\D/g, "").slice(0, 2) })}
        onFocus={() => openPanel("day", dayRef.current)}
        placeholder="DD"
        inputMode="numeric"
        maxLength={2}
        className="w-14 rounded-lg border px-3 py-2 text-center text-sm"
      />
      <span className="text-sm text-neutral-400">일</span>

      {/* 패널(숫자패드/월버튼/일버튼)은 이 화면 어디에 있든 document.body 맨 위 레이어에 그려집니다.
          그래서 부모 박스가 overflow-hidden 이어도 잘리지 않아요. */}
      {typeof document !== "undefined" &&
        open &&
        panelPos &&
        createPortal(
          <div
            ref={panelRef}
            style={{ position: "fixed", top: panelPos.top, left: panelPos.left, zIndex: 9999 }}
          >
            {open === "year" && (
              <div className="w-32 rounded-lg border bg-white p-2 shadow-lg">
                {KEYPAD_ROWS.map((row, i) => (
                  <div key={i} className="grid grid-cols-3 gap-1">
                    {row.map((digit, j) =>
                      digit === "" ? (
                        <span key={j} />
                      ) : (
                        <button
                          key={j}
                          type="button"
                          onClick={() => (digit === "⌫" ? pressYearBackspace() : pressYearDigit(digit))}
                          className="cursor-pointer rounded-md border py-1.5 text-sm hover:bg-neutral-100"
                        >
                          {digit}
                        </button>
                      ),
                    )}
                  </div>
                ))}
              </div>
            )}

            {open === "month" && (
              <div className="grid w-48 grid-cols-4 gap-1 rounded-lg border bg-white p-2 shadow-lg">
                {MONTHS.map((m) => (
                  <button
                    key={m}
                    type="button"
                    onClick={() => pickMonth(m)}
                    className="cursor-pointer rounded-md border py-1.5 text-sm hover:bg-neutral-100"
                  >
                    {m}
                  </button>
                ))}
              </div>
            )}

            {open === "day" && (
              <div className="grid max-h-48 w-56 grid-cols-6 gap-1 overflow-auto rounded-lg border bg-white p-2 shadow-lg">
                {DAYS.map((d) => (
                  <button
                    key={d}
                    type="button"
                    onClick={() => pickDay(d)}
                    className="cursor-pointer rounded-md border py-1.5 text-sm hover:bg-neutral-100"
                  >
                    {d}
                  </button>
                ))}
              </div>
            )}
          </div>,
          document.body,
        )}
    </div>
  );
}

// 진짜 존재하는 날짜인지 확인합니다. (13월, 32일, 2월 30일 같은 건 걸러냅니다.)
export function isValidBirthDate(year: string, month: string, day: string) {
  const y = Number(year);
  const m = Number(month);
  const d = Number(day);
  const currentYear = new Date().getFullYear();

  if (!year || !month || !day) return false;
  if (year.length !== 4) return false;
  if (y < 1900 || y > currentYear) return false;
  if (m < 1 || m > 12) return false;
  if (d < 1 || d > 31) return false;

  const date = new Date(y, m - 1, d);
  return date.getFullYear() === y && date.getMonth() === m - 1 && date.getDate() === d;
}
```

바뀐 부분을 간단히 정리하면:

- 예전에는 패널이 `absolute`로 "입력칸을 감싼 작은 박스 안"에서 위치를
  잡았는데, 이제는 `position: fixed`로 **화면 전체 기준** 좌표를 계산해서
  `document.body`에 직접 그려요. `createPortal`이 바로 이 "다른 위치에
  그리기"를 해주는 React 기능이에요.
- 패널을 열 때(`openPanel`) 입력칸의 실제 화면 위치(`getBoundingClientRect`)를
  구해서, 그 바로 아래에 패널이 나타나도록 좌표를 계산해요.
- 패널이 이제 부모 박스 밖(`document.body`)에 그려지기 때문에, "바깥을
  클릭하면 닫기" 로직도 패널 자기 자신(`panelRef`)은 예외로 봐주도록
  살짝 수정했어요. (안 그러면 버튼을 눌러도 패널이 먼저 닫혀버려서 클릭이
  씹혀요.)

## 확인하기 — 약 5분

1. `/signup` 화면에서 년도 칸을 클릭해 숫자패드를 열어봅니다. 박스 경계에
   가깝더라도 잘리지 않고 전체가 다 보이는지 확인합니다.
2. 월/일 버튼도 마찬가지로 잘리지 않는지 확인합니다.
3. 관리자 페이지 → 회원 → 등록/수정 모달에서도 생년월일 선택기가 잘리지
   않는지 확인합니다. (이 부품은 두 화면에서 같이 쓰고 있어서, 한 번
   고치면 둘 다 고쳐져요.)
4. 숫자/버튼을 눌렀을 때 예전처럼 잘 채워지고 패널이 닫히는지 확인합니다.
5. 패널이 열린 상태에서 패널 바깥(다른 입력칸 등)을 클릭하면 잘 닫히는지
   확인합니다.
6. `⌫` 지우기 버튼도 잘 동작하는지 확인합니다.
