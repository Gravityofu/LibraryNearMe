# 개선80: 대출 처리 시 자료 상태 확인 기준값을 '대출가능'으로 수정하기

## 목표

대출 처리 로직(`loans.service.ts`)은 자료(실물)가 대출 가능한 상태인지 확인할 때, 코드 안에 `'이용가능'`이라는 문자열을 기준값으로 쓰고 있습니다. 그런데 실제로 우리 시스템에서 자료가 "대출 가능"함을 나타내는 값은 `'대출가능'`입니다. (설정 화면의 기본 상태 목록이나, 예전 영문 코드를 한글로 바꿔주는 변환표에서도 전부 `'대출가능'`을 쓰고 있습니다.)

이 기준값이 옛날 값(`'이용가능'`)으로 남아있던 탓에, 실제로는 대출 가능한 상태인 자료도 대출 처리 시 "현재 대출 가능한 상태가 아닙니다"라는 메시지와 함께 거부되고 있었습니다. 이 가이드는 기준값을 실제 시스템에서 쓰는 값인 `'대출가능'`으로 바로잡습니다.

---

## 1단계: `loans.service.ts` 수정하기

`backend/src/loans/loans.service.ts` 파일을 여세요.

파일 맨 위쪽에서 아래 내용을 찾으세요.

```typescript
const AVAILABLE = '이용가능';
const ON_LOAN = '대출중';
```

이 내용을 아래 내용으로 바꿔주세요.

```typescript
const AVAILABLE = '대출가능';
const ON_LOAN = '대출중';
```

**설명:** `AVAILABLE`은 "자료가 대출 가능한 상태"임을 나타내는 기준값으로, 대출 처리 로직에서 자료 상태와 이 값을 비교해 대출 가능 여부를 판단합니다. `ON_LOAN`(대출중)은 이미 실제 시스템 값과 일치하고 있어서 그대로 둡니다. `AVAILABLE`만 실제 시스템에서 쓰는 값인 `'대출가능'`으로 고치면, 자료 상태 확인이 정상적으로 동작합니다.

## 확인하기

1. `backend` 서버를 재시작해 주세요.
2. 자료 상태가 '대출가능'인 등록번호로, 대출 한도에 걸리지 않는 회원을 골라 대출을 시도해 보세요.
3. 이번에는 "현재 대출 가능한 상태가 아닙니다" 메시지 없이 정상적으로 대출이 처리되어야 합니다.
4. 대출 처리 후, 해당 자료의 상태가 '대출중'으로 바뀌었는지, 그리고 회원의 "대출 자료 목록"에 방금 대출한 자료가 나타나는지 확인해 주세요.
5. 반대로, 상태가 '대출중'이거나 '보수중' 등 대출 가능하지 않은 자료로 대출을 시도했을 때는 여전히 "현재 대출 가능한 상태가 아닙니다" 메시지가 뜨며 정상적으로 거부되는지도 확인해 주세요.
