# 개선145. '자주 묻는 질문' 게시판 홈페이지 아코디언 UI

## 목표

'자주 묻는 질문' 게시판만 홈페이지에서 다른 게시판과 다르게 보여주도록 만듭니다.

- 다른 게시판(목록형/썸네일형)은 지금처럼 목록 → 클릭 시 별도의 상세 페이지로 이동합니다. (이 부분은 그대로 둡니다.)
- '자주 묻는 질문' 게시판만 질문 목록이 세로로 나열되고, 질문을 클릭하면 다른 페이지로 이동하지 않고 그 질문 바로 아래에 아코디언(접고 펼치기) 형태로 답변이 펼쳐집니다.
- 펼쳐진 내용 맨 위에는 관리자 페이지에서 입력한 키워드가 굵은 이탤릭체·도서관 색상으로 나오고, 그 아래에 관리자 페이지에서 저장한 본문 내용이 나옵니다.
- 키워드나 본문은 질문을 클릭하는 순간 서버에서 불러오고, 한 번 불러온 내용은 다시 접었다 펴도 새로 불러오지 않고 그대로 재사용합니다. (이미 있는 "글 상세 조회" API를 그대로 재사용하기 때문에, 새 백엔드 코드는 필요 없습니다.)

> 참고: '자주 묻는 질문'은 지금까지 '목록형' 게시판(제목·작성자·작성일·조회수가 나오는 표)이었는데, 아코디언 방식은 표보다는 "질문 하나하나가 눌러서 펼쳐지는 리스트" 형태가 자연스러워서, 이 게시판만 표 대신 질문 리스트로 화면을 새로 만들었습니다. 다른 목록형 게시판(참고서비스 등)은 지금 그대로 표 형태를 유지합니다.

바꿀 파일은 `frontend/src/app/(site)/boards/[code]/page.tsx` 하나뿐입니다. 백엔드는 손댈 필요가 없습니다.

```typescript
  function goToPage(p: number) {
    router.push(`/boards/${code}?page=${p}`);
  }

  // '자주 묻는 질문' 아코디언용: 이 글의 키워드·본문을 처음 펼칠 때만 서버에서 불러옵니다.
  // (기존에 있는 "글 상세 조회" API를 그대로 재사용합니다. 이 API를 부르면 조회수가 1 올라갑니다.)
  async function loadFaqDetail(id: number) {
    if (faqDetails[id]) return;
    setFaqLoadingId(id);
    const res = await fetch(`${API_URL}/public/posts/${id}`);
    if (res.ok) {
      const data = await res.json();
      setFaqDetails((prev) => ({ ...prev, [id]: { content: data.content, keywords: data.keywords || [] } }));
    }
    setFaqLoadingId(null);
  }

  // 질문을 클릭했을 때: 이미 펼쳐진 질문을 다시 누르면 접고, 아니면 그 질문만 펼칩니다.
  function toggleFaq(id: number) {
    if (expandedId === id) {
      setExpandedId(null);
      return;
    }
    setExpandedId(id);
    loadFaqDetail(id);
  }
```

## 확인하기

1. 관리자 페이지 > 게시판(자주 묻는 질문)에서 제목·키워드·내용을 입력해 질문을 2~3개 등록해 주세요. (이미 등록되어 있다면 넘어가셔도 됩니다.)
2. 홈페이지에서 '자주 묻는 질문' 게시판으로 이동해서, 표가 아니라 질문 제목이 세로로 나열된 목록으로 보이는지 확인합니다.
3. 질문 하나를 클릭했을 때 페이지 이동 없이 그 질문 바로 아래로 키워드와 내용이 펼쳐지는지 확인합니다.
4. 펼쳐진 질문을 다시 클릭하면 접히는지, 다른 질문을 클릭하면 이전 질문은 접히고 새 질문만 펼쳐지는지 확인합니다.
5. 키워드를 입력하지 않은 질문을 펼쳤을 때도 화면이 깨지지 않고 내용이 바로 나오는지 확인합니다.
6. 질문이 15개보다 많다면 페이지 번호를 눌러 다음 페이지로 넘어가도 정상 작동하는지 확인합니다.
7. 다른 게시판(공지, 열린 게시판 등)은 이전처럼 표/카드 목록 → 클릭 시 별도 상세 페이지로 이동하는 방식이 그대로 유지되는지 확인합니다.
