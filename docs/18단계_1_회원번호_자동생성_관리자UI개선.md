# 18단계 (1) — 회원번호 자동 생성 + 관리자 메뉴 강조/브레드크럼

> 목표: ① 관리자가 회원을 등록할 때 회원번호("M000001" 형식)가 자동으로
> 다음 번호로 채워지게 만듭니다. ② "목록" 메뉴는 자료 등록·실물 등록
> 화면에 있을 때도 선택된 것처럼 박스 표시가 나오게 합니다. ③ 관리자
> 페이지 상단 좌측에 지금 어디에 있는지 알려주는 브레드크럼(경로 표시)을
> 추가합니다.
> 소요 시간: 약 30분

## 오늘 만드는 것 (그림으로)

```
① 회원번호 자동 채우기
"회원" → "등록" 버튼 클릭
┌─────────────────────┐
│ 회원번호  [M000005]    │  ← 자동으로 다음 번호가 채워짐 (직접 수정도 가능)
└─────────────────────┘

② 사이드바 강조 범위 넓히기
목록 페이지 있을 때:      [목록] ← 박스 표시
자료 등록 페이지 있을 때:  [목록] ← 지금까지는 표시 안 됐음 → 오늘부터 표시
실물 등록 페이지 있을 때:  [목록] ← 지금까지는 표시 안 됐음 → 오늘부터 표시

③ 브레드크럼 추가
상단 좌측에 이렇게 표시됩니다.
"자료 등록" 화면 → 목록 › 자료 등록
"실물 등록" 화면 → 목록 › 실물 등록
"회원" 화면      → 회원
```

## 1. 백엔드 — 다음 회원번호 계산 API 추가 — 약 8분

`backend/src/users/users.service.ts` 를 엽니다. `update()` 함수 바로 아래
(파일 맨 끝, 마지막 닫는 중괄호 `}` 앞)에 아래 함수를 추가하세요.

```typescript
  // 다음 회원번호를 계산합니다. "M" + 숫자 6자리(M000001, M000002...) 형식입니다.
  async getNextMemberNo(libraryId: number) {
    const candidates = await this.prisma.user.findMany({
      where: { libraryId, memberNo: { startsWith: 'M' } },
      orderBy: { memberNo: 'desc' },
      take: 20,
      select: { memberNo: true },
    });

    let maxNum = 0;
    for (const c of candidates) {
      const match = c.memberNo?.match(/^M(\d{6})$/);
      if (match) {
        maxNum = parseInt(match[1], 10);
        break;
      }
    }

    const next = maxNum + 1;
    return { memberNo: 'M' + String(next).padStart(6, '0') };
  }
```

- 자릿수가 6자리로 고정되어 있어서(`M000001`), 문자열로 정렬해도 숫자
  순서와 그대로 일치해요. 그래서 `orderBy: { memberNo: 'desc' }` 하나로
  가장 큰 번호를 찾을 수 있어요.
- 혹시 "M" 형식이 아닌 예전 회원번호가 섞여 있어도, 정규식으로 정확히
  "M+숫자6자리" 모양인 것만 골라서 계산하기 때문에 안전해요.

`backend/src/users/users.controller.ts` 를 엽니다. `list` 메서드 **바로
위**에 추가하세요.

```typescript
  // GET 요청: 다음 회원번호 미리 계산해서 알려주기 — 관리자만
  @Get('next-member-no')
  @UseGuards(AdminGuard)
  getNextMemberNo(@Req() req: any) {
    return this.usersService.getNextMemberNo(req.user.libraryId);
  }
```

> ⚠️ 이 경로는 반드시 `@Get()` (회원/관리자 목록 조회, `list`) **위쪽**에
> 있어야 해요. NestJS는 주소를 위에서부터 순서대로 확인하기 때문에,
> `next-member-no`가 `:id` 같은 다른 경로에 걸려 헷갈리는 걸 막기 위해서예요.

저장하면 backend가 재시작됩니다.

## 2. 관리자 회원 등록 화면 — 자동으로 다음 번호 채우기 — 약 6분

`frontend/src/app/admin/members/page.tsx` 를 엽니다. 아래 부분을 찾으세요.

```tsx
  function openAddModal() {
    setEditingId(null);
    setForm(EMPTY_FORM);
    setShowForm(true);
  }
```

이렇게 바꿔주세요. (함수를 `async`로 바꾸고, 다음 회원번호를 물어봐서
채워 넣는 부분을 추가했어요.)

```tsx
  async function openAddModal() {
    setEditingId(null);
    setForm(EMPTY_FORM);
    setShowForm(true);

    const token = localStorage.getItem("token");
    if (!token) return;
    const res = await fetch(`${API_URL}/users/next-member-no`, {
      headers: { Authorization: `Bearer ${token}` },
    });
    if (res.ok) {
      const data = await res.json();
      setForm((prev) => ({ ...prev, memberNo: data.memberNo }));
    }
  }
```

- 모달이 열리자마자 서버에 "다음 회원번호가 뭐예요?"라고 물어봐서 회원번호
  칸에 미리 채워 넣어요. 자동으로 채워지지만, 회원번호 칸은 여전히 직접
  타이핑해서 바꿀 수 있는 입력칸이라 필요하면 수정도 가능해요.

## 4. 브레드크럼(경로 표시) 추가 — 약 10분

같은 `frontend/src/app/admin/layout.tsx` 파일입니다.

### 4-1. 화면 주소 → 표시할 경로 목록 만들기

아래 부분을 찾으세요.

```tsx
export default function AdminLayout({
  children,
}: {
  children: React.ReactNode;
}) {
```

바로 위에 아래 내용을 추가하세요.

```tsx
// 화면 주소별로 상단에 보여줄 경로(브레드크럼)를 정의합니다.
// 배열에 문구가 두 개면 "A › B" 처럼 화살표로 이어서 보여줍니다.
const BREADCRUMB_MAP: Record<string, string[]> = {
  "/admin/settings": ["admin.menu.systemSettings"],
  "/admin/materials/list": ["admin.menu.materialsList"],
  "/admin/materials/new": ["admin.menu.materialsList", "admin.menu.materialsNew"],
  "/admin/materials/copies": ["admin.menu.materialsList", "admin.menu.materialsCopy"],
  "/admin/members": ["admin.menu.members"],
};

```

### 4-2. 지금 화면에 맞는 경로 계산하기

아래 부분을 찾으세요.

```tsx
  useRequireAuth();
  const pathname = usePathname();
```

이렇게 바꿔주세요.

```tsx
  useRequireAuth();
  const pathname = usePathname();
  const crumbs = BREADCRUMB_MAP[pathname];
```

### 4-3. 화면 위쪽에 브레드크럼 보여주기

아래 부분을 찾으세요.

```tsx
      <section className="flex-1">{children}</section>
```

이렇게 바꿔주세요.

```tsx
      <section className="flex-1">
        {crumbs && (
          <div className="px-6 pt-4 text-xs text-neutral-400">
            {crumbs.map((key, i) => (
              <span key={key}>
                {i > 0 && <span className="mx-1.5">›</span>}
                {t(key)}
              </span>
            ))}
          </div>
        )}
        {children}
      </section>
```

- `BREADCRUMB_MAP`에 없는 주소(예: 나중에 만들 대출/반납 화면)는 그냥
  브레드크럼이 안 보여요. 새 화면을 만들 때 이 목록에 한 줄만 추가하면
  됩니다.

## 5. 확인하기 — 약 6분

1. "회원" → "등록" 버튼을 누르면 회원번호 칸에 "M000001"(또는 다음 번호)이
   자동으로 채워지는지 확인합니다.
2. 회원을 하나 등록한 뒤 다시 "등록"을 누르면 그 다음 번호(M000002)로
   올라가는지 확인합니다.
3. 회원번호 칸을 직접 수정할 수도 있는지 확인합니다.
4. "목록" 화면에서 "자료 등록" 버튼을 눌러 이동했을 때, 사이드바의 "목록"
   메뉴에 여전히 박스(강조) 표시가 있는지 확인합니다.
5. "실물 등록" 화면에서도 마찬가지로 "목록" 메뉴가 강조되는지 확인합니다.
6. 각 화면 상단 좌측에 경로 표시가 보이는지 확인합니다. (예: 자료 등록
   화면 → "목록 › 자료 등록")

✅ 모두 확인되면 성공입니다! 🎉
