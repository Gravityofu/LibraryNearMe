# 개선27. '별치기호' · '소장처' 드롭다운도 '상태'처럼 처음부터 값이 채워지게 하기

## 🎯 목표

지금 '상태'는 모달을 열면 처음부터 첫 번째 값(예: "이용가능")이 자동으로 선택되어 있어요. 그런데 '별치기호'와 '소장처'는 아직 빈 값("-")이 기본으로 선택되어 있죠. 이번엔 이 둘도 '상태'와 똑같이, 모달을 열자마자 첫 번째 값이 자동으로 선택되도록 만들게요. (지난번(개선26)에 이 두 항목을 필수로 만들었으니, 처음부터 값이 채워져 있는 게 자연스러워요.)

---

## 수정하기

**파일**: `frontend/src/app/admin/materials/copies/page.tsx`

### 1) 폼을 초기화할 때, 별치기호/소장처도 첫 번째 값으로 채우기

**찾기:**

```tsx
  function resetForm() {
    setSelectedCopyId(null);
    setForm({
      ...EMPTY_FORM,
      authorCode: findAuthorCode(marc),
      registrationNo: computeNextRegNo(latestRegNo),
      status: copyOptions.STATUS[0]?.value || "",
    });
  }
```

**이렇게 바꿔주세요:**

```tsx
  function resetForm() {
    setSelectedCopyId(null);
    setForm({
      ...EMPTY_FORM,
      authorCode: findAuthorCode(marc),
      registrationNo: computeNextRegNo(latestRegNo),
      status: copyOptions.STATUS[0]?.value || "",
      specialCode: copyOptions.SPECIAL_CODE[0]?.value || "",
      location: copyOptions.LOCATION[0]?.value || "",
    });
  }
```

### 무슨 코드인가요?

'상태'에 이미 있던 `status: copyOptions.STATUS[0]?.value || ""`와 똑같은 방식이에요. `copyOptions.SPECIAL_CODE[0]`은 '별치기호' 목록의 첫 번째 값, `copyOptions.LOCATION[0]`은 '소장처' 목록의 첫 번째 값을 뜻해요. `?.value`는 "그 값이 있으면 `.value`를 꺼내고, 없으면 그냥 넘어가라"는 뜻이고, 혹시 목록이 완전히 비어있는 극단적인 경우를 대비해서 `|| ""`(빈 문자열)를 기본값으로 함께 넣어뒀어요.
