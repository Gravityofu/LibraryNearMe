# 18단계 (2) — 관리자 대시보드 추가 + 홈페이지 회원가입 회원번호 자동 입력

> 목표: ① 로그인 후 관리자 페이지에 처음 들어가면 "대시보드" 화면이 나오게
> 합니다(지금은 내용 없이 "(작업 중)"만 표시). 사이드바 "목록" 위에 "대시보드"
> 메뉴를 추가하고, 브레드크럼도 붙입니다. ② 홈페이지 회원가입 화면에도
> 회원번호가 자동으로 채워지게 하고(수정 불가), 가입이 완료될 때만 그
> 번호가 실제로 저장되게 만듭니다.
> 소요 시간: 약 30분

---

## 오늘 만드는 것 (그림으로)

```
① 대시보드
사이드바                     로그인 후 /admin 접속 시
┌───────────┐              ┌─────────────────────┐
│ 대시보드     │  ← 새로 추가    │ 대시보드                │
│ 목록        │              │ (작업 중)               │
│ 회원        │              └─────────────────────┘
│ 대출/반납    │
│ 설정        │
└───────────┘

② 홈페이지 회원가입 회원번호 자동 입력
회원가입 화면
┌─────────────────────┐
│ 회원번호   [M000006]    │  ← 자동 채움, 수정 불가(비활성화)
│ ...나머지 입력 폼...      │
└─────────────────────┘
가입 완료 → 그때 M000006이 실제로 저장됨
가입 실패(예: 중복 아이디) → M000006은 저장 안 됨, 다음 시도 때 같은 번호가 다시 나옴
```

## 2. 홈페이지 회원가입 — 회원번호 자동 입력

### 2-1. 백엔드 — 공개용(로그인 없이) 다음 회원번호 API 추가 — 약 8분

`backend/src/users/users.service.ts` 를 엽니다. `getNextMemberNo()` 함수
바로 아래에 함수를 하나 추가하세요.

```typescript

  async getNextMemberNoPublic() {
    const library = await this.prisma.library.findFirst();
    if (!library) return { memberNo: null };
    return this.getNextMemberNo(library.id);
  }
```

이어서, `signup()` 함수 위쪽의 `type SignupData` 를 찾으세요.

```typescript

  birthDate?: string;
  address?: string;

```

이렇게 바꿔주세요.


`signup()` 함수 안의 아래 부분을 찾으세요.

```typescript
    await this.prisma.user.create({
      data: {
        libraryId: library.id,
        loginId: data.loginId,
        passwordHash,
        name: data.name,
        phone: data.phone,

```

이렇게 바꿔주세요. (회원번호도 같이 저장하고, 혹시 그 사이 다른 사람이
같은 번호로 먼저 가입해버린 아주 드문 경우를 대비해서 오류 처리를
추가했어요.)

```typescript
    try {
      await this.prisma.user.create({
        data: {
          libraryId: library.id,
          loginId: data.loginId,
          passwordHash,
          name: data.name,
          phone: data.phone,
          email: data.email || undefined,
          birthDate: data.birthDate ? new Date(data.birthDate) : undefined,
          address: data.address || undefined,
          memberNo: data.memberNo || undefined,
          cardToken,
        },
      });
    } catch (e: any) {
      if (e.code === 'P2002') {
        throw new ConflictException(
          '처리 중 문제가 발생했습니다. 다시 시도해주세요.',
        );
      }
      throw e;
    }

    return { message: '회원가입이 완료되었습니다.' };
```

> 회원가입이 이 과정 중간에 실패하면(아이디 중복, 회원번호 충돌 등)
> `user.create` 자체가 실행되지 않으니, 미리 보여준 회원번호는 그냥
> 버려지고 DB에는 아무것도 저장되지 않아요. 다음에 회원가입 화면을 다시
> 열면 같은 계산 방식으로 그 번호가 다시 제시됩니다.

## 3. 확인하기 — 약 6분

1. 로그인 후 관리자 페이지에 처음 들어가면(또는 사이드바 "대시보드"
   클릭) "대시보드" 화면에 "(작업 중)" 문구만 나오는지 확인합니다.
2. 사이드바에 "목록" 위에 "대시보드" 메뉴가 보이고, 대시보드 화면에
   있을 때만 강조되는지 확인합니다.
3. 대시보드 화면 상단에 브레드크럼("대시보드")이 보이는지 확인합니다.
4. `/signup` 화면을 열면 회원번호 칸에 값이 자동으로 채워지고, 수정할
   수 없는(회색 배경) 상태인지 확인합니다.
5. 회원가입을 완료한 뒤 관리자 페이지 → 회원 목록에서 그 회원의
   회원번호가 저장돼 있는지 확인합니다.
6. 다시 `/signup` 화면을 열면 그 다음 번호로 올라가 있는지 확인합니다.
7. (선택) 일부러 이미 있는 아이디로 가입을 시도해서 실패시킨 뒤, 다시
   회원가입 화면을 열었을 때 회원번호가 그대로(건너뛰지 않고) 다시
   나오는지 확인합니다.

✅ 모두 확인되면 성공입니다! 🎉
