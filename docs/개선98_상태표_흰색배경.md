# 개선98: '상태' 표의 각 행 배경색을 흰색으로 변경

## 목표

'설정 → 목록 → 상태' 표에서 각 상태값이 나오는 줄(행)에 별도의 배경색이 지정되어 있지 않아서, 뒤쪽 페이지 바탕색(크림색)이 그대로 비쳐 보여 표가 눈에 잘 띄지 않았습니다. 이번 가이드는 표의 각 행에 흰색 배경을 명확히 지정해서, 표가 바탕색과 분리되어 잘 보이도록 합니다.

**참고(이번 가이드만 예외):** 이번에는 파일 전체가 아니라 딱 한 줄(표의 행 스타일을 정하는 부분)만 바뀌기 때문에, 지난번 안내드린 "파일 전체를 통째로 바꾸는 방식" 대신 이 한 줄만 찾아서 바꾸는 방식으로 안내드립니다. 코드 여러 곳이 함께 바뀌는 다음 가이드부터는 다시 파일 전체를 통째로 드리겠습니다.

---

## 1단계: 표 행에 흰색 배경 추가하기

**무엇을, 왜 바꾸나요:** `copy-options-settings-form.tsx` 파일에서 '상태' 표의 각 행(`<tr>`)을 그리는 부분에 `bg-white`(흰색 배경)를 추가합니다. 지금까지는 배경색이 따로 지정되지 않아 페이지의 크림색 바탕이 그대로 비쳐 보였는데, 이제는 각 행이 흰색으로 명확하게 채워집니다. 마우스를 올렸을 때 옅은 회색으로 바뀌는 동작(`hover:bg-neutral-50`)은 그대로 유지됩니다.

`frontend/src/components/copy-options-settings-form.tsx` 파일을 여세요.

아래 내용을 찾으세요.

```typescript
                      className="cursor-pointer border-t border-neutral-100 hover:bg-neutral-50"
```

이 내용을 아래 내용으로 바꿔주세요.

```typescript
                      className="cursor-pointer border-t border-neutral-100 bg-white hover:bg-neutral-50"
```

## 확인하기

1. `frontend` 서버를 재시작해 주세요.

3. 행 위에 마우스를 올렸을 때 옅은 회색으로 바뀌는 동작이 그대로 잘 되는지 확인해 주세요.
