# 개선90: '자료 종류'/'상태' 드롭다운 검색값도 굵게 표시하기

## 목표

개선89에서는 직접 글자를 입력하는 검색어(서명, 저자, 이름, 휴대폰번호 등)만 굵게 표시되도록 만들었습니다. 드롭다운으로 고르는 '자료 종류'(목록 메뉴)와 '상태'(회원 메뉴)는 글자를 직접 입력하는 게 아니라 정확히 하나의 값을 고르는 방식이라, 개선89의 `Highlight` 부품(부분 일치를 찾아 굵게 표시)이 적용되어 있지 않았습니다. 이 가이드는 이 두 항목도, 검색 결과 목록에서 그 값에 해당하는 칸 전체를 굵게 표시하도록 만듭니다.

---

## 1단계: '목록' 메뉴 — '자료 종류' 칸 굵게 표시하기

`frontend/src/app/admin/materials/list/page.tsx` 파일을 여세요.

아래 내용을 찾으세요.

```typescript
                    <td className="whitespace-nowrap px-4 py-2.5">
                      {lang === "ko" ? typeInfo?.nameKo ?? row.material.type : typeInfo?.nameEn ?? row.material.type}
                    </td>
```

이 내용을 아래 내용으로 바꿔주세요.

```typescript
                    <td className="whitespace-nowrap px-4 py-2.5">
                      {(() => {
                        const typeName =
                          lang === "ko" ? typeInfo?.nameKo ?? row.material.type : typeInfo?.nameEn ?? row.material.type;
                        // '자료 종류'는 드롭다운에서 정확히 하나를 고르는 방식이라, 그 종류로 검색한
                        // 상태라면(filters.type이 이 자료의 종류와 같다면) 칸 전체를 굵게 표시합니다.
                        return filters.type && filters.type === row.material.type ? (
                          <strong className="font-bold">{typeName}</strong>
                        ) : (
                          typeName
                        );
                      })()}
                    </td>
```

**설명:** '자료 종류'는 텍스트를 입력하는 게 아니라 드롭다운에서 하나를 고르는 것이라 "부분적으로 일치하는 글자"라는 개념이 없습니다. 대신 지금 적용된 검색 조건(`filters.type`)이 이 자료의 종류와 정확히 같을 때, 그 칸 전체를 굵게(`font-bold`) 표시하도록 했습니다.

---

## 2단계: '회원' 메뉴 — '상태' 칸 굵게 표시하기

`frontend/src/app/admin/members/page.tsx` 파일을 여세요.

아래 내용을 찾으세요.

```typescript
                <td className={`whitespace-nowrap px-4 py-2.5 font-semibold ${statusColorClass(row.status)}`}>
                  {t(`members.status.${row.status}`)}
                </td>
```

이 내용을 아래 내용으로 바꿔주세요.

```typescript
                <td
                  className={`whitespace-nowrap px-4 py-2.5 ${
                    filters.status && filters.status === row.status ? "font-bold" : "font-semibold"
                  } ${statusColorClass(row.status)}`}
                >
                  {t(`members.status.${row.status}`)}
                </td>
```

**설명:** '상태'도 드롭다운에서 정확히 하나를 고르는 방식입니다. 지금 적용된 검색 조건(`filters.status`)이 이 회원의 상태와 정확히 같을 때는 평소(`font-semibold`)보다 더 굵은 `font-bold`로 표시해서, 이 상태값으로 검색했다는 것이 눈에 띄게 했습니다. 상태로 검색하지 않았을 때는 지금까지와 똑같이 `font-semibold`로 보입니다.
