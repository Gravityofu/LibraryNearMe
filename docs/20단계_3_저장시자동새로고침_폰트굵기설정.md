# 20단계_3. 설정 저장 시 자동 새로고침 + 폰트 굵기(두께) 설정 추가

## 🎯 목표

이번엔 두 가지를 고칠게요.

**1) 설정 저장 후 자동 새로고침**

지금은 관리자 설정(도서관 탭, 디자인 탭)에서 "저장"을 눌러도 화면에 바로 반영되지 않는 항목들이 있어서, 눈으로 확인하려면 수동으로 새로고침을 해야 했어요. 이제 "저장"을 누르고 성공하면, 잠깐 저장 완료 메시지를 보여준 뒤 **자동으로 페이지가 새로고침**되도록 만들게요.

**2) 폰트 굵기(두께) 설정**

글꼴을 바꿔보니 어떤 글꼴은 얇아서 글자가 흐릿하게 보이는 경우가 있으셨죠. 그래서 디자인 탭에 **"글자 굵기"**를 고를 수 있는 항목을 추가해서, 보통(400) / 약간 굵게(500) / 중간 굵게(600) / 굵게(700) / 매우 굵게(800) 중에서 고를 수 있게 만들게요.

> 💡 참고로 구글 폰트(노토 산스, 나눔고딕, 나눔명조)는 우리가 미리 지정해둔 몇 가지 굵기만 인터넷에서 받아와요. 목록에 없는 굵기를 고르면 브라우저가 임의로 두껍게 흉내 내서 보여주는데(이걸 "가짜 굵게"라고 불러요), 진짜 그 굵기의 글꼴 모양은 아니어서 살짝 뭉개져 보일 수 있어요. Pretendard는 굵기를 자유자재로 표현할 수 있는 "가변 폰트"라 이런 문제가 없어요.

```
npx prisma migrate dev --name add_font_weight
```

## 3단계. 굵기 목록 정의하기

**파일**: `frontend/src/lib/fonts.ts`

파일 맨 아래, `getFontOption` 함수 다음에 이 코드를 추가해주세요.

**찾기:**

```typescript
// 저장된 key로 글꼴 정보를 찾아줍니다. 못 찾으면 Pretendard를 기본으로 돌려줘요.
export function getFontOption(key: string): FontOption {
  return FONT_OPTIONS.find((f) => f.key === key) || FONT_OPTIONS[0];
}
```

**바로 아래에 추가해주세요:**

```typescript
// 디자인 탭에서 고를 수 있는 글자 굵기 목록입니다.
export type FontWeightOption = { value: string; label: string };

export const FONT_WEIGHT_OPTIONS: FontWeightOption[] = [
  { value: "400", label: "보통 (400)" },
  { value: "500", label: "약간 굵게 (500)" },
  { value: "600", label: "중간 굵게 (600)" },
  { value: "700", label: "굵게 (700)" },
  { value: "800", label: "매우 굵게 (800)" },
];
```

이제 굵기도 실제로 적용되는 부분을 고쳐볼게요. 아래 코드를 찾아주세요.

**찾기:**

```tsx
  // 글꼴이 바뀔 때마다, 실제 화면에 그 글꼴을 적용합니다.
  useEffect(() => {
    const option = getFontOption(theme.fontFamily);
    const linkId = "dynamic-font-link";
    let linkEl = document.getElementById(linkId) as HTMLLinkElement | null;

    if (option.googleFontUrl) {
      // 구글 폰트가 필요한 경우, <link> 태그를 만들어서(또는 이미 있으면 주소만 바꿔서) 불러옵니다.
      if (!linkEl) {
        linkEl = document.createElement("link");
        linkEl.id = linkId;
        linkEl.rel = "stylesheet";
        document.head.appendChild(linkEl);
      }
      linkEl.href = option.googleFontUrl;
    } else if (linkEl) {
      // Pretendard나 시스템 폰트처럼 구글 폰트가 필요 없는 경우, 이전에 넣었던 링크를 지웁니다.
      linkEl.remove();
    }

    // Tailwind의 font-sans 클래스는 빌드할 때 값이 이미 고정되어버리기 때문에(=inline),
    // --font-sans 변수를 바꾸는 것만으로는 반영되지 않습니다.
    // 그래서 <body> 태그에 직접 글꼴을 지정해서 확실하게 덮어씁니다.
    document.body.style.fontFamily = option.stack;
  }, [theme.fontFamily]);
```

**이렇게 바꿔주세요:**


### 무슨 코드인가요?

- `setTimeout(() => window.location.reload(), 600)`: 저장이 성공하면 `notify(...)`로 "저장되었습니다" 메시지를 먼저 보여주고, 0.6초 뒤에 `window.location.reload()`로 페이지를 통째로 새로고침해요. 메시지를 잠깐이라도 보여준 뒤 새로고침해야, 저장이 잘 됐다는 걸 사용자가 인지할 수 있어요.
- 굵기 선택 박스는 글꼴 선택 박스와 똑같은 구조예요. `FONT_WEIGHT_OPTIONS`에서 고른 값이 `fontWeight` 상태에 들어가고, 저장할 때 같이 전송돼요.

## 6단계. '도서관' 탭도 저장 후 자동 새로고침 되게 하기

## ✅ 확인하기

1. 백엔드에서 `npx prisma migrate dev --name add_font_weight`를 실행했는지 확인해주세요.
2. 백엔드, 프론트엔드를 재시작해주세요.
3. 관리자 페이지 → 설정 → 디자인 탭에서 "글자 굵기" 선택 박스가 보이는지 확인해주세요.
4. 색상이나 글꼴, 굵기를 아무거나 바꾸고 "저장"을 눌러보세요. "저장되었습니다" 메시지가 잠깐 보인 뒤 페이지가 자동으로 새로고침되면서 바뀐 내용이 바로 반영되는지 확인해주세요.
5. 도서관 탭에서도 이름이나 로고 등을 바꾸고 저장했을 때 자동으로 새로고침되는지 확인해주세요.
6. 굵기를 "매우 굵게 (800)"로 바꿔서 글자가 눈에 띄게 두꺼워지는지 확인해주세요.
