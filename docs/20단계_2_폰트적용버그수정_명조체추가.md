# 20단계_2. 글꼴 적용 버그 수정 + 명조체 폰트 추가

## 🎯 목표

지난번(20단계_1)에 만든 글꼴 변경 기능이 실제로는 화면에 반영되지 않는 문제를 고치고, 눈에 띄게 비교해볼 수 있도록 **명조체(세리프) 글꼴**을 하나 추가할게요.

### 왜 글꼴이 안 바뀌었나요?

우리 프로젝트의 `globals.css`를 보면 이런 코드가 있어요.

```css
@theme inline {
  --font-sans: "Pretendard Variable", Pretendard, ...;
  ...
}
```

여기서 `@theme inline`의 `inline`이라는 단어가 핵심이에요. Tailwind CSS(우리가 쓰는 버전인 v4)는 이 `inline` 표시가 있으면, `font-sans`라는 클래스를 만들 때 `--font-sans` 변수를 **그대로 참조하는 게 아니라, 빌드할 때 값을 통째로 박아 넣어요.** 즉 실제로 사이트에 적용되는 CSS는

```css
/* 우리가 기대한 모습 (변수 참조) */
.font-sans { font-family: var(--font-sans); }

/* 실제로 만들어지는 모습 (값이 그대로 박힘) */
.font-sans { font-family: "Pretendard Variable", Pretendard, ...; }
```

이런 차이가 있어서, 자바스크립트로 `--font-sans` 변수 값을 아무리 바꿔도 이미 굳어진(inline된) CSS에는 영향을 주지 못했던 거예요.

### 어떻게 고치나요?

Tailwind가 만들어주는 클래스에 의존하지 않고, **`<body>` 태그에 직접 `style="font-family: ..."`을 자바스크립트로 지정**하는 방식으로 바꿀게요. `style` 속성으로 직접 지정한 값은 다른 어떤 CSS 클래스보다도 우선순위가 높기 때문에, 이 방법이 가장 확실해요.

## 1단계. 명조체 글꼴 추가하기

**파일**: `frontend/src/lib/fonts.ts`

**찾기:**

```typescript
  {
    key: "system",
    label: "시스템 기본 글꼴",
    stack: '-apple-system, BlinkMacSystemFont, system-ui, "Malgun Gothic", sans-serif',
    googleFontUrl: null,
  },
];
```

**이렇게 바꿔주세요:**

```typescript
  {
    key: "system",
    label: "시스템 기본 글꼴",
    stack: '-apple-system, BlinkMacSystemFont, system-ui, "Malgun Gothic", sans-serif',
    googleFontUrl: null,
  },
  {
    key: "nanum-myeongjo",
    label: "나눔명조 (명조체)",
    stack: '"Nanum Myeongjo", serif',
    googleFontUrl: "https://fonts.googleapis.com/css2?family=Nanum+Myeongjo:wght@400;700;800&display=swap",
  },
];
```

> 💡 "나눔명조"는 네이버가 무료로 배포하는 대표적인 한글 명조체(붓글씨처럼 획 끝에 삐침이 있는 서체)예요. 다른 글꼴들과 생김새 차이가 확실해서 비교 테스트하기 좋아요.

## 2단계. 글꼴을 `<body>`에 직접 적용하도록 수정하기

**파일**: `frontend/src/components/theme-provider.tsx`

**찾기:**

```tsx
    // 사이트 전체에서 쓰는 --font-sans 값을 선택한 글꼴로 바꿉니다.
    document.documentElement.style.setProperty("--font-sans", option.stack);
```

**이렇게 바꿔주세요:**

```tsx
    // Tailwind의 font-sans 클래스는 빌드할 때 값이 이미 고정되어버리기 때문에(=inline),
    // --font-sans 변수를 바꾸는 것만으로는 반영되지 않습니다.
    // 그래서 <body> 태그에 직접 글꼴을 지정해서 확실하게 덮어씁니다.
    document.body.style.fontFamily = option.stack;
```

### 무슨 코드인가요?

`document.body.style.fontFamily = ...`는 `<body>` 태그에 `style="font-family: ..."`을 직접 써넣는 것과 같아요. `style` 속성으로 직접 준 값은 CSS 클래스(`font-sans` 같은)보다 항상 우선순위가 높기 때문에, Tailwind가 만든 클래스가 뭐라고 하든 상관없이 이 값이 그대로 적용돼요.

## ✅ 확인하기

1. 프론트엔드를 재시작해주세요 (`npm run dev`를 껐다 다시 켜주시면 새 글꼴 목록이 확실히 반영돼요).
2. 관리자 페이지 → 설정 → 디자인 탭 → 글꼴 선택 박스에서 **"나눔명조 (명조체)"**를 선택하고 저장해주세요.
3. 사이트 전체 글자 모양이 확 바뀌는지 확인해주세요. (획 끝이 붓글씨처럼 삐치는 느낌이 나면 성공이에요.)
4. 다른 글꼴들(노토 산스, 나눔고딕, 시스템 기본)로도 바꿔보면서 이번엔 진짜로 화면이 바뀌는지 확인해주세요.
5. 다시 "Pretendard (기본)"으로 돌려서 저장하면 원래대로 돌아오는지 확인해주세요.
