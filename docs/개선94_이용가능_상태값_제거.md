# 개선94: 실물 자료 기본 상태값 '이용가능' → '대출가능'으로 통일

## 목표

새 실물 자료(`Copy`)를 등록할 때 상태값을 지정하지 않으면 데이터베이스 기본값으로 `'이용가능'`이라는 문자열이 들어가도록 되어 있었습니다. 하지만 우리 시스템이 실제로 쓰는 상태값은 `'대출가능'`, `'대출중'`, `'예약보관중'`, `'보수중'`, `'제적'`뿐이고, `'이용가능'`은 어디에서도 쓰지 않는 값입니다. 이번 가이드는 이 기본값을 `'대출가능'`으로 바꾸고, 혹시 이미 `'이용가능'`으로 등록되어 있는 실물 자료가 있다면 그것도 자동으로 `'대출가능'`으로 고쳐지도록 만듭니다.

---

## 1단계: 데이터베이스 기본값 고치기

`backend/prisma/schema.prisma` 파일을 여세요.

`model Copy {` 안에서 아래 내용을 찾으세요.

```
  status         String     @default("이용가능")
```

이 내용을 아래 내용으로 바꿔주세요.

```
  status         String     @default("대출가능")
```

**설명:** 실물 자료를 등록할 때 상태값을 아예 지정하지 않으면 자동으로 들어가는 값을, 우리 시스템이 실제로 쓰는 값인 `'대출가능'`으로 바꿨습니다.

---

## 2단계: 데이터베이스에 실제로 반영하기

터미널에서 아래 명령어를 순서대로 입력하세요.

```
cd C:\projects\LibraryNearMe\backend
npx prisma migrate dev --name change_copy_default_status
```

중간에 이름을 물어보면 그대로 Enter를 눌러 진행하시면 됩니다.

**참고:** 이 마이그레이션은 앞으로 새로 등록되는 자료에만 영향을 줍니다. 이미 `'이용가능'`으로 저장되어 있는 기존 자료는 3단계에서 자동으로 고쳐집니다.

---

## 3단계: 이미 '이용가능'으로 저장된 기존 자료도 자동으로 고쳐지게 하기

`backend/src/settings/copy-options.service.ts` 파일을 여세요.

아래 내용을 찾으세요.

```typescript
const LEGACY_STATUS_MAP: Record<string, string> = {
  AVAILABLE: '대출가능',
  ON_LOAN: '대출중',
  RESERVED: '예약보관중',
  REPAIR: '보수중',
  WITHDRAWN: '제적',
};
```

이 내용을 아래 내용으로 바꿔주세요.

```typescript
const LEGACY_STATUS_MAP: Record<string, string> = {
  이용가능: '대출가능',
  AVAILABLE: '대출가능',
  ON_LOAN: '대출중',
  RESERVED: '예약보관중',
  REPAIR: '보수중',
  WITHDRAWN: '제적',
};
```

**설명:** 이 표(`LEGACY_STATUS_MAP`)는 원래 "예전에 쓰던 영문 상태 코드(AVAILABLE 등)를 지금 쓰는 한글 값으로 딱 한 번 자동으로 바꿔주는" 용도로 만들어져 있었습니다. 여기에 `'이용가능' → '대출가능'` 규칙을 하나 추가했습니다. 이렇게 하면 '목록' 화면을 열 때(정확히는 상태 목록을 처음부터 다시 만드는 상황일 때) `status`가 `'이용가능'`으로 되어 있는 기존 자료들이 자동으로 `'대출가능'`으로 바뀝니다. 별도로 데이터베이스를 직접 수정하실 필요는 없습니다.

**참고:** 이 자동 변환은 도서관의 상태 목록(`CopyOption`)이 하나도 없는 상태에서 '목록' 화면을 처음 열 때만 실행되는 코드라서, 이미 상태 목록을 만들어서 쓰고 계신 도서관이라면(즉 이미 개선80을 적용해서 정상적으로 쓰고 계셨다면) 이 변환이 실행되지 않을 수 있습니다. 확인하기의 3번 항목으로 실제로 `'이용가능'` 상태인 자료가 남아있는지 확인해 주시고, 남아있다면 알려주세요 — 그 경우에는 이미 등록된 자료를 한 번에 고쳐주는 별도 코드를 추가하는 가이드를 만들어드리겠습니다.

---

## 확인하기

1. `backend` 서버를 재시작해 주세요.
2. '목록' 메뉴에서 새 실물 자료를 하나 등록해 보세요(상태값을 따로 고르지 않고 등록할 수 있는 경우). 등록된 자료의 상태가 `'대출가능'`으로 나오는지 확인해 주세요.
3. 데이터베이스 도구(예: Prisma Studio, `npx prisma studio`)나 '목록' 화면의 상태별 검색 기능을 이용해서, `status`가 `'이용가능'`으로 남아있는 자료가 있는지 확인해 주세요. 남아있다면 저에게 알려주세요.
