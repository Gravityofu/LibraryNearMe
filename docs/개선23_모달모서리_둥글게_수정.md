# 개선23. 모달 모서리 둥글게 처리하기 (+ 앞으로의 GitHub 안내 방식 변경)

## 🎯 목표

실물 자료 등록 모달에서 왼쪽 모서리는 둥근데 오른쪽은 스크롤바 때문에 직각으로 보이는 문제를 고칠게요.

### 왜 이런 문제가 생겼나요?

지금 모달 상자는 이렇게 되어 있어요.

```tsx
<div className="max-h-[85vh] w-full max-w-md overflow-auto rounded-xl bg-white p-6 shadow-xl">
```

`rounded-xl`(둥근 모서리)과 `overflow-auto`(내용이 넘치면 스크롤)가 **같은 칸**에 같이 붙어있다 보니, 브라우저가 스크롤바를 그릴 때 오른쪽 가장자리에 딱 붙여서 그려버려서 둥근 모서리 부분을 스크롤바가 가려버리는 문제가 생겨요.

### 어떻게 고치나요?

박스를 두 겹으로 나눌게요.

- **바깥 상자**: 둥근 모서리(`rounded-xl`) + `overflow-hidden`(넘치는 건 모양대로 잘라냄)만 담당
- **안쪽 상자**: 실제 스크롤(`overflow-y-auto`)과 여백(padding)을 담당

이렇게 하면 스크롤바는 안쪽 상자 안에서만 움직이고, 바깥 상자가 모서리를 둥글게 잘라주기 때문에 스크롤바가 있어도 네 모서리가 전부 둥글게 유지돼요.

> 💡 이제부터 스크롤이 있는 모달을 새로 만들 때는 항상 이 "바깥 상자(모서리 담당) + 안쪽 상자(스크롤 담당)" 두 겹 구조로 만들게요.

## 수정하기

**파일**: `frontend/src/app/admin/materials/copies/page.tsx`

**찾기:**

```tsx
          <div
            className="max-h-[85vh] w-full max-w-md overflow-auto rounded-xl bg-white p-6 shadow-xl"
            onClick={(e) => e.stopPropagation()}
          >
            <div className="mb-3 flex items-center justify-between">
```

**이렇게 바꿔주세요:**

```tsx
          <div
            className="w-full max-w-md overflow-hidden rounded-xl bg-white shadow-xl"
            onClick={(e) => e.stopPropagation()}
          >
          <div className="max-h-[85vh] overflow-y-auto p-6">
            <div className="mb-3 flex items-center justify-between">
```

이제 이 상자를 닫는 부분도 짝을 맞춰서 `</div>`를 하나 더 추가해야 해요. 아래 코드를 찾아주세요.

**찾기:**

```tsx
            <div className="mt-4">
              <ThemedButton
                preset="버튼1"
                onClick={selectedCopyId ? handleUpdateCopy : handleAddCopy}
                className="w-full"
              >
                {t("materials.copies.save")}
              </ThemedButton>
            </div>
          </div>
        </div>
      )}
```

**이렇게 바꿔주세요:**

```tsx
            <div className="mt-4">
              <ThemedButton
                preset="버튼1"
                onClick={selectedCopyId ? handleUpdateCopy : handleAddCopy}
                className="w-full"
              >
                {t("materials.copies.save")}
              </ThemedButton>
            </div>
          </div>
          </div>
        </div>
      )}
```

### 무슨 코드인가요?

- 바깥 `<div>`: `overflow-hidden rounded-xl`만 갖고 있어요. 이 상자 자체는 스크롤이 생기지 않고, 안에 있는 내용을 자기 모양(둥근 사각형)대로 잘라내는 역할만 해요.
- 안쪽 `<div>`: `max-h-[85vh] overflow-y-auto p-6`을 가져요. 실제로 내용이 길어지면 스크롤이 생기는 건 이 안쪽 상자예요. 스크롤바가 생겨도 바깥 상자의 둥근 모서리 안쪽에서만 보이기 때문에 모서리가 잘려 보이지 않아요.
- `<div>` 태그 개수가 하나 늘어난 만큼, 닫는 `</div>`도 하나 더 늘어난 걸 확인해주세요. (들여쓰기가 조금 헷갈릴 수 있는데, 위에 적어드린 대로 그대로 넣어주시면 돼요.)
