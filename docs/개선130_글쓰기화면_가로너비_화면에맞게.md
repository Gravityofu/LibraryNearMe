# 개선130 - 게시판 글쓰기/수정 화면의 제목·내용 가로 길이를 화면에 맞게 수정

## 목표

게시판 글쓰기/수정 화면에서 '제목', '내용' 등 입력 영역의 가로 길이가 `max-w-3xl`(약 768px)로 좁게 고정되어 있던 것을, 화면 크기에 맞춰 넓게 쓸 수 있도록 바꿉니다.

---

## 1단계: `write/page.tsx` 수정하기

`frontend/src/app/admin/boards/write/page.tsx` 파일을 엽니다.

찾기:
```tsx
      <div className="flex max-w-3xl flex-col gap-4">
```

교체:
```tsx
      <div className="flex w-full flex-col gap-4">
```

저장합니다. 이게 전부입니다.

---

## 확인하기

1. 프론트엔드 서버를 재시작(또는 저장 시 자동 반영)합니다.
2. 아무 게시판에서나 '+ 글쓰기'를 열어봅니다. 제목 입력란과 에디터가 화면 너비에 맞게 넓게 보이는지 확인합니다.
3. 브라우저 창 크기를 줄이거나 늘려보면서, 화면 크기에 따라 자연스럽게 너비가 조절되는지 확인합니다.
4. '자료를 신청합니다' 게시판처럼 타이틀/자료 종류/저자 입력란이 추가로 있는 화면도 넓게 잘 보이는지 확인합니다.
