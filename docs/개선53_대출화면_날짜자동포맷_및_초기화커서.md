# 개선 53: 대출일 직접 입력 시 자동으로 날짜 형식 만들기 + '초기화' 시 커서 이동

## 목표

개선52에서 대출/반납일을 직접 타이핑할 수 있게 했는데, `21213113`처럼 아무 숫자나 그대로 입력되는 문제가 있었습니다. 이번에는 그 칸을 클릭하면 안에 있던 값이 전체 선택되고, 숫자만 입력해도 자동으로 `2014-02-12`처럼 하이픈(`-`)이 들어간 날짜 형식으로 바뀌도록 고칩니다. (예: `20140212`라고 타이핑하면 화면에는 `2014-02-12`로 보입니다.)

그리고 회원을 검색한 뒤 '초기화' 버튼을 누르면, 커서가 자동으로 '회원 검색' 입력폼으로 이동하게 해서 바로 이어서 다음 회원을 검색할 수 있게 합니다.

### 1-1. 숫자를 날짜 형식으로 바꿔주는 도구 함수 추가하기

아래 부분을 찾으세요.

```tsx
function todayStr() {
  return new Date().toISOString().slice(0, 10);
}
```

이렇게 바꿔주세요.

```tsx
function todayStr() {
  return new Date().toISOString().slice(0, 10);
}

// 사용자가 입력한 글자에서 숫자만 뽑아, "YYYY-MM-DD" 형태로 하이픈을 자동으로 넣어줍니다.
// 예: "20140212" -> "2014-02-12", "202402" -> "2024-02"
function formatDateInput(raw: string) {
  const digits = raw.replace(/\D/g, "").slice(0, 8);
  if (digits.length <= 4) return digits;
  if (digits.length <= 6) return `${digits.slice(0, 4)}-${digits.slice(4)}`;
  return `${digits.slice(0, 4)}-${digits.slice(4, 6)}-${digits.slice(6)}`;
}
```

### 1-5. 대출일 직접 입력 칸에 자동 포맷 + 클릭 시 전체 선택 적용하기

아래 부분을 찾으세요.

```tsx
                <input
                  type="text"
                  value={loanDateStr}
                  onChange={(e) => setLoanDateStr(e.target.value)}
                  placeholder={t("loans.dateOverride.placeholder")}
                  className="w-32 rounded-lg border border-neutral-200 px-3 py-2 text-sm"
                />
```

이렇게 바꿔주세요.

```tsx
                <input
                  type="text"
                  value={loanDateStr}
                  onChange={(e) => setLoanDateStr(formatDateInput(e.target.value))}
                  onFocus={(e) => e.target.select()}
                  placeholder={t("loans.dateOverride.placeholder")}
                  className="w-32 rounded-lg border border-neutral-200 px-3 py-2 text-sm"
                />
```

(`onChange`에서 이제 입력값을 그대로 저장하지 않고, 먼저 `formatDateInput`을 거쳐서 숫자만 남기고 자동으로 하이픈을 넣은 값을 저장합니다. `onFocus`는 이 칸을 클릭(또는 Tab으로 이동)해서 커서가 들어갈 때, 안에 있던 값 전체를 선택 상태로 만들어줍니다. 그래서 바로 숫자를 타이핑하면 기존 값이 지워지고 새 값으로 바뀝니다.)

파일을 저장하세요.
