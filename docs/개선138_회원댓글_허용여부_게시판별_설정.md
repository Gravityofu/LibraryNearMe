# 개선138: 게시판별로 '회원 댓글' 허용 여부 설정하기

## 목표

지금은 로그인한 회원이면 어떤 게시판이든 무조건 댓글을 쓸 수 있게 되어 있습니다. 이번 가이드는 다른 세 항목("회원 글쓰기", "비로그인 글쓰기", "비로그인 댓글")과 마찬가지로, **"회원 댓글"**이라는 항목을 게시판마다 켜고 끌 수 있도록 만듭니다. 이 항목을 끄면, 로그인한 회원이라도 그 게시판에는 댓글을 쓸 수 없습니다. (관리자는 이 설정과 상관없이 항상 관리자 페이지에서 댓글을 지울 수 있습니다.)

## 1단계: 데이터베이스 — 게시판에 '회원 댓글 허용' 항목 추가

`backend/prisma/schema.prisma` 파일을 여세요.

아래 내용을 찾으세요.

```prisma
  allowMemberWrite  Boolean  @default(false)  // 회원이 글을 쓸 수 있는 게시판인지 (열린 게시판, 자료를 신청합니다만 true)
  allowGuestWrite   Boolean  @default(false)  // allowMemberWrite가 true일 때만 의미 있음: 비회원(비로그인)도 글을 쓸 수 있는지
  allowGuestComment Boolean  @default(false)  // 이 게시판의 댓글을 비회원(비로그인)도 쓸 수 있는지
```

이 내용을 아래 내용으로 바꿔주세요.

```prisma
  allowMemberWrite   Boolean  @default(false)  // 회원이 글을 쓸 수 있는 게시판인지 (열린 게시판, 자료를 신청합니다만 true)
  allowGuestWrite    Boolean  @default(false)  // allowMemberWrite가 true일 때만 의미 있음: 비회원(비로그인)도 글을 쓸 수 있는지
  allowMemberComment Boolean  @default(true)   // 로그인한 회원이 이 게시판에 댓글을 쓸 수 있는지
  allowGuestComment  Boolean  @default(false)  // 이 게시판의 댓글을 비회원(비로그인)도 쓸 수 있는지
```

**설명:** 기본값을 `true`로 둔 이유는, 지금까지 회원 댓글이 항상 가능했던 동작을 그대로 유지하기 위해서입니다. 즉 이 가이드를 적용해도 별도로 끄지 않는 이상 기존과 똑같이 동작하고, 필요할 때만 끌 수 있게 됩니다.

터미널(명령 프롬프트)을 여시고, 아래 명령을 순서대로 입력해 주세요.

**주의:** 이 부분은 `if`/`else`의 짝이 맞아야 합니다. 원래 있던 `if (!commentGuestName.trim()) { ... }`부터 그 아래 `if (commentGuestPassword.length < 4) { ... }`까지는 그대로 두시되, 전체가 새로 추가한 `else { ... }` 블록 **안에** 들어가야 합니다. 아래는 이 함수의 앞부분 전체 모습입니다. 헷갈리시면 아래 내용으로 통째로 비교해서 맞춰주세요.

```typescript
  async function handleAddComment() {
    if (!commentContent.trim()) {
      return;
    }
    if (isLoggedIn) {
      if (!post?.board.allowMemberComment) {
        notify("❌ " + t("boards.public.comments.memberBlocked"), "error");
        return;
      }
    } else {
      if (!post?.board.allowGuestComment) {
        notify("❌ " + t("boards.public.comments.loginRequired"), "error");
        return;
      }
      if (!commentGuestName.trim()) {
        notify("❌ " + t("boards.public.write.guestNameRequired"), "error");
        return;
      }
      if (commentGuestPassword.length < 4) {
        notify("❌ " + t("boards.public.write.guestPasswordRequired"), "error");
        return;
      }
    }

    const body: any = { postId: id, content: commentContent };
    if (!isLoggedIn) {
      body.guestName = commentGuestName;
      body.guestPassword = commentGuestPassword;
    }

    const res = await fetch(`${API_URL}/public/comments`, {
      method: "POST",
      headers: {
        "Content-Type": "application/json",
        ...(isLoggedIn ? { Authorization: `Bearer ${token}` } : {}),
      },
      body: JSON.stringify(body),
    });
    if (res.ok) {
      setCommentContent("");
      setCommentGuestName("");
      setCommentGuestPassword("");
      loadComments();
    } else {
      const data = await res.json().catch(() => null);
      notify("❌ " + (data?.message || t("boards.public.comments.saveFail")), "error");
    }
  }
```

**설명:** 로그인한 회원이면 `allowMemberComment`, 로그인하지 않았다면 `allowGuestComment` 값을 확인해서, 허용되지 않으면 알맞은 안내 문구(각각 "회원 댓글을 허용하지 않습니다" 또는 "로그인이 필요합니다")를 보여주고, 허용되면 지금처럼 댓글 입력창을 보여줍니다. `canComment`를 먼저 계산해두는 이유는, `A ? B : C ? D : E`처럼 물음표(`?`)를 두 번 겹쳐 쓰면 괄호가 어디서 어디까지인지 헷갈려서 실수하기 쉽기 때문입니다.
