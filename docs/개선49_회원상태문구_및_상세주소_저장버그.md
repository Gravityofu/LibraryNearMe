# 개선 49: 회원 상태 문구 변경 + 상세 주소 저장 버그 수정

## 목표

회원 상태 '활성'을 '대출가능'으로 바꿉니다.

그리고 상세 주소가 저장되지 않는 문제를 고칩니다. 원인은 지금까지 도로명 주소와 상세 주소를 합쳐서 하나의 글자값(`address`)으로만 저장하고 있었기 때문입니다. 새로 등록할 때는 합쳐진 값이 저장은 되지만, 나중에 그 회원을 다시 수정하려고 열면 합쳐졌던 전체 주소가 통째로 "도로명 주소" 칸에 들어가고 "상세 주소" 칸은 항상 빈 칸으로 초기화되어서, 이미 입력했던 상세 주소가 사라진 것처럼 보이는 문제였습니다. 이번에 상세 주소를 위한 칸을 데이터베이스에 따로 만들어서, 도로명 주소와 상세 주소가 각각 정확히 저장되고 다시 열었을 때도 각자 제자리에 그대로 나오도록 고칩니다.

## 1. 데이터베이스에 상세 주소 칸 추가하기: `schema.prisma`

`C:\projects\LibraryNearMe\backend\prisma\schema.prisma` 파일을 여세요.

`User` 모델 안에서 아래 부분을 찾으세요.

```prisma
  address       String?                       // 주소 (선택)
  postalCode    String?                       // 우편번호 (선택)
```

이렇게 바꿔주세요.

```prisma
  address       String?                       // 주소 (도로명 주소, 선택)
  addressDetail String?                       // 상세 주소 (동/호수 등, 선택)
  postalCode    String?                       // 우편번호 (선택)
```

파일을 저장하세요.

터미널에서 아래 명령어를 순서대로 입력하세요.

```
cd C:\projects\LibraryNearMe\backend
npx prisma migrate dev --name add_address_detail
```

명령어가 끝나면 정상적으로 실행되었는지 확인하세요.
