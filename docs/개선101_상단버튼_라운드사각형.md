# 개선101: 상단 메뉴 버튼을 알약(pill) 모양에서 라운드 사각형으로 변경

## 목표

첨부해주신 그림처럼, 지금은 양 끝이 완전히 둥근 '알약' 모양(`rounded-full`)으로 되어 있는 상단 메뉴 버튼들을, 모서리만 둥근 사각형(`rounded-lg`) 모양으로 바꿉니다. 대상은 아래 네 곳입니다.

- '예약' 탭 상단의 5개 메뉴 버튼 (개선100에서 만든 것)
- '목록' 메뉴 상단의 '상세 검색' / '등록번호 검색' 버튼
- '회원' 메뉴 상단의 '상세 검색' 버튼
- '대출이력' 탭 상단의 '상세 검색' 버튼

이번에는 파일마다 한두 줄의 스타일(모양)만 바뀌기 때문에, 지난 개선98과 같은 방식으로 그 줄들만 찾아서 바꾸는 방식으로 안내드립니다.

---

## 1단계: '목록' 메뉴 상단 버튼 (상세 검색 / 등록번호 검색)

`frontend/src/app/admin/materials/list/page.tsx` 파일을 여세요.

아래 내용이 이 파일에 **두 번** 나옵니다(하나는 '상세 검색' 버튼, 하나는 '등록번호 검색' 버튼). 에디터의 "찾아서 모두 바꾸기(Find & Replace All)"를 이용해 두 곳을 한 번에 바꿔주세요.

**찾기:**
```
rounded-full border border-neutral-200 bg-white px-4 py-2 text-sm font-medium text-neutral-700 shadow-sm hover:bg-neutral-50
```

**바꾸기:**
```
rounded-lg border border-neutral-200 bg-white px-4 py-2 text-sm font-medium text-neutral-700 shadow-sm hover:bg-neutral-50
```

## 2단계: '회원' 메뉴 상단 버튼 (상세 검색)

`frontend/src/app/admin/members/page.tsx` 파일을 여세요.

아래 내용을 찾으세요. (이 파일에는 비슷하게 생긴 작은 버튼이 하나 더 있는데(주소 찾기 버튼), 그 버튼은 크기가 더 작아서(`px-3 py-1 text-xs`) 아래 내용과는 다릅니다. 반드시 아래 내용과 **정확히 일치하는** 줄만 바꿔주세요.)

```typescript
          className="cursor-pointer rounded-full border border-neutral-200 bg-white px-4 py-2 text-sm font-medium text-neutral-700 shadow-sm hover:bg-neutral-50"
```

이 내용을 아래 내용으로 바꿔주세요.

```typescript
          className="cursor-pointer rounded-lg border border-neutral-200 bg-white px-4 py-2 text-sm font-medium text-neutral-700 shadow-sm hover:bg-neutral-50"
```

## 확인하기

1. `frontend` 서버를 재시작해 주세요.
2. '목록' 메뉴 상단의 '상세 검색' / '등록번호 검색' 버튼이 라운드 사각형으로 보이는지 확인해 주세요.
3. '회원' 메뉴 상단의 '상세 검색' 버튼이 라운드 사각형으로 보이는지 확인해 주세요.
4. '대출/반납 → 대출이력' 탭 상단의 '상세 검색' 버튼이 라운드 사각형으로 보이는지 확인해 주세요.
5. '대출/반납 → 예약' 탭 상단의 5개 메뉴 버튼이 라운드 사각형으로 보이는지, 선택했을 때 진회색으로 채워지는 모양은 그대로인지 확인해 주세요.
6. '회원' 메뉴의 '주소 찾기' 버튼처럼 이번에 바꾸지 않은 다른 알약 모양 버튼들은 원래대로 잘 남아있는지 확인해 주세요.
