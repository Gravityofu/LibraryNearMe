# 개선22. 실물 등록 페이지 - 레이아웃 개편 및 입력 폼 모달화

## 🎯 목표

말씀하신 대로 화면 구성을 크게 바꿀게요. 가능합니다!

**전 (현재)**

```
┌─────────────────┬─────────────────┐
│ KOMARC 정보       │                   │
├─────────────────┤  실물 등록/수정 폼   │
│ 실물 자료 목록     │                   │
└─────────────────┴─────────────────┘
```

**후 (변경할 모습)**

```
┌─────────────────┬─────────────────┐
│                   │                   │
│   KOMARC 정보     │   실물 자료 목록    │
│                   │                   │
└─────────────────┴─────────────────┘

  '새 실물 자료 등록' 또는 기존 자료 행을 클릭하면 ↓

        ┌───────────────────┐
        │   (모달) 실물 자료 추가│
        │   ...입력폼...        │
        └───────────────────┘
```

- 왼쪽 화면: KOMARC 정보만
- 오른쪽 화면: 실물 자료 목록 표만 (지금 하던 대로 그대로 작동)
- 실물 자료 입력/수정 폼: 모달 창으로 분리
  - "새 실물 자료 등록" 행 클릭 → 모달 제목 **"실물 자료 추가"**
  - 기존 자료 행 클릭 → 모달 제목 "실물 등록자료 수정" (기존과 동일)
- 더 이상 필요 없는 것: 입력 폼 테두리 색(검정/도서관색) 로직 → 통째로 삭제

import { Suspense, useEffect, useState } from "react";

import Link from "next/link";

import { useNotify } from "@/components/notify-provider";
import { useI18n } from "@/components/language-provider";
import MarcEditor, { DEFAULT_FIELDS, MarcField } from "@/components/marc-editor";
import AdminBackButton from "@/components/admin-back-button";

const API_URL = process.env.NEXT_PUBLIC_API_URL ?? "http://localhost:3001";

type CopyItem = {

  callNumber?: string;
  authorCode?: string;
  specialCode?: string;
  shelfNo?: string;
  location?: string;
  memo?: string;
  status: string;
  volume?: string;
  copyNumber?: string;
};

  title: string;
  creator?: string;
  publisher?: string;
  pubYear?: string;
  classNumber?: string;

  registrationNo: "",
  callNumber: "",
  authorCode: "",
  specialCode: "",
  shelfNo: "",
  location: "",
  memo: "",
  status: "AVAILABLE",
  volume: "",
  copyNumber: "",
};

const STATUS_OPTIONS = [
  { value: "AVAILABLE", labelKey: "materials.copies.status.available" },
  { value: "ON_LOAN", labelKey: "materials.copies.status.onLoan" },
  { value: "RESERVED", labelKey: "materials.copies.status.reserved" },
  { value: "REPAIR", labelKey: "materials.copies.status.repair" },
  { value: "LOST", labelKey: "materials.copies.status.lost" },
  { value: "WITHDRAWN", labelKey: "materials.copies.status.withdrawn" },
];

// MARC 목록에서 090 태그의 ▼b(저자기호)를 찾아옵니다.
function findAuthorCode(marc?: { tag: string; value: string }[]) {
  const field = marc?.find((f) => f.tag === "090");
  if (!field) return "";
  const part = field.value.split("▼").find((p) => p.startsWith("b"));
  return part ? part.slice(1).trim() : "";
}

// 가장 최근 등록번호의 다음 숫자를 계산합니다. (등록번호는 1,2,3... 순수 숫자입니다.)
function computeNextRegNo(latest: string | null): string {
  if (!latest) return "1";
  const n = parseInt(latest, 10);
  if (Number.isNaN(n)) return "";
  return String(n + 1);
}

function CopiesPageInner() {
  const searchParams = useSearchParams();
  const materialId = searchParams.get("materialId");

  const { notify } = useNotify();
  const { t } = useI18n();

  const [material, setMaterial] = useState<MaterialFull | null>(null);

  const [selectedCopyId, setSelectedCopyId] = useState<number | null>(null);
  const [latestRegNo, setLatestRegNo] = useState<string | null>(null);
  const [primaryColor, setPrimaryColor] = useState("#2563eb");
  const [showModal, setShowModal] = useState(false);

  async function loadMaterial(id: string) {
    const token = localStorage.getItem("token");
    if (!token) return;
    const res = await fetch(`${API_URL}/materials/${id}`, {
      headers: { Authorization: `Bearer ${token}` },
    });
    if (res.ok) {
      const data = await res.json();
      setMaterial(data);
      setMarc(Array.isArray(data.marc) && data.marc.length > 0 ? data.marc : DEFAULT_FIELDS);

      setForm((prev) => ({ ...EMPTY_FORM, authorCode: findAuthorCode(data.marc), registrationNo: prev.registrationNo }));
      setSelectedCopyId(null);

    } else {
      notify("❌ " + t("materials.copies.loadFail"), "error");
    }

  async function refreshMaterial(id: number) {
    const token = localStorage.getItem("token");
    if (!token) return;
    const res = await fetch(`${API_URL}/materials/${id}`, {
      headers: { Authorization: `Bearer ${token}` },
    });
    if (res.ok) {
      setMaterial(await res.json());
    }

    if (!token) return;

  );

### 무슨 코드인가요? (바뀐 부분 위주로)

- `showModal` 상태를 새로 만들어서, 이 값이 `true`일 때만 화면 맨 아래에 입력 폼 모달이 나타나요.
- `openAddModal()`: '새 실물 자료 등록' 행을 클릭하면 실행돼요. 폼을 비우고(`resetForm()`) 모달을 엽니다.
- `openEditModal(copy)`: 기존 자료 행을 클릭하면 실행돼요. 그 자료 값으로 폼을 채우고(`selectCopy(copy)`) 모달을 엽니다.
- 왼쪽/오른쪽 박스 구조가 예전엔 "왼쪽 위: MARC, 왼쪽 아래: 목록"이었는데, 이제는 "왼쪽: MARC만, 오른쪽: 목록만"으로 나뉘었어요. 각자 세로로 더 넓게(`max-h-[75vh]`) 쓸 수 있게 됐어요.
- 예전에 오른쪽 패널에 있던 `style={{ borderColor: selectedCopyId ? primaryColor : "#000000" }}` 같은 테두리 색 로직은 통째로 지웠어요. 모달은 그냥 다른 모달들(상세 검색, 등록번호 검색)과 똑같은 모양(둥근 흰 박스 + 그림자)으로 통일했어요.
- 저장(`handleAddCopy`, `handleUpdateCopy`)이 성공하면 마지막에 `setShowModal(false)`를 추가해서, 저장이 끝나면 모달이 자동으로 닫히도록 했어요.
- 모달을 닫는 방법은 세 가지예요: 오른쪽 위 "✕" 버튼 클릭, 모달 바깥의 어두운 부분 클릭, 또는 저장 성공.
- '새 실물 자료 등록' 행의 배경색은 이번엔 항상 검정(`#383838`)으로 고정했어요. (예전엔 "선택된 상태"를 표시하기 위해 색이 바뀌었는데, 이제 그 행을 누르면 곧장 모달이 뜨는 방식이라 "선택 상태"라는 개념 자체가 필요 없어졌어요.) 기존 자료 행의 선택 강조 색상(도서관 기본색)은 예전처럼 그대로 남겨뒀어요 — 모달이 열려있는 동안 "지금 이 자료를 수정 중이에요"라는 표시로 자연스럽게 남아있어요.

## ✅ 확인하기

1. 백엔드, 프론트엔드를 실행해주세요.
2. 자료 목록에서 자료를 하나 클릭해서 실물 등록 페이지로 들어가주세요.
3. 처음 들어왔을 때, 왼쪽엔 KOMARC 정보만, 오른쪽엔 실물 자료 목록 표만 보이는지 확인해주세요. (입력 폼은 안 보여야 정상이에요.)
4. '새 실물 자료 등록' 행을 클릭하면 모달이 뜨고, 제목이 "실물 자료 추가"로 나오는지 확인해주세요.
5. 등록번호 칸에 최근 번호의 다음 숫자가 자동으로 채워져 있는지 확인해주세요.
6. 값을 입력하고 "저장"을 누르면 모달이 닫히고, 오른쪽 목록에 새 자료가 추가되는지 확인해주세요.
7. 이번엔 기존 자료 행을 클릭해보세요. 모달이 뜨고 제목이 "실물 등록자료 수정"으로 나오며, 그 자료의 값이 폼에 채워지는지 확인해주세요.
8. 값을 수정하고 "저장"을 누르면 모달이 닫히고 목록에 반영되는지 확인해주세요.
9. 모달의 "✕" 버튼이나 바깥의 어두운 부분을 클릭했을 때도 잘 닫히는지 확인해주세요.
