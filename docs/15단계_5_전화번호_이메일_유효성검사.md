### 2-1. 전화번호 자동 하이픈 함수 + 형식 검사 함수 추가

`EMPTY_FORM` 상수 바로 아래에 아래 두 함수를 추가하세요.

```tsx
// 숫자만 남기고, 3자리-4자리-4자리 모양으로 하이픈을 자동으로 붙여줍니다.
function formatPhone(raw: string) {
  const digits = raw.replace(/\D/g, "").slice(0, 11); // 숫자만, 최대 11자리
  if (digits.length < 4) return digits;
  if (digits.length < 8) return `${digits.slice(0, 3)}-${digits.slice(3)}`;
  return `${digits.slice(0, 3)}-${digits.slice(3, 7)}-${digits.slice(7)}`;
}

// 하이픈을 뺀 숫자가 정확히 11자리인지 확인합니다.
function isValidPhone(phone: string) {
  return phone.replace(/\D/g, "").length === 11;
}

// 이메일은 입력했을 때만(선택 항목이라) 형식을 확인합니다.
function isValidEmail(email: string) {
  if (!email.trim()) return true;
  return /^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(email.trim());
}
```

- `formatPhone`: 사용자가 숫자만 계속 입력해도, 3자리를 채우면 뒤에 `-`, 다시 4자리를 더 채우면 또 `-`가 자동으로 붙어요. 숫자가 아닌 문자(예: 붙여넣기로 들어온 기존 하이픈)는 먼저 다 지우고 다시 규칙대로 붙이기 때문에, 사용자가 뭘 입력하든 항상 올바른 모양이 돼요.
- `isValidPhone`: 하이픈을 빼고 세어서 딱 11자리인지 확인해요. `010`으로 시작하는 휴대폰 번호는 항상 11자리(010-XXXX-XXXX)죠.

### 2-2. 전화번호 입력칸에 자동 서식 적용

`applyDetailSearch` 함수는 그대로 두고, **등록/수정 모달 안**의 전화번호 입력칸을 찾으세요.

```tsx
              <label className="block">
                <span className="mb-1 block text-sm text-neutral-500">{t("members.form.field.phone")}</span>
                <input
                  value={form.phone}
                  onChange={(e) => setForm({ ...form, phone: e.target.value })}
                  className="w-full rounded-lg border px-3 py-2 text-sm"
                />
              </label>
```

이렇게 바꿔주세요. (`onChange`에서 `formatPhone`을 거치고, `placeholder`·`inputMode`·`maxLength`를 추가했어요. `*`를 붙여서 필수 항목임을 표시했습니다.)

```tsx
              <label className="block">
                <span className="mb-1 block text-sm text-neutral-500">{t("members.form.field.phone")} *</span>
                <input
                  value={form.phone}
                  onChange={(e) => setForm({ ...form, phone: formatPhone(e.target.value) })}
                  placeholder="000-0000-0000"
                  inputMode="numeric"
                  maxLength={13}
                  className="w-full rounded-lg border px-3 py-2 text-sm"
                />
              </label>
```

- `inputMode="numeric"`: 모바일에서 이 칸을 누르면 숫자 키패드가 뜨게 해줘요(휴대폰으로 관리자 페이지를 쓸 때 편해요).
- `maxLength={13}`: `000-0000-0000`이 정확히 13글자라서, 그 이상은 아예 입력이 안 돼요(2차 안전장치).

### 2-3. 저장하기 전 형식 검사 추가

`handleSave` 함수 안, 아래 부분을 찾으세요.

```tsx
    if (!editingId && (!form.loginId.trim() || !form.password.trim() || !form.name.trim())) {
      notify("❌ " + t("members.form.requiredFields"), "error");
      return;
    }
```

이렇게 바꿔주세요. (전화번호·이메일 검사 두 가지를 이어서 추가했어요.)

```tsx
    if (!editingId && (!form.loginId.trim() || !form.password.trim() || !form.name.trim())) {
      notify("❌ " + t("members.form.requiredFields"), "error");
      return;
    }
    if (!isValidPhone(form.phone)) {
      notify("❌ " + t("members.form.invalidPhone"), "error");
      return;
    }
    if (!isValidEmail(form.email)) {
      notify("❌ " + t("members.form.invalidEmail"), "error");
      return;
    }
```

- 이 검사를 통과 못 하면 `return`으로 함수가 여기서 멈추기 때문에, 서버로 저장 요청 자체가 안 나가요. 즉 11자리를 다 채우지 않거나, 이메일 형식이 아니면 "저장" 버튼을 눌러도 저장되지 않고 오류 알림만 떠요.
- 전화번호는 이번에 **필수 항목**으로 바뀌었어요(회원 등록/수정 모두). 기존에 전화번호가 없던 회원을 수정할 땐, 이 화면에서 전화번호를 채워 넣어야 다른 정보도 함께 저장할 수 있어요.
- 이메일은 계속 **선택 항목**이라, 비워두면 검사를 건너뛰고, 뭔가 입력했을 때만 형식을 확인해요.

## 3. 확인하기 — 약 5분

1. 표 머리글·상세검색·등록/수정 모달에서 칸 이름이 **"휴대폰 번호"**로 바뀌었는지 확인합니다.
2. 등록 모달의 휴대폰 번호 칸에 `01012345678`처럼 숫자만 이어서 입력했을 때, 자동으로 `010-1234-5678` 모양이 되는지 확인합니다.
3. 숫자를 11자리보다 적게 입력하고 저장 시도 → "휴대폰 번호 11자리를 모두 입력해주세요." 오류가 뜨는지 확인합니다.
4. 이메일 칸에 `abc`처럼 형식이 아닌 값을 넣고 저장 시도 → "이메일 형식이 올바르지 않습니다." 오류가 뜨는지 확인합니다.
5. 이메일 칸을 비워두고 나머지를 올바르게 입력하면 정상적으로 저장되는지 확인합니다(이메일은 선택이므로).
6. 다 올바르게 입력하고 저장 → 회원 목록 표에 `010-1234-5678`처럼 하이픈 포함된 번호로 저장되는지 확인합니다.
