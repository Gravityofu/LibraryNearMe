# 개선 59: 대출/반납 화면 회원 검색에서 관리자 계정도 검색되게 하기

## 목표

'대출/반납' 화면에서 회원을 검색할 때, 지금까지는 '일반 이용자(MEMBER)' 역할을 가진 계정만 검색 대상이었습니다. 그래서 '관리자(ADMIN)'나 '슈퍼 관리자(SUPER)' 역할을 가진 계정은 이름이나 회원번호로 검색해도 결과에 나타나지 않았습니다. (요청하신 `M000001` 계정이 검색되지 않은 이유입니다.)

관리자 계정도 도서관을 실제로 이용하며 책을 빌릴 수 있어야 하므로, 역할(role)에 상관없이 모든 계정이 검색되도록 고칩니다. (단, 회원 상태가 '대출가능(ACTIVE)'이어야 검색되는 조건은 그대로 유지합니다. 정지되거나 탈퇴한 계정은 여전히 검색되지 않는 것이 맞기 때문입니다.)

---

## 백엔드 수정하기: `loans.service.ts`

`C:\projects\LibraryNearMe\backend\src\loans\loans.service.ts` 파일을 여세요.

### 1. 기본 검색(`findMembers`)에서 역할 제한 없애기

아래 부분을 찾으세요.

```ts
    return this.prisma.user.findMany({
      where: {
        libraryId,
        role: 'MEMBER',
        status: 'ACTIVE',
        OR: [
          { name: { contains: kw } },
          { memberNo: { contains: kw } },
        ],
      },
```

이렇게 바꿔주세요.

```ts
    return this.prisma.user.findMany({
      where: {
        libraryId,
        status: 'ACTIVE',
        OR: [
          { name: { contains: kw } },
          { memberNo: { contains: kw } },
        ],
      },
```

### 2. 상세 검색(`findMembersDetailed`)에서도 역할 제한 없애기

아래 부분을 찾으세요.

```ts
    const where: any = { libraryId, role: 'MEMBER', status: 'ACTIVE' };
```

이렇게 바꿔주세요.

```ts
    const where: any = { libraryId, status: 'ACTIVE' };
```

파일을 저장하세요.

## 확인하기

1. 백엔드 서버를 재시작하세요. (`npm run start:dev`)
2. '대출/반납' 화면에서 관리자 계정의 이름이나 회원번호(예: `M000001`)로 검색해보세요. 이제 검색 결과에 나타나는지 확인하세요.
3. '상세 검색' 모달에서도 관리자 계정의 정보(휴대폰, 아이디, 이메일, 주소 등)로 검색했을 때 정상적으로 검색되는지 확인하세요.
4. 기존 일반 이용자(MEMBER) 검색은 여전히 정상적으로 잘 되는지 확인하세요.
5. 상태가 '정지' 또는 '탈퇴'인 계정은 여전히 검색되지 않는지도 함께 확인하세요. (이 조건은 그대로 유지되었습니다.)
