# 개선151. 썸네일형 게시판 카드 - 사진 영역 크기 고정 + 키워드 자리 고정

## 목표

썸네일형 게시판의 카드 목록에서, 사진 비율이 서로 달라도 사진이 나오는 영역(상자) 크기는 항상 똑같게 만듭니다.

- 지금은 사진을 상자에 꽉 채워서(그래서 사진 비율에 따라 잘리는 부분이 다르게) 보여주고 있는데, 이걸 사진 전체가 다 보이도록 바꾸고, 상자보다 사진이 작게 남는 빈 공간은 흰색으로, 사진은 수직/수평 가운데에 오도록 바꿉니다. (상자 크기 자체는 개선150에서 만든 '가로형/세로형' 비율을 그대로 씁니다. 상자 크기가 똑같으니 사진 비율과 상관없이 제목이 시작하는 위치도 항상 같아집니다.)
- 키워드를 쓰지 않은 글도, 키워드가 들어갈 자리를 빈 칸으로 남겨둬서, 카드마다 내용이 들쭉날쭉해 보이지 않도록 합니다.

바꾸는 파일은 `frontend/src/app/(site)/boards/[code]/page.tsx` 하나입니다.

---

## 1단계. 사진 영역: 꽉 채우기 → 전체 보이게 + 흰 여백

아래 코드를 찾으세요.

```typescript
                <div className={`w-full bg-neutral-100 ${isTallThumbnail ? "aspect-[3/4]" : "aspect-video"}`}>
                  {row.thumbnailUrl ? (
                    // eslint-disable-next-line @next/next/no-img-element
                    <img src={row.thumbnailUrl} alt="" className="h-full w-full object-cover" />
                  ) : (
                    <div className="flex h-full w-full items-center justify-center text-xs text-neutral-300">
                      {t("boards.list.col.thumbnail")}
                    </div>
                  )}
                </div>
```

아래로 바꿔주세요.

```typescript
                <div className={`w-full bg-white ${isTallThumbnail ? "aspect-[3/4]" : "aspect-video"}`}>
                  {row.thumbnailUrl ? (
                    // eslint-disable-next-line @next/next/no-img-element
                    <img src={row.thumbnailUrl} alt="" className="h-full w-full object-contain" />
                  ) : (
                    <div className="flex h-full w-full items-center justify-center bg-neutral-100 text-xs text-neutral-300">
                      {t("boards.list.col.thumbnail")}
                    </div>
                  )}
                </div>
```

**바뀐 점**: `object-cover`(상자를 꽉 채우도록 잘라서 보여줌) 대신 `object-contain`(사진을 자르지 않고 상자 안에 전부 들어오게 줄여서 보여줌)으로 바꿨습니다. 사진이 상자보다 작게 보이는 빈 공간은 상자 배경색(흰색, `bg-white`)으로 채워집니다. `object-contain`은 기본적으로 가로·세로 모두 가운데 정렬되기 때문에 사진이 항상 상자 한가운데에 오게 됩니다. 사진이 없는 글의 자리표시(placeholder)는 헷갈리지 않도록 그대로 회색(`bg-neutral-100`) 배경을 유지했습니다.

## 2단계. 키워드가 없어도 자리 고정하기

아래 코드를 찾으세요.

```typescript
                  {row.keywords && row.keywords.length > 0 && (
                    <p className="line-clamp-3 text-xs" style={{ color: primaryColor || "#3b82f6" }}>
                      {row.keywords.map((k) => `#${k}`).join(" ")}
                    </p>
                  )}
```

아래로 바꿔주세요.

```typescript
                  <p
                    className="line-clamp-3 min-h-[1rem] text-xs"
                    style={{ color: primaryColor || "#3b82f6" }}
                  >
                    {row.keywords && row.keywords.length > 0
                      ? row.keywords.map((k) => `#${k}`).join(" ")
                      : "\u00A0"}
                  </p>
```

**바뀐 점**: 키워드가 있을 때만 보이던 줄을 항상 보이게 바꾸고, 키워드가 없으면 빈 문자(`\u00A0`)를 넣어서 그 줄의 높이만 유지하도록 했습니다. 이렇게 하면 키워드가 있는 글과 없는 글이 섞여 있어도 카드 안 내용의 위치가 흔들리지 않습니다.

---

## 확인하기

1. 가로가 긴 사진을 첨부한 글과 세로가 긴 사진을 첨부한 글을 같은 썸네일형 게시판에 각각 써보세요.
2. 홈페이지에서 그 게시판을 열어, 두 사진이 담긴 상자의 크기(가로·세로)가 서로 똑같은지 확인합니다.
3. 사진이 상자보다 작게 들어가서 남는 빈 공간이 흰색으로 채워지고, 사진이 잘리지 않고 전체가 다 보이는지 확인합니다.
4. 사진이 상자 안에서 가운데(위아래·좌우 모두)에 위치하는지 확인합니다.
5. 키워드를 넣은 글과 넣지 않은 글을 같은 게시판에 나란히 놓고, 제목이 시작하는 위치·본문 미리보기 위치가 카드마다 흔들리지 않고 일정한지 확인합니다.
6. 사진을 첨부하지 않은 글은 지금처럼 회색 빈 상자(안내 문구 포함)가 그대로 나오는지 확인합니다.
