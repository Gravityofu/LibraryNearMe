# 개선152. 가로형 썸네일에서 사진 상자 비율이 적용되지 않던 문제 수정

## 목표

개선151에서 "사진 상자 크기를 고정"하도록 고쳤는데, 확인해 주신 대로 '세로형'(한 줄 4개)은 잘 적용되고 '가로형'(한 줄 3개)은 사진 비율에 따라 상자 크기가 여전히 다르게 나오는 문제를 고칩니다.

## 원인

이 프로젝트에서 쓰는 Tailwind(화면 스타일을 입히는 도구) 버전에서, `aspect-video`라는 이름이 붙은 스타일이 어떤 이유로든 실제 CSS로 만들어지지 않고 있었습니다. (반면 세로형에 쓴 `aspect-[3/4]`처럼 숫자를 직접 대괄호 안에 적어주는 방식은 정상적으로 만들어집니다.) 그래서 세로형은 상자 비율이 잘 고정되고, 가로형은 상자에 비율 자체가 적용되지 않아서 사진 원래 크기만큼 상자가 늘어나 보였던 것입니다.

## 수정 방법

`frontend/src/app/(site)/boards/[code]/page.tsx` 파일을 여세요.

아래 줄을 찾으세요.

```typescript
                <div className={`w-full bg-white ${isTallThumbnail ? "aspect-[3/4]" : "aspect-video"}`}>
```

아래로 바꿔주세요. (`aspect-video` → `aspect-[16/9]`, 세로형과 같은 방식으로 통일)

```typescript
                <div className={`w-full bg-white ${isTallThumbnail ? "aspect-[3/4]" : "aspect-[16/9]"}`}>
```

`aspect-video`와 `aspect-[16/9]`는 가로:세로 비율(16:9)이 완전히 똑같습니다. 이름 붙은 방식 대신, 이미 잘 작동하는 것으로 확인된 숫자 직접 지정 방식으로 통일한 것뿐이라 화면에 보이는 비율 자체는 달라지지 않습니다.

## 확인하기

1. '가로형'(한 줄 3개)으로 설정된 게시판에서, 가로가 긴 사진을 첨부한 글과 세로가 긴 사진을 첨부한 글을 나란히 확인합니다. 두 사진 상자의 크기가 이제 서로 똑같은지 확인합니다.
2. 제목이 시작하는 위치가 사진 비율과 상관없이 카드마다 일정한지 확인합니다.
3. '세로형'(한 줄 4개) 게시판도 이전처럼 계속 잘 작동하는지 다시 한번 확인합니다.
