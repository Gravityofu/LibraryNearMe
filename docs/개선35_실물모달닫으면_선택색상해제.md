# 개선35. 실물 목록 모달을 닫으면 선택 배경색도 함께 없어지게 하기

## 🎯 원인과 목표

지금은 실물 목록에서 하나를 클릭하면 `selectedCopyId`라는 값에 그 실물의 id가 저장되면서 배경색이 도서관 색상으로 바뀌는데, 모달을 닫을 때는 `showModal`만 `false`로 바꾸고 `selectedCopyId`는 그대로 남겨두고 있었어요. 그래서 모달은 사라지는데 목록의 배경색은 계속 남아있었던 거예요.

이번엔 모달이 닫힐 때(바깥 영역 클릭, ✕ 버튼 클릭, 저장/삭제 완료 후 자동으로 닫힐 때 모두) `selectedCopyId`도 함께 비워서, 모달이 닫히면 항상 흰 배경으로 돌아가도록 고칠게요.

## 수정하기

**파일**: `frontend/src/app/admin/materials/copies/page.tsx`

### 1) 모달을 닫는 함수 새로 만들기

**찾기:**

```tsx
  // '새 실물 자료 등록' 행을 클릭했을 때: 폼을 비우고 모달을 엽니다.
  function openAddModal() {
    resetForm();
    setShowModal(true);
  }

  // 기존 실물 자료 행을 클릭했을 때: 그 자료 값으로 폼을 채우고 모달을 엽니다.
  function openEditModal(copy: CopyItem) {
    selectCopy(copy);
    setShowModal(true);
  }
```

**이렇게 바꿔주세요:**

```tsx
  // '새 실물 자료 등록' 행을 클릭했을 때: 폼을 비우고 모달을 엽니다.
  function openAddModal() {
    resetForm();
    setShowModal(true);
  }

  // 기존 실물 자료 행을 클릭했을 때: 그 자료 값으로 폼을 채우고 모달을 엽니다.
  function openEditModal(copy: CopyItem) {
    selectCopy(copy);
    setShowModal(true);
  }

  // 모달을 닫을 때는 선택 표시(배경색)도 함께 없애줍니다.
  function closeModal() {
    setShowModal(false);
    setSelectedCopyId(null);
  }
```

### 무슨 코드인가요?

모달을 닫는 6가지 경우(바깥 클릭, ✕ 버튼, 등록 완료, 수정 완료, 삭제 완료) 전부 `setShowModal(false)` 대신 새로 만든 `closeModal()`을 쓰도록 바꿨어요. `closeModal()`은 모달을 닫는 것과 동시에 `setSelectedCopyId(null)`로 선택 표시도 함께 지워서, 모달이 어떤 방식으로 닫히든 목록은 항상 흰 배경으로 돌아가요.

4. 다시 하나를 클릭해서 모달을 열고, 이번엔 ✕ 버튼으로 닫아보세요. 마찬가지로 흰색으로 돌아가는지 확인해주세요.
5. 실물 하나를 눌러 수정하고 저장해보세요. 모달이 닫힌 뒤 그 행이 흰색으로 돌아가는지 확인해주세요.
