# 16단계 (2) — 회원가입 완료 후 자동 로그인 + 이전 페이지로 이동

> 목표: 회원가입이 성공하면 그 자리에 멈춰있지 않고, **자동으로 로그인된 상태**로
> 바뀌면서 원래 보고 있던 페이지로 돌아가게 만듭니다.
> 소요 시간: 약 10분

---

## 오늘 고치는 문제

지금은 회원가입 버튼을 누르면 DB에는 잘 저장되지만, 화면은 그대로 회원가입 페이지에
남아있어요. 사용자 입장에서는 "가입은 됐는데 로그인은 다시 해야 하나?" 헷갈리는
상황이에요.

오늘은 이렇게 바꿉니다.

```
(자료 페이지 등) → [로그인/회원가입] 클릭
        ↓
     로그인 화면 (원래 있던 페이지를 "redirect" 로 기억)
        ↓ "회원가입" 링크 클릭 (redirect 정보를 그대로 들고 감)
     회원가입 화면
        ↓ 가입하기 버튼
     ① 가입 저장 → ② 자동 로그인 → ③ 원래 있던 페이지로 이동
```

즉, "회원가입 링크를 어디서 눌렀는지"를 기억해뒀다가, 가입이 끝나면 로그인까지
자동으로 시켜주고 그 자리로 돌려보내 줍니다.

---

## 1. 로그인 화면 — "어디서 왔는지" 기억해서 회원가입 링크에 실어 보내기 — 약 5분

`frontend/src/app/(site)/login/page.tsx` 를 엽니다.

### 1-1. import 수정

맨 위, `import { useState } from "react";` 줄을 아래처럼 바꾸세요. (`useEffect` 를
추가로 불러옵니다.)

```tsx
import { useState, useEffect } from "react";
```

### 1-2. redirect 값을 기억할 상태 추가

아래 부분을 찾으세요.

```tsx
  const [loginId, setLoginId] = useState("");
  const [password, setPassword] = useState("");
```

이렇게 바꿔주세요. (redirect 값을 담아둘 상태와, 페이지가 열리자마자 주소창의
`?redirect=` 값을 읽어오는 코드를 추가했어요.)

```tsx
  const [loginId, setLoginId] = useState("");
  const [password, setPassword] = useState("");
  const [redirectParam, setRedirectParam] = useState("");

  // 페이지가 열릴 때 주소창의 ?redirect=... 값을 읽어서 기억해둡니다.
  useEffect(() => {
    const r = new URLSearchParams(window.location.search).get("redirect");
    if (r) setRedirectParam(r);
  }, []);
```

### 1-3. 로그인 성공 후 이동에 재사용

아래 부분을 찾으세요.

```tsx
      const redirect = new URLSearchParams(window.location.search).get("redirect") || "/";
      router.push(redirect);
```

이렇게 바꿔주세요. (같은 값을 매번 새로 읽지 않고, 위에서 기억해둔 `redirectParam`
을 그대로 씁니다.)

```tsx
      router.push(redirectParam || "/");
```

### 1-4. 회원가입 링크에 redirect 값 실어 보내기

아래 부분을 찾으세요. (16단계 1에서 추가했던 링크 3개예요.)

```tsx
            <Link href="/signup" className="hover:text-neutral-800">
              {t("login.signupLink")}
            </Link>
```

이렇게 바꿔주세요. (기억해둔 `redirectParam`이 있으면 `/signup?redirect=...` 형태로,
없으면 그냥 `/signup`으로 이동합니다.)

```tsx
            <Link
              href={redirectParam ? `/signup?redirect=${encodeURIComponent(redirectParam)}` : "/signup"}
              className="hover:text-neutral-800"
            >
              {t("login.signupLink")}
            </Link>
```

## 2. 회원가입 화면 — 가입 성공 시 자동 로그인 + 이동 — 약 5분

`frontend/src/app/(site)/signup/page.tsx` 를 엽니다.

### 2-1. import 추가

맨 위쪽 import 목록에 두 줄을 추가하세요.

```tsx
import { useRouter } from "next/navigation";
import { useAuth } from "@/components/auth-provider";
```

### 2-2. 훅 추가

아래 부분을 찾으세요.

```tsx
export default function SignupPage() {
  const { t } = useI18n();
```

이렇게 바꿔주세요.

```tsx
export default function SignupPage() {
  const { t } = useI18n();
  const { login } = useAuth();
  const router = useRouter();
```

### 2-3. 가입 성공 처리 바꾸기

`handleSignup` 함수 안에서 아래 부분을 찾으세요.

```tsx
    if (res.ok) {
      notify(t("signup.success"), "success");
    } else {
```

이렇게 바꿔주세요. (가입이 끝나면, 방금 입력한 아이디·비밀번호로 곧바로 로그인
요청을 한 번 더 보내서 "출입증(토큰)"을 받아온 뒤, 로그인 상태로 만들고 원래
있던 페이지로 이동시킵니다.)

```tsx
    if (res.ok) {
      const loginRes = await fetch(`${API_URL}/auth/login`, {
        method: "POST",
        headers: { "Content-Type": "application/json" },
        body: JSON.stringify({ loginId, password }),
      });

      if (loginRes.ok) {
        const loginData = await loginRes.json();
        login({ token: loginData.token, userName: loginData.user.name, role: loginData.user.role });
        notify(t("signup.success"), "success");
        const redirect = new URLSearchParams(window.location.search).get("redirect") || "/";
        router.push(redirect);
      } else {
        // 가입은 됐지만 자동 로그인만 실패한 드문 경우 — 로그인 화면으로 보냅니다.
        notify(t("signup.success"), "success");
        router.push("/login");
      }
    } else {
```

- 회원가입 API(`POST /users`)는 원래부터 "가입됐다"는 메시지만 돌려주고 출입증(토큰)은
  안 줘요. 그래서 가입 직후에 로그인 API(`POST /auth/login`)를 한 번 더 호출해서
  진짜 로그인을 시켜주는 방식이에요. 방금 입력한 아이디·비밀번호를 그대로 재사용하니
  사용자는 아무것도 다시 입력할 필요가 없어요.
- 아주 드물게 가입은 됐는데 자동 로그인만 실패하면(예: 서버가 그 사이 잠깐 응답이
  느렸다거나) 로그인 화면으로 보내서 직접 로그인하도록 안내해요.

## 3. 확인하기 — 약 5분

1. 자료 목록 같은 아무 페이지에서 "로그인/회원가입" 버튼을 눌러 로그인 화면으로
   갑니다. (주소창에 `?redirect=...`가 붙어있는지 확인하세요.)
2. "회원가입" 링크를 눌러 회원가입 화면으로 이동합니다. (주소창에 여전히
   `?redirect=...`가 붙어있어야 해요.)
3. 새 아이디로 가입을 완료합니다.
4. 가입이 끝나자마자 **로그인된 상태**(오른쪽 위 등에 이름이 보이는지)로,
   **원래 있던 페이지**로 자동 이동하는지 확인합니다.
5. `?redirect` 없이 그냥 `/signup`으로 바로 들어가서 가입해도, 가입 후 홈(`/`)으로
   잘 이동하는지 확인합니다.

✅ 모두 확인되면 성공입니다! 🎉
