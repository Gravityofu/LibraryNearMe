# 개선18. '새 실물 자료 등록' 행 가운데 정렬 + 버튼1 색상 적용

## 🎯 목표

지난번(개선17)에 만든 "+ 새 실물 자료 등록" 행을 이번엔 이렇게 다듬을게요.

- 글자가 왼쪽에 붙어있던 걸 **행 가운데**로 오도록 정렬
- 배경색/글자색을 검정(`#000000`)/하양(`#ffffff`) 하드코딩 대신, 관리자 설정 → 디자인 탭의 **"버튼1" 색상**을 그대로 가져다 쓰기
- 선택 안 된 상태의 테두리 색도 검정(`border-black`) 대신 **버튼1의 배경색**으로 바꾸기

이렇게 하면 나중에 관리자 페이지 → 설정 → 디자인 탭에서 "버튼1" 색을 바꾸는 순간, 이 행의 색깔도 자동으로 같이 바뀌어요. 색을 코드에 직접 적어두지 않고 "버튼1"이라는 이름표만 붙여두는 방식이라, 앞으로 색을 바꾸고 싶을 때 코드를 건드릴 필요가 없어집니다.

### 그림으로 보면

```
[전]                                    [후]
┌───────────────────────┐        ┌───────────────────────┐
│(+) 새 실물 자료 등록      │        │      (+) 새 실물 자료 등록   │
└───────────────────────┘        └───────────────────────┘
  왼쪽 정렬, 검정/하양 고정색            가운데 정렬, "버튼1" 색상(변경 가능)
```

## 1단계. 관리자 설정 색상을 읽어오기

**파일**: `frontend/src/app/admin/materials/copies/page.tsx`

파일 맨 위쪽, `import` 하는 부분을 찾아주세요.

**찾기:**

```tsx
import ThemedButton from "@/components/themed-button";
```

**이렇게 바로 아래 줄을 추가해주세요:**

```tsx
import ThemedButton from "@/components/themed-button";
import { useTheme } from "@/components/theme-provider";
```

---

이번엔 `CopiesPageInner` 함수 안, `primaryColor` 상태를 선언한 줄을 찾아주세요.

**찾기:**

```tsx
  const [primaryColor, setPrimaryColor] = useState("#2563eb");
```

**바로 아래에 이 두 줄을 추가해주세요:**

```tsx
  const [primaryColor, setPrimaryColor] = useState("#2563eb");
  const { buttonStyles } = useTheme();
  const button1 = buttonStyles.find((b) => b.name === "버튼1");
  const button1Bg = button1?.bgColor || "#383838";
  const button1Text = button1?.textColor || "#F9F6F0";
```

### 무슨 코드인가요?

- `useTheme()`: 관리자 설정 → 디자인 탭에서 저장한 색상 정보를 가져오는 훅이에요. 실물 등록 페이지 하단 "저장" 버튼에서 이미 쓰고 있던 것과 똑같은 방식이에요.
- `buttonStyles.find((b) => b.name === "버튼1")`: 여러 버튼 설정 중에서 이름이 "버튼1"인 것을 찾아요.
- `button1Bg`, `button1Text`: 찾은 "버튼1"의 배경색/글자색이에요. 혹시 아직 설정이 안 되어있는 경우를 대비해서 `|| "#383838"`, `|| "#F9F6F0"`처럼 기본값도 함께 넣어뒀어요.

## 2단계. 가운데 정렬 + 색상 교체하기

같은 파일에서, 개선17에서 만들었던 아래 코드를 찾아주세요.

**찾기:**

```tsx
                <tr onClick={resetForm} className="cursor-pointer">
                  <td
                    colSpan={4}
                    className={`px-2 py-2 font-semibold ${
                      selectedCopyId === null ? "" : "border border-black text-black"
                    }`}
                    style={selectedCopyId === null ? { backgroundColor: "#000000", color: "#ffffff" } : undefined}
                  >
                    <span className="inline-flex items-center gap-2">
                      <span
                        className="flex h-5 w-5 shrink-0 items-center justify-center rounded-full border text-xs leading-none"
                        style={{ borderColor: "currentColor" }}
                      >
                        +
                      </span>
                      {t("materials.copies.newRegistrationRow")}
                    </span>
                  </td>
                </tr>
```

**이렇게 바꿔주세요:**

```tsx
                <tr onClick={resetForm} className="cursor-pointer">
                  <td
                    colSpan={4}
                    className={`px-2 py-2 text-center font-semibold ${
                      selectedCopyId === null ? "" : "border text-black"
                    }`}
                    style={
                      selectedCopyId === null
                        ? { backgroundColor: button1Bg, color: button1Text }
                        : { borderColor: button1Bg }
                    }
                  >
                    <span className="inline-flex items-center gap-2">
                      <span
                        className="flex h-5 w-5 shrink-0 items-center justify-center rounded-full border text-xs leading-none"
                        style={{ borderColor: "currentColor" }}
                      >
                        +
                      </span>
                      {t("materials.copies.newRegistrationRow")}
                    </span>
                  </td>
                </tr>
```

### 무슨 코드인가요?

- `text-center`: `<td>` 클래스에 추가해서, 안에 있는 "+ 새 실물 자료 등록" 글자가 행 가운데로 오도록 만들어요.
- `selectedCopyId === null ? "" : "border text-black"`: 선택 안 된 상태일 때는 `border`(테두리 있음) + `text-black`(검정 글자)만 클래스로 주고, 테두리 **색깔**은 `style`에서 따로 지정해요.
- `style={ ... }` 부분:
  - 등록 모드(선택 안 됨, `selectedCopyId === null`)일 때: 배경색은 `button1Bg`, 글자색은 `button1Text` — 즉 "버튼1" 색상 그대로예요.
  - 다른 자료가 선택됐을 때: 배경색 없이, 테두리 색만 `button1Bg`로 지정해요.
- 이제 이 두 색깔은 더 이상 코드에 직접 적힌 고정값이 아니라 `button1Bg`/`button1Text` **변수**이기 때문에, 관리자 페이지에서 "버튼1" 색을 바꾸면 이 행도 자동으로 같이 바뀝니다.

## ✅ 확인하기

1. 백엔드와 프론트엔드를 실행해주세요.
2. 관리자 페이지 → 자료 목록 → 아무 자료나 클릭해서 실물 등록 페이지로 들어가주세요.
3. "+ 새 실물 자료 등록" 글자가 행 **가운데**에 오는지 확인해주세요.
4. 이 글자의 배경색이 관리자 설정 → 디자인 탭에 있는 "버튼1" 배경색과 같은 색인지 확인해주세요. (기본값이면 짙은 회색일 거예요.)
5. 기존 실물 자료 행을 하나 클릭해보세요. "새 실물 자료 등록" 행의 배경색이 사라지고, 테두리 색이 "버튼1" 배경색으로 바뀌는지 확인해주세요.
6. 관리자 페이지 → 설정 → 디자인 탭에서 "버튼1"의 배경색이나 글자색을 다른 색으로 바꾸고 저장한 뒤, 이 실물 등록 페이지로 돌아와서 색이 그 즉시 바뀌어 보이는지 확인해주세요. (페이지를 새로고침해야 반영될 수 있어요.)
