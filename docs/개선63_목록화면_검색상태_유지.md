# 개선 63: '목록' 화면에서 검색했던 내용을 기억해두기

## 목표

'목록' 화면에서 자료를 검색한 뒤, (1) 자료를 클릭해 상세 화면에서 자료를 삭제하거나, (2) 상세 화면에서 '뒤로 가기'를 누르면, 지금은 두 경우 모두 검색 결과가 사라진 처음 화면(아무것도 검색 안 한 상태)으로 돌아갑니다.

원인은 '목록' 화면이 검색 조건(어떤 종류, 어떤 제목으로 찾았는지 등)과 검색 결과를 화면(컴포넌트)이 떠 있는 동안에만 기억하고 있기 때문입니다. 상세 화면으로 이동했다가 '목록' 화면으로 다시 돌아오면, 그 화면은 처음부터 새로 열리는 것이라 이전에 검색했던 내용을 전혀 기억하지 못합니다.

이번에는 검색할 때마다 그 검색 조건과 몇 번째 페이지를 보고 있었는지를 브라우저에 잠깐 저장해두고(같은 탭에서만 유지되고, 탭을 닫으면 사라지는 임시 저장소입니다), '목록' 화면이 다시 열릴 때 그 저장된 내용이 있으면 자동으로 같은 조건으로 다시 검색해서 보여주도록 고칩니다. 이렇게 하면 자료를 삭제하고 돌아오든, '뒤로 가기'로 돌아오든 상관없이 마지막으로 검색했던 목록이 그대로 다시 나타납니다.

## 화면 수정하기: `page.tsx`

`C:\projects\LibraryNearMe\frontend\src\app\admin\materials\list\page.tsx` 파일을 여세요.

### 1. 저장할 때 쓸 이름(키) 정해두기

아래 부분을 찾으세요.

```tsx
const PAGE_SIZE_OPTIONS = [10, 20, 30, 40, 50];
const COLUMN_COUNT = 11;
```

이렇게 바꿔주세요.

```tsx
const PAGE_SIZE_OPTIONS = [10, 20, 30, 40, 50];
const COLUMN_COUNT = 11;

// 마지막으로 검색했던 조건/페이지를 기억해두는 저장소 이름입니다.
// (sessionStorage는 같은 탭 안에서만 유지되고, 탭을 닫으면 사라집니다.)
const SEARCH_STATE_KEY = "lnm-materials-list-search";
```

### 2. 검색에 성공할 때마다 조건을 저장해두기

아래 부분을 찾으세요.

```tsx
    if (res.ok) {
      const data = await res.json();
      setRows(data.items);
      setTotal(data.total);
      setPage(data.page);
      setPageSize(data.pageSize);
      setHasSearched(true);
    } else {
      notify("❌ " + t("materials.list.searchFail"), "error");
    }
```

이렇게 바꿔주세요.

```tsx
    if (res.ok) {
      const data = await res.json();
      setRows(data.items);
      setTotal(data.total);
      setPage(data.page);
      setPageSize(data.pageSize);
      setHasSearched(true);

      // 이번에 검색한 조건과 페이지를 저장해둡니다. 나중에 이 화면에 다시 돌아왔을 때 그대로 복원합니다.
      sessionStorage.setItem(
        SEARCH_STATE_KEY,
        JSON.stringify({ filters: f, page: data.page, pageSize: data.pageSize }),
      );
    } else {
      notify("❌ " + t("materials.list.searchFail"), "error");
    }
```

### 3. 화면이 열릴 때, 저장된 검색 조건이 있으면 자동으로 복원하기

아래 부분을 찾으세요.

```tsx
  useEffect(() => {
    loadMaterialTypes();
    // eslint-disable-next-line react-hooks/exhaustive-deps
  }, []);
```

이렇게 바꿔주세요.

```tsx
  useEffect(() => {
    loadMaterialTypes();
    // eslint-disable-next-line react-hooks/exhaustive-deps
  }, []);

  // 이 화면이 새로 열릴 때, 이전에 검색했던 조건이 저장되어 있으면 그 조건으로 자동으로 다시 검색합니다.
  useEffect(() => {
    const saved = sessionStorage.getItem(SEARCH_STATE_KEY);
    if (!saved) return;
    try {
      const parsed = JSON.parse(saved);
      if (parsed.filters) {
        setFilters(parsed.filters);
        fetchList(parsed.page || 1, parsed.pageSize || 10, parsed.filters);
      }
    } catch {
      // 저장된 내용이 이상하면 그냥 무시하고 처음 화면 그대로 둡니다.
    }
    // eslint-disable-next-line react-hooks/exhaustive-deps
  }, []);
```

파일을 저장하세요.
