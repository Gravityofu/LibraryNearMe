# 개선26 보충설명. 2단계를 아주 천천히, 한 줄씩 따라가기

지난 가이드(개선26)의 2단계에서 "어디까지 지우고 어디부터 넣어야 할지 헷갈린다"고 하셨죠. 이 파일에서는 딱 2단계만, 훨씬 더 잘게 쪼개서 설명해드릴게요.

핵심은 이거예요: **`handleAddCopy`와 `handleUpdateCopy`, 이렇게 똑같이 생긴 함수가 2개** 있고, 둘 다 거의 같은 모양이라 헷갈리기 쉬워요. 그래서 이번엔 **완전히 따로**, 순서대로 하나씩 해볼게요.

먼저 파일을 열어주세요: `frontend/src/app/admin/materials/copies/page.tsx`

## B. `handleAddCopy` 함수 **안쪽**에서, 등록번호만 확인하던 부분을 지우기

이제 `handleAddCopy` 함수 안에 있는 이 5줄을 찾아주세요. (바로 위 A단계에서 새로 추가한 코드 말고, 그 아래 원래 있던 `handleAddCopy` 함수 안쪽이에요.)

**이 5줄을 마우스로 정확히 선택해서 지워주세요:**

```tsx
    if (!form.registrationNo.trim()) {
      notify("❌ " + t("materials.copies.regNoRequired"), "error");
      return;
    }
```

**그 자리에 이 1줄만 새로 입력해주세요:**

```tsx
    if (!validateRequiredFields()) return;
```

지우고 나서 다시 넣으면, `handleAddCopy` 함수 전체가 이런 모습이 되어야 해요.

```tsx
  async function handleAddCopy() {
    if (!material) return;
    const token = localStorage.getItem("token");
    if (!token) return;
    if (!validateRequiredFields()) return;
    const res = await fetch(`${API_URL}/materials/${material.id}/copies`, {
      method: "POST",
      headers: { "Content-Type": "application/json", Authorization: `Bearer ${token}` },
      body: JSON.stringify(form),
    });

    if (res.ok) {
      notify("✅ " + t("materials.copies.addSuccess"), "success");
      await refreshMaterial(material.id);
      resetForm();
      await loadLatestRegNo();
      setShowModal(false);
    } else {
      const data = await res.json().catch(() => null);
      notify("❌ " + (data?.message || t("materials.copies.addFail")), "error");
    }
  }
```

> ✅ 여기까지 하면 `handleAddCopy` 부분은 완전히 끝났어요! `if (!material) return;`, `if (!token) return;`, `if (!validateRequiredFields()) return;` 이렇게 딱 3줄만 함수 맨 위에 남아있으면 정확한 거예요.

## C. 이번엔 `handleUpdateCopy` 함수 (아래쪽에 따로 있는 함수)

`Ctrl+F`로 이번엔 `handleUpdateCopy`를 검색해주세요. `handleAddCopy` 바로 아래쪽에 이런 모양으로 있을 거예요.

```tsx
  async function handleUpdateCopy() {
    if (!selectedCopyId || !material) return;
    const token = localStorage.getItem("token");
    if (!token) return;
    if (!form.registrationNo.trim()) {
      notify("❌ " + t("materials.copies.regNoRequired"), "error");
      return;
    }
    const res = await fetch(`${API_URL}/copies/${selectedCopyId}`, {
```

> ⚠️ 여기가 헷갈리기 쉬운 지점이에요! `handleAddCopy`는 첫 줄이 `if (!material) return;`이고, `handleUpdateCopy`는 첫 줄이 `if (!selectedCopyId || !material) return;`이라서 살짝 더 길어요. 지금 보고 계신 코드가 `selectedCopyId`라는 글자가 있는 쪽이 맞는지 꼭 확인해주세요.

이번엔 **새 함수를 또 추가하지 않아요.** (`validateRequiredFields` 함수는 A단계에서 이미 한 번 만들었고, 그 함수를 이 아래에서도 그대로 재사용할 거예요.) 그냥 안쪽에 있는 아래 5줄만 지워주세요.

**이 5줄을 지워주세요:**

```tsx
    if (!form.registrationNo.trim()) {
      notify("❌ " + t("materials.copies.regNoRequired"), "error");
      return;
    }
```

**그 자리에 이 1줄만 새로 입력해주세요:**

```tsx
    if (!validateRequiredFields()) return;
```

다 하고 나면, `handleUpdateCopy` 함수 전체가 이런 모습이 되어야 해요.

```tsx
  async function handleUpdateCopy() {
    if (!selectedCopyId || !material) return;
    const token = localStorage.getItem("token");
    if (!token) return;
    if (!validateRequiredFields()) return;
    const res = await fetch(`${API_URL}/copies/${selectedCopyId}`, {
      method: "PATCH",
      headers: { "Content-Type": "application/json", Authorization: `Bearer ${token}` },
      body: JSON.stringify(form),
    });
    if (res.ok) {
      notify("✅ " + t("materials.copies.updateSuccess"), "success");
      await refreshMaterial(material.id);
      setShowModal(false);
    } else {
      const data = await res.json().catch(() => null);
      notify("❌ " + (data?.message || t("materials.copies.updateFail")), "error");
    }
  }
```

## 정리: 결국 이렇게 3군데가 바뀌는 거예요

1. `handleAddCopy` **바로 위**에 `validateRequiredFields` 함수가 **새로 하나 생김** (1번만)
2. `handleAddCopy` **안쪽**의 등록번호 확인 5줄 → `if (!validateRequiredFields()) return;` 1줄로 **교체**
3. `handleUpdateCopy` **안쪽**의 등록번호 확인 5줄 → `if (!validateRequiredFields()) return;` 1줄로 **교체**

`validateRequiredFields` 함수는 딱 한 번만 만들면 되고, 두 함수(`handleAddCopy`, `handleUpdateCopy`)가 이 함수를 공통으로 가져다 쓰는 구조예요.

## ✅ 확인하기

파일을 저장한 뒤, 아래처럼 보이면 정확히 된 거예요.

- `Ctrl+F`로 `validateRequiredFields`를 검색하면 **총 3번** 나와야 해요. (함수를 만든 곳 1번 + `handleAddCopy` 안에서 부르는 곳 1번 + `handleUpdateCopy` 안에서 부르는 곳 1번)
