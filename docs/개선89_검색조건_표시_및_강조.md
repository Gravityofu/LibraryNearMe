# 개선89: 검색 조건 문구 표시 + 검색된 글자 굵게 강조하기

## 목표

'목록' 메뉴와 '회원' 메뉴에서 상세 검색(또는 등록번호 검색)을 하면, 지금은 결과만 보이고 "무엇으로 검색했는지"는 화면 어디에도 나오지 않습니다. 이 가이드는 두 가지를 추가합니다.

1. 검색 버튼들이 있는 줄에서 마지막 버튼 오른쪽에 여백을 두고, 지금 어떤 조건으로 검색했는지 보여주는 문구를 추가합니다. ('목록' 메뉴는 '등록번호 검색' 버튼 오른쪽, '회원' 메뉴는 '상세 검색' 버튼 오른쪽입니다.)
2. 검색 결과 목록에서, 검색어와 일치하는 글자 부분을 굵게 표시해서 눈에 잘 띄도록 합니다.

### 2-1. 검색어를 굵게 표시해주는 부품과, 검색 조건 문구를 만들어주는 함수를 추가하기

아래 내용을 찾으세요.

```typescript
const PAGE_SIZE_OPTIONS = [10, 20, 30, 40, 50];
const COLUMN_COUNT = 11;
```

이 내용을 아래 내용으로 바꿔주세요.

```typescript
const PAGE_SIZE_OPTIONS = [10, 20, 30, 40, 50];
const COLUMN_COUNT = 11;

// 정규식에서 특별한 의미를 가지는 글자(. * + ? 등)를 그냥 글자 그대로 찾도록 앞에 \를 붙여줍니다.
function escapeForSearch(str: string) {
  return str.replace(/[.*+?^${}()|[\]\\]/g, "\\$&");
}

// text 안에서 query와 일치하는 부분을 찾아 굵게 표시합니다. (대소문자 구분 안 함)
function Highlight({ text, query }: { text: string; query?: string }) {
  if (!query || !query.trim() || !text) return <>{text}</>;
  const q = query.trim();
  const parts = text.split(new RegExp(`(${escapeForSearch(q)})`, "gi"));
  return (
    <>
      {parts.map((part, i) =>
        part.toLowerCase() === q.toLowerCase() ? (
          <strong key={i} className="font-bold">
            {part}
          </strong>
        ) : (
          <span key={i}>{part}</span>
        ),
      )}
    </>
  );
}
```

**설명:** `Highlight`는 텍스트 하나와 검색어 하나를 받아서, 검색어와 일치하는 부분만 `<strong>`(굵은 글씨)로 감싸주는 부품입니다. 검색어가 없으면 원래 글자를 그대로 보여줍니다.

### 2-2. 검색 조건을 문구로 만들어주는 함수 추가하기

아래 내용을 찾으세요.

```typescript
  function changePageSize(size: number) {
    setPageSize(size);
    if (hasSearched) {
      fetchList(1, size, filters);
    }
  }

  const totalPages = Math.max(1, Math.ceil(total / pageSize));
```

이 내용을 아래 내용으로 바꿔주세요.

```typescript
  function changePageSize(size: number) {
    setPageSize(size);
    if (hasSearched) {
      fetchList(1, size, filters);
    }
  }

  // 지금 적용된 검색 조건(filters)을 사람이 읽을 수 있는 문구로 만들어줍니다.
  function buildSearchSummary(f: Filters): string {
    const parts: string[] = [];
    if (f.type) {
      const typeInfo = materialTypes.find((m) => m.code === f.type);
      const name = typeInfo ? (lang === "ko" ? typeInfo.nameKo ?? f.type : typeInfo.nameEn ?? f.type) : f.type;
      parts.push(`${t("materials.new.typeLabel")} '${name}'`);
    }
    if (f.title) parts.push(`${t("materials.new.field.title")} '${f.title}'`);
    if (f.creator) parts.push(`${t("materials.new.field.creator")} '${f.creator}'`);
    if (f.subject) parts.push(`${t("materials.new.field.subject")} '${f.subject}'`);
    if (f.registrationNos && f.registrationNos.length > 0) {
      parts.push(`${t("materials.list.col.registrationNo")} '${f.registrationNos.join(", ")}'`);
    }
    return parts.join(", ");
  }

  const searchSummary = hasSearched ? buildSearchSummary(filters) : "";

  const totalPages = Math.max(1, Math.ceil(total / pageSize));
```

**설명:** `buildSearchSummary`는 지금 적용된 검색 조건(`filters`)을 살펴보고, 실제로 값이 있는 항목만 골라서 "유형 'OO', 서명 'OO'"처럼 문구로 만들어줍니다. 상세 검색을 했다면 유형/서명/저자/주제 중 채워진 것만, 등록번호 검색을 했다면 등록번호 목록이 문구에 들어갑니다.

이 내용을 아래 내용으로 바꿔주세요.

```typescript

                      {row.registrationNo ? (
                        filters.registrationNos && filters.registrationNos.length > 0 ? (
```
