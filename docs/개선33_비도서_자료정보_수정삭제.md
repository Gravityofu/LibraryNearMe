# 개선33. 비도서 자료 - 전체 정보 표시 + 수정 + 삭제 기능

## 🎯 목표

MARC 편집기를 쓰지 않는 자료(보드게임, 웹페이지, 법령 등)를 클릭해서 들어가면, 왼쪽 박스에 제목·저자·발행처·발행년, 이 4개만 보이고 있었어요. 등록할 때 입력했던 나머지 정보(ISBN, 분류기호, 형태, 주제어, 사용 언어, 설명, 표지 URL, 자료 위치 URL)는 화면 어디에도 안 보이고 있었어요.

이번엔 이렇게 고칠게요.

1. 등록된 정보를 **전부** 보여줘요.
2. 그 자리에서 바로 **수정**할 수 있게 해요.
3. **삭제**도 할 수 있게 해요. 단, 이 자료에 실물(Copy)이 하나라도 등록되어 있으면 "실물이 있어서 삭제할 수 없다"는 안내와 함께 삭제를 막아요. 실물이 하나도 없을 때만 삭제가 진행돼요.
4. 박스 제목도 상황에 맞게 바꿔요. MARC 편집기를 쓰는 자료(도서·DVD)는 지금처럼 'MARC 정보'로, MARC를 안 쓰는 자료는 **'자료 등록정보'**로 보여요.

> 💡 실제 파일(`materials.controller.ts`, `materials.service.ts`, `dictionary.ts`, `materials/copies/page.tsx`)을 확인해서 작성했어요.

### 무슨 코드인가요?

- `updateMaterialSimple()`은 MARC를 쓰지 않는 자료의 정보를 통째로 받아 그대로 저장해요. `updateMaterialMarc()`(MARC 자동추출용)와는 별도의 함수라서, 도서·DVD 수정 기능에는 전혀 영향을 주지 않아요.
- `removeMaterial()`은 자료를 지우기 전에 그 자료에 딸린 실물(`copies`)이 있는지 먼저 확인해요. 하나라도 있으면 몇 건 있는지 메시지로 알려주면서 삭제를 막아요.
- 라우트도 각각 `/materials/:id/simple`(수정), `/materials/:id`의 `DELETE`(삭제)로 따로 만들어서, 기존 `/materials/:id`의 `PATCH`(MARC 수정)와 겹치지 않게 했어요.

```tsx
                        value={simpleForm[f.key as keyof typeof simpleForm]}
                        onChange={(e) => setSimpleForm({ ...simpleForm, [f.key]: e.target.value })}
                        className="w-full rounded-lg border border-neutral-200 bg-white px-3 py-2 text-sm"
                      />
                    </label>
                  ))}
                </div>

                <div className="mt-4">
                  <ThemedButton preset="버튼1" onClick={handleSaveSimple} className="w-full">
                    {t("materials.copies.save")}
                  </ThemedButton>
                </div>

                <button
                  onClick={handleDeleteMaterial}
                  className="mt-2 w-full cursor-pointer rounded-lg bg-red-600 py-2.5 text-sm font-semibold text-white hover:bg-red-700"
                >
                  {t("materials.copies.deleteMaterialBtn")}
                </button>
              </div>
            )}
          </div>
        </div>
```

### 무슨 코드인가요?

- `SIMPLE_MATERIAL_FIELDS` 목록에 맞춰 입력칸을 하나씩 그려요. 자료 등록 화면(`materials/new/page.tsx`)에서 썼던 것과 같은 필드 이름·라벨을 그대로 재사용했어요.
- `자료 위치 URL`(`onlineUrl`)은 실물 자료(`isPhysical`)일 때는 안 보이게 필터링했어요. 실물 자료에는 원래 필요 없는 항목이니까요.
- '저장' 버튼을 누르면 `handleSaveSimple()`이 실행돼서 `/materials/:id/simple`로 전체 내용을 저장해요.
- '이 자료 삭제' 버튼을 누르면 확인창이 뜨고, '확인'을 누르면 `/materials/:id`로 삭제 요청을 보내요. 만약 이 자료에 실물이 남아있으면 서버가 거부하면서 몇 건 남아있는지 알림으로 보여줘요. 실물이 하나도 없을 때만 실제로 삭제되고, 삭제되면 자동으로 자료 목록 화면으로 돌아가요.
- 박스 제목은 `usesMarc` 값에 따라 'MARC 정보' 또는 '자료 등록정보'로 바뀌어요.
