# 개선 55: '대출/반납일 변경' 버튼과 날짜 입력 칸을 하나로 묶어 보이게 하기

## 목표

지금은 '대출/반납일 변경' 버튼과 날짜 입력 칸이 각각 따로 테두리와 둥근 모서리를 가지고 있어서, 두 부품이 서로 다른 기능인 것처럼 뚝 떨어져 보입니다. 이번에는 두 부품을 하나의 테두리로 감싸고, 가운데에 얇은 구분선만 넣어서 "버튼을 누르면 이 옆 칸의 날짜가 바뀐다"는 것이 한눈에 느껴지도록 디자인을 바꿉니다. (검색창 옆에 검색 버튼이 붙어 있는 것과 비슷한 느낌입니다.)

버튼에는 옅은 회색 배경을 넣어서 "이건 버튼이다"라는 것을 구분하고, 입력 칸을 클릭(포커스)했을 때는 파란색 테두리가 살짝 들어오게 해서 지금 이 칸을 수정하고 있다는 것도 알 수 있게 합니다.

무엇이 달라졌는지 설명드립니다.

- 바깥쪽 `<div>`가 이제 버튼과 입력 칸을 함께 감싸는 테두리(`border border-neutral-300`)와 둥근 모서리(`rounded-lg`)를 가집니다. `overflow-hidden`은 안쪽 내용이 이 둥근 모서리 밖으로 삐져나오지 않게 해줍니다.
- 버튼과 입력 칸 사이의 빈틈(`gap-2`)을 없앴고, 대신 버튼 오른쪽에만 얇은 구분선(`border-r`)을 넣어서 둘이 붙어 있는 하나의 부품처럼 보이게 했습니다.
- 버튼에 `bg-neutral-100`(옅은 회색 배경)을 넣어서 이 부분이 클릭 가능한 버튼이라는 것을 더 잘 알 수 있게 했습니다.
- 입력 칸 자체의 테두리와 둥근 모서리는 없앴습니다(`border-0`). 대신 이 칸을 클릭(포커스)하면 `focus:ring-2 focus:ring-blue-400`으로 파란색 테두리가 안쪽에 나타나서, 지금 이 칸이 활성화되어 있다는 것을 보여줍니다.
