# 17단계 (2) — "도서관 설정" 메뉴를 "설정" 메뉴 안으로 이동

> 목표: 사이드바에 따로 있던 "도서관 설정" 메뉴를 없애고, 그 내용을 "설정"
> 메뉴 화면 안에 "도서관"이라는 탭(버튼)으로 넣습니다. "설정" 화면을 열면
> 기존처럼 "KORMARC 태그" 탭과 새로운 "도서관" 탭 중에서 골라볼 수 있게 됩니다.
> 소요 시간: 약 20분

---

## 1. "도서관 설정" 화면 내용을 부품(컴포넌트)으로 분리하기 — 약 8분

`frontend/src/components` 폴더 안에 **`library-settings-form.tsx`** 파일을
새로 만들고 아래 내용을 붙여넣습니다. (지금 `frontend/src/app/admin/page.tsx`
안에 있던 입력 폼 내용을 그대로 옮긴 거예요. 로그인 여부를 화면 단에서 따로
확인하던 부분만 뺐어요 — "설정" 화면 자체가 이미 관리자만 들어올 수 있게
막혀 있기 때문이에요.)

```tsx
"use client";

import { useEffect, useState } from "react";
import { Button } from "@/components/ui/button";
import { Input } from "@/components/ui/input";
import { Label } from "@/components/ui/label";
import { useI18n } from "@/components/language-provider";
import { useNotify } from "@/components/notify-provider";

const API_URL = "http://localhost:3001";

export default function LibrarySettingsForm() {
  const { t } = useI18n();
  const { notify } = useNotify();
  const [name, setName] = useState("");
  const [primaryColor, setPrimaryColor] = useState("#2563eb");
  const [logoUrl, setLogoUrl] = useState("");
  const [chromeBgColor, setChromeBgColor] = useState("#383838");
  const [chromeTextColor, setChromeTextColor] = useState("#F9F6F0");
  const [footerVersion, setFooterVersion] = useState("1.0.0");
  const [footerCopyright, setFooterCopyright] = useState("ⓒ 2026 Gravityofu");

  useEffect(() => {
    fetch(`${API_URL}/library`)
      .then((res) => res.json())
      .then((data) => {
        if (data) {
          setName(data.name);
          setPrimaryColor(data.primaryColor);
          setLogoUrl(data.logoUrl || "");
          setChromeBgColor(data.chromeBgColor || "#383838");
          setChromeTextColor(data.chromeTextColor || "#F9F6F0");
          setFooterVersion(data.footerVersion || "1.0.0");
          setFooterCopyright(data.footerCopyright || "ⓒ 2026 Gravityofu");
        }
      });
  }, []);

  async function handleSave() {
    const token = localStorage.getItem("token");
    if (!token) return;
    const res = await fetch(`${API_URL}/library`, {
      method: "PATCH",
      headers: { "Content-Type": "application/json", Authorization: `Bearer ${token}` },
      body: JSON.stringify({
        name,
        primaryColor,
        logoUrl,
        chromeBgColor,
        chromeTextColor,
        footerVersion,
        footerCopyright,
      }),
    });
    if (res.ok) {
      notify(t("admin.settings.saved"), "success");
    } else {
      const data = await res.json().catch(() => null);
      notify("❌ " + (data?.message || t("admin.settings.saveFail")), "error");
    }
  }

  return (
    <div className="max-w-md">
      <div className="flex flex-col gap-4">
        <div className="flex flex-col gap-2">
          <Label htmlFor="name">{t("admin.settings.name")}</Label>
          <Input id="name" value={name} onChange={(e) => setName(e.target.value)} />
        </div>
        <div className="flex flex-col gap-2">
          <Label htmlFor="color">{t("admin.settings.color")}</Label>
          <Input id="color" type="color" value={primaryColor} onChange={(e) => setPrimaryColor(e.target.value)} className="h-10 w-20 p-1" />
        </div>
        <div className="flex flex-col gap-2">
          <Label htmlFor="logoUrl">{t("admin.settings.logoUrl")}</Label>
          <Input id="logoUrl" value={logoUrl} onChange={(e) => setLogoUrl(e.target.value)} placeholder="https://..." />
        </div>
        <div className="flex flex-col gap-2">
          <Label htmlFor="chromeBg">{t("admin.settings.chromeBgColor")}</Label>
          <Input
            id="chromeBg"
            type="color"
            value={chromeBgColor}
            onChange={(e) => setChromeBgColor(e.target.value)}
            className="h-10 w-20 p-1"
          />
        </div>
        <div className="flex flex-col gap-2">
          <Label htmlFor="chromeText">{t("admin.settings.chromeTextColor")}</Label>
          <Input
            id="chromeText"
            type="color"
            value={chromeTextColor}
            onChange={(e) => setChromeTextColor(e.target.value)}
            className="h-10 w-20 p-1"
          />
        </div>
        <div className="flex flex-col gap-2">
          <Label htmlFor="footerVersion">{t("admin.settings.footerVersion")}</Label>
          <Input id="footerVersion" value={footerVersion} onChange={(e) => setFooterVersion(e.target.value)} />
        </div>
        <div className="flex flex-col gap-2">
          <Label htmlFor="footerCopyright">{t("admin.settings.footerCopyright")}</Label>
          <Input id="footerCopyright" value={footerCopyright} onChange={(e) => setFooterCopyright(e.target.value)} />
        </div>
        <Button className="cursor-pointer" onClick={handleSave}>
          {t("admin.settings.save")}
        </Button>
      </div>
    </div>
  );
}
```

## 2. "설정" 화면에 "도서관" 탭 추가 — 약 6분

`frontend/src/app/admin/settings/page.tsx` 를 엽니다.

### 2-1. import 추가

맨 위, 아래 부분을 찾으세요.

```tsx
import { Tabs, TabsContent, TabsList, TabsTrigger } from "@/components/ui/tabs";
import { useNotify } from "@/components/notify-provider";
import { useI18n } from "@/components/language-provider";
```

이렇게 바꿔주세요.

```tsx
import { Tabs, TabsContent, TabsList, TabsTrigger } from "@/components/ui/tabs";
import { useNotify } from "@/components/notify-provider";
import { useI18n } from "@/components/language-provider";
import LibrarySettingsForm from "@/components/library-settings-form";
```

### 2-2. 탭 목록에 "도서관" 추가

아래 부분을 찾으세요.

```tsx
      <Tabs defaultValue="kormarcTags">
        <TabsList>
          <TabsTrigger value="kormarcTags">{t("settings.tabs.kormarcTags")}</TabsTrigger>
        </TabsList>
```

이렇게 바꿔주세요.

```tsx
      <Tabs defaultValue="kormarcTags">
        <TabsList>
```

### 2-3. "도서관" 탭 내용 추가

아래 부분을 찾으세요. (파일 안에서 한 곳뿐이라 쉽게 찾을 수 있어요.)

## 5. `/admin` 주소로 직접 들어와도 "설정" 화면으로 보내기 — 약 4분

`frontend/src/app/admin/page.tsx` 를 엽니다. 파일 전체 내용을 아래로 통째로
바꿔주세요. (이제 이 화면은 아무것도 보여줄 필요가 없어요. 사이드바 메뉴를
다 지웠지만, 혹시 누군가 주소창에 `/admin`을 직접 쳐서 들어올 수도 있으니
"설정" 화면으로 자동으로 보내주기만 합니다.)

```tsx
"use client";

import { useEffect } from "react";
import { useRouter } from "next/navigation";

export default function AdminIndexPage() {
  const router = useRouter();

  useEffect(() => {
    router.replace("/admin/settings");
  }, [router]);

  return null;
}
```

## 6. 확인하기 — 약 5분

1. 관리자 페이지 사이드바에 더 이상 "도서관 설정" 메뉴가 보이지 않는지
   확인합니다.
2. "설정" 메뉴를 클릭하면 위쪽에 "KORMARC 태그"와 "도서관" 탭 두 개가
   보이는지 확인합니다.
3. "도서관" 탭을 클릭하면 이전 "도서관 설정" 화면(이름/색상/로고/Footer
   설정)이 그대로 나오는지 확인합니다.
4. 이름이나 색상을 바꾸고 저장하면 정상적으로 저장되는지 확인합니다.
5. 주소창에 직접 `/admin`을 쳐서 들어가면 자동으로 `/admin/settings`로
   이동하는지 확인합니다.
6. "KORMARC 태그" 탭도 예전처럼 잘 동작하는지 확인합니다.

✅ 모두 확인되면 성공입니다! 🎉
