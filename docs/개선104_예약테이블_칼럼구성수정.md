# 개선104: '예약' 페이지 표의 칼럼 구성 수정

## 목표

'예약' 페이지 표의 칼럼(제목 줄)을 아래와 같이 고칩니다.

- '보관예정일'을 '보관마감일'로 이름 변경
- '소장처' 칼럼 삭제
- 칼럼 순서를 **번호 → 예약 상태 → 예약일 → 보관마감일 → 등록번호 → 자료명 → 저자 → 회원번호 → 회원이름** 순으로 변경

칼럼 이름표와 순서만 바뀌고, 표 자체는 개선100에서 만든 것처럼 아직 실제 데이터와 연결되어 있지 않아 계속 빈 상태로 나옵니다.

---

## 1단계: 칼럼 문구 수정하기 (`dictionary.ts`)

`frontend/src/lib/dictionary.ts` 파일을 여세요.

### 1-1. 한국어 문구 수정하기

아래 내용을 찾으세요.

```typescript
    "loans.reservation.col.holdDueDate": "보관예정일",
```

이 내용을 아래 내용으로 바꿔주세요.

```typescript
    "loans.reservation.col.holdDueDate": "보관마감일",
```

### 1-2. 영어 문구도 함께 맞춰주기

아래 내용을 찾으세요.

```typescript
    "loans.reservation.col.holdDueDate": "Hold Due Date",
```

이 내용을 아래 내용으로 바꿔주세요.

```typescript
    "loans.reservation.col.holdDueDate": "Hold Deadline",
```

**참고:** '소장처' 문구(`loans.reservation.col.location`)는 이제 화면에서 쓰지 않지만, 다른 곳에서 이 문구를 다시 쓸 수도 있으니 그대로 남겨두셔도 괜찮습니다.

---

## 2단계: 표 칼럼 개수를 10개에서 9개로 줄이기

**무엇을, 왜 바꾸나요:** '소장처' 칼럼이 없어지면서 표의 전체 칼럼 개수가 10개에서 9개로 줄어듭니다. `RESERVATION_COLUMN_COUNT`는 검색 결과가 없을 때 "표시할 예약 자료가 없습니다" 문구가 표 가로 폭 전체에 걸쳐 나오게 하는 값이라, 실제 칼럼 개수와 맞춰줘야 합니다.

`frontend/src/app/admin/loans/page.tsx` 파일을 여세요.

아래 내용을 찾으세요.

```typescript
const RESERVATION_COLUMN_COUNT = 10;
```

이 내용을 아래 내용으로 바꿔주세요.

```typescript
const RESERVATION_COLUMN_COUNT = 9;
```
