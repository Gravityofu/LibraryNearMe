# 개선157. 글쓰기 화면에 썸네일용 사진 권장 크기 안내 문구 추가

## 목표

먼저, 사진이 잘리지 않는 비율을 알려드립니다.

- **가로형(한 줄 3개) 게시판**: 상자 비율이 **16:9**입니다. 예) 1600×900px, 1280×720px
- **세로형(한 줄 4개) 게시판**: 상자 비율이 **3:4**입니다. 예) 900×1200px, 1200×1600px

이 비율에 맞는 사진을 올리면 잘리는 부분 없이 상자에 꽉 차게 나옵니다. (정확히 이 비율이 아니어도 괜찮습니다 — 개선156에서 적용한 방식은 조금만 어긋나도 자연스럽게 필요한 만큼만 잘라서 보여주기 때문에 실사용에는 문제가 없습니다. 다만 정확히 맞추면 전혀 잘리지 않습니다.)

이번 가이드에서는, 썸네일형 게시판의 글쓰기 화면(관리자 페이지 + 홈페이지)에서 내용 입력창 위에 "썸네일용 사진(첫 번째 사진)은 OOOpx × OOOpx로 올려주세요."라는 안내 문구가 게시판의 가로형/세로형 설정에 맞춰 자동으로 나오게 합니다. 목록형 게시판이나 썸네일이 필요 없는 게시판에서는 이 문구가 나오지 않습니다.

바꾸는 파일은 3개입니다.
1. `frontend/src/lib/dictionary.ts` (안내 문구 추가)
2. `frontend/src/app/(site)/boards/[code]/write/page.tsx` (홈페이지 글쓰기 화면)
3. `frontend/src/app/admin/boards/write/page.tsx` (관리자 페이지 글쓰기 화면)

---

## 1단계. 사전(dictionary.ts)에 안내 문구 추가하기

`frontend/src/lib/dictionary.ts` 파일을 여세요.

### 1-1. 한국어(ko) 섹션

아래 줄을 찾으세요.

```
    "boards.write.field.content": "내용",
```

이 줄 **바로 아래**에 두 줄을 추가하세요.

```
    "boards.write.thumbnailHint.wide": "썸네일용 사진(첫 번째 사진)은 1600 x 900px (16:9 비율)로 올려주시면 잘리지 않고 깔끔하게 나옵니다.",
    "boards.write.thumbnailHint.tall": "썸네일용 사진(첫 번째 사진)은 900 x 1200px (3:4 비율)로 올려주시면 잘리지 않고 깔끔하게 나옵니다.",
```

### 1-2. 영어(en) 섹션

아래 줄을 찾으세요.

```
    "boards.write.field.content": "Content",
```

이 줄 **바로 아래**에 두 줄을 추가하세요.

```
    "boards.write.thumbnailHint.wide": "For the thumbnail image (first image), please upload one sized 1600 x 900px (16:9 ratio) so it fits without cropping.",
    "boards.write.thumbnailHint.tall": "For the thumbnail image (first image), please upload one sized 900 x 1200px (3:4 ratio) so it fits without cropping.",
```

## 2단계. 홈페이지 글쓰기 화면 수정

`frontend/src/app/(site)/boards/[code]/write/page.tsx` 파일을 여세요.

### 2-1. `Board` 타입에 게시판 형태 정보 추가

아래 코드를 찾으세요.

```typescript
type Board = {
  id: number;
  code: string;
  name: string;
  allowMemberWrite: boolean;
  allowGuestWrite: boolean;
  isMaterialRequest: boolean;
};
```

아래로 바꿔주세요.

```typescript
type Board = {
  id: number;
  code: string;
  name: string;
  allowMemberWrite: boolean;
  allowGuestWrite: boolean;
  isMaterialRequest: boolean;
  listStyle: "LIST" | "THUMBNAIL";
  thumbnailRatio: "WIDE" | "TALL";
};
```

### 2-2. 내용 입력창 위에 안내 문구 넣기

아래 코드를 찾으세요.

```typescript
        <div>
          <span className="mb-1 block text-sm text-neutral-500">{t("boards.write.field.content")} *</span>
          <RichTextEditor
            value={content}
            onChange={setContent}
            imageUploadUrl={`${API_URL}/uploads/public-board-image`}
          />
        </div>
```

아래로 바꿔주세요.

```typescript
        <div>
          <span className="mb-1 block text-sm text-neutral-500">{t("boards.write.field.content")} *</span>
          {board.listStyle === "THUMBNAIL" && (
            <p className="mb-2 text-xs text-neutral-400">
              {board.thumbnailRatio === "TALL"
                ? t("boards.write.thumbnailHint.tall")
                : t("boards.write.thumbnailHint.wide")}
            </p>
          )}
          <RichTextEditor
            value={content}
            onChange={setContent}
            imageUploadUrl={`${API_URL}/uploads/public-board-image`}
          />
        </div>
```

## 3단계. 관리자 페이지 글쓰기 화면 수정

`frontend/src/app/admin/boards/write/page.tsx` 파일을 여세요.

### 3-1. `Board` 타입에 게시판 형태 정보 추가

아래 코드를 찾으세요.

```typescript
type Board = {
  id: number;
  code: string;
  name: string;
  isMaterialRequest: boolean;
};
```

아래로 바꿔주세요.

```typescript
type Board = {
  id: number;
  code: string;
  name: string;
  isMaterialRequest: boolean;
  listStyle: "LIST" | "THUMBNAIL";
  thumbnailRatio: "WIDE" | "TALL";
};
```

### 3-2. 내용 입력창 위에 안내 문구 넣기

아래 코드를 찾으세요.

```typescript
        <div>
          <span className="mb-1 block text-sm text-neutral-500">{t("boards.write.field.content")} *</span>
          <RichTextEditor value={content} onChange={setContent} />
        </div>
```

아래로 바꿔주세요.

```typescript
        <div>
          <span className="mb-1 block text-sm text-neutral-500">{t("boards.write.field.content")} *</span>
          {board?.listStyle === "THUMBNAIL" && (
            <p className="mb-2 text-xs text-neutral-400">
              {board.thumbnailRatio === "TALL"
                ? t("boards.write.thumbnailHint.tall")
                : t("boards.write.thumbnailHint.wide")}
            </p>
          )}
          <RichTextEditor value={content} onChange={setContent} />
        </div>
```

(관리자 페이지의 `board`는 아직 불러오는 중일 때 `null`일 수 있어서, `board.listStyle`이 아니라 `board?.listStyle`처럼 물음표를 붙였습니다. 이렇게 하면 `board`가 아직 없을 때 오류 없이 그냥 문구를 안 보여줍니다.)

## 확인하기

1. 관리자 페이지에서 썸네일형 & 가로형으로 설정된 게시판(예: '열린 게시판')의 글쓰기 화면을 열어, 내용 입력창 위에 "1600 x 900px (16:9 비율)" 안내 문구가 나오는지 확인합니다.
2. 썸네일형 & 세로형으로 설정된 게시판의 글쓰기 화면에서는 "900 x 1200px (3:4 비율)" 문구가 나오는지 확인합니다.
3. 목록형(LIST)으로 설정된 게시판(예: '참고서비스', 'FAQ')의 글쓰기 화면에서는 이 안내 문구가 아예 나오지 않는지 확인합니다.
4. 홈페이지 글쓰기 화면에서도 같은 방식으로 게시판 형태에 맞는 문구가 나오는지 확인합니다.
5. 관리자 페이지 > 게시판 메뉴에서 어떤 게시판의 목록 스타일/썸네일 비율을 바꿔보고, 그 게시판의 글쓰기 화면 문구도 바뀐 설정에 맞게 바뀌는지 확인합니다.
