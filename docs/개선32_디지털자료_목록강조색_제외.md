# 개선32. 자료 목록에서 디지털 자료는 '실물 미등록' 강조색 빼기

## 🎯 원인과 목표

자료 목록 화면(`materials/list/page.tsx`)은 실물(Copy)이 없는 행을 옅은 노란색(`bg-amber-50`)으로 표시해서, "아직 실물 등록이 안 된 자료"를 한눈에 알아볼 수 있게 해주고 있어요. 그런데 이 화면은 아직 예전 하드코딩 목록(`material-types.ts`)을 쓰고 있어서, 그 자료가 애초에 실물을 가질 수 있는 종류인지(실물 자료)와 상관없이 "실물이 하나도 없으면 무조건" 노란색으로 표시하고 있었어요. 그래서 원래부터 실물이 있을 수 없는 디지털 자료까지 다 노란색으로 표시되고 있었던 거예요.

이번엔 이 화면도 22단계에서 만든 `/material-types` API를 쓰도록 바꾸면서, **실물 자료인데 실물이 하나도 없을 때만** 노란색으로 표시하고, 디지털 자료는 실물이 있든 없든 항상 흰 배경으로 보이도록 고칠게요.

> 💡 `개선30`, `개선31`에서 `materials/copies/page.tsx`를 이미 이렇게 고쳤는데, 이번에 확인해보니 `materials/list/page.tsx`(자료 목록 화면)는 아직 예전 방식 그대로였어요. 이 파일도 같은 방식으로 맞춰드릴게요.

```tsx
            {hasSearched &&
              rows.map((row, i) => {
                const typeInfo = materialTypes.find((m) => m.code === row.material.type);
                // 실물 자료인데 실물이 하나도 없을 때만 노란색으로 표시해요. 디지털 자료는 원래 실물이 없을 수 있으니 표시하지 않아요.
```
