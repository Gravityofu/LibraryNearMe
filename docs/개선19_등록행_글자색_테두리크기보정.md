# 개선19. '새 실물 자료 등록' 행 - 글자색 변수화 & 테두리로 인한 크기 차이 보정

## 🎯 목표

이번엔 두 가지를 고쳐볼게요.

**1) 선택 해제됐을 때 글자색도 변수로**

지금은 다른 실물 자료 행을 클릭해서 '새 실물 자료 등록'이 해제되면, 테두리 색은 "버튼1" 색(변수)을 쓰는데 **글자색은 `text-black`으로 고정**되어 있어요. 이 글자색도 테두리와 똑같이 "버튼1" 배경색을 그대로 쓰도록 바꿔서, 나중에 관리자 설정에서 "버튼1" 색을 바꾸면 글자색도 같이 바뀌게 만들게요.

**2) 테두리가 생기면서 행 크기가 달라지는 문제 보정**

'새 실물 자료 등록' 행만 `border`(테두리)가 있고 나머지 기존 자료 행들은 테두리가 없다 보니, 테두리 두께(1px)만큼 이 행의 실제 크기가 미세하게 달라 보여요. 이건 `border` 대신 `box-shadow`로 테두리처럼 보이는 효과를 주는 방법으로 해결할 수 있어요. `box-shadow`는 실제 요소 크기(레이아웃)에 영향을 주지 않고, 그냥 시각적으로 테두리처럼 그려주기만 하거든요.

### 그림으로 보면

```
[전] border 사용                    [후] box-shadow 사용
┌──────────────────┐               ┌──────────────────┐
│                    │  ← 1px 두께   │                    │  ← 시각적으로는 똑같이 테두리처럼
│ 새 실물 자료 등록    │    만큼 다른   │  새 실물 자료 등록    │     보이지만, 실제 칸 크기는
│                    │    행보다      │                    │     다른 행과 완전히 동일
└──────────────────┘    살짝 커짐    └──────────────────┘
```

## 수정하기

**파일**: `frontend/src/app/admin/materials/copies/page.tsx`

아래 코드를 찾아주세요.

**찾기:**

```tsx
                <tr onClick={resetForm} className="cursor-pointer">
                  <td
                    colSpan={4}
                    className={`px-2 py-2 text-center font-semibold ${
                      selectedCopyId === null ? "" : "border text-black"
                    }`}
                    style={
                      selectedCopyId === null
                        ? { backgroundColor: button1Bg, color: button1Text }
                        : { borderColor: button1Bg }
                    }
                  >
```

**이렇게 바꿔주세요:**

```tsx
                <tr onClick={resetForm} className="cursor-pointer">
                  <td
                    colSpan={4}
                    className="px-2 py-2 text-center font-semibold"
                    style={
                      selectedCopyId === null
                        ? { backgroundColor: button1Bg, color: button1Text }
                        : { color: button1Bg, boxShadow: `inset 0 0 0 1px ${button1Bg}` }
                    }
                  >
```

### 무슨 코드인가요?

- `className`에서 `border text-black` 부분을 통째로 지웠어요. 이제 이 `<td>`는 항상 `px-2 py-2 text-center font-semibold`만 갖고, 테두리나 글자색은 전부 `style`에서 상황에 따라 정해요.
- 선택 해제 상태(`selectedCopyId !== null`)일 때:
  - `color: button1Bg`: 글자색을 "버튼1" **배경색**과 똑같이 맞췄어요. (테두리 색과 글자색이 같은 색을 쓰는 거예요.)
  - `boxShadow: `inset 0 0 0 1px ${button1Bg}``: `border` 대신 이 방식으로 테두리처럼 보이는 효과를 줘요. `inset`은 "요소 안쪽에 그린다"는 뜻이고, `0 0 0 1px`은 "테두리처럼 사방에 1px 두께로 그린다"는 뜻이에요. 이 방식은 실제 칸 크기를 전혀 바꾸지 않기 때문에, 다른 자료 행들과 높이/너비가 완전히 똑같이 유지돼요.
  - 색은 여전히 `button1Bg` **변수**를 그대로 쓰고 있어서, 하드코딩이 아니라 관리자 설정과 계속 연결되어 있어요.

## ✅ 확인하기

1. 백엔드와 프론트엔드를 실행해주세요.
2. 실물 등록 페이지에서 기존 자료 행을 하나 클릭해보세요.
3. '새 실물 자료 등록' 행에 테두리(선)와 글자색이 모두 "버튼1" 색으로 나오는지 확인해주세요.
4. 이때 '새 실물 자료 등록' 행의 높이/너비가 바로 아래(또는 위) 있는 기존 자료 행들과 완전히 똑같아 보이는지 확인해주세요. (자로 재는 느낌이 아니라, 눈으로 봤을 때 삐뚤빼뚤하지 않으면 성공이에요.)
5. 다시 '새 실물 자료 등록' 행을 클릭해서 등록 모드로 돌아왔을 때도 이상 없이 잘 보이는지 확인해주세요.
6. 관리자 설정 → 디자인 탭에서 "버튼1" 색을 바꿔보고, 이 행의 테두리/글자색이 같이 바뀌는지도 확인해주세요.
