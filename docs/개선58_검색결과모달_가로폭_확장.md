# 개선 58: 회원 검색 결과 모달 가로 길이 넓히기 (휴대폰 번호 전체 표시)

## 목표

개선57에서 회원번호/휴대폰번호가 항상 같은 위치에서 시작하도록 칸을 나눴는데, 모달 자체의 가로 폭이 좁아서 휴대폰 번호처럼 긴 값은 뒷부분이 말줄임(`...`) 처리되어 잘려 보일 수 있습니다. 이름이야 짧게 줄여 봐도 크게 문제되지 않지만, 회원번호와 휴대폰번호는 정확히 다 보여야 하는 중요한 정보이므로, 모달의 가로 폭 자체를 넓혀서 마지막 자리까지 잘리지 않고 모두 보이도록 고칩니다.

## 화면 수정하기: `page.tsx`

`C:\projects\LibraryNearMe\frontend\src\app\admin\loans\page.tsx` 파일을 여세요.

### 1. 회원 검색 결과 모달의 가로 폭 넓히기

아래 부분을 찾으세요. (파일에 `max-w-sm rounded-xl bg-white p-6 shadow-xl`이라는 글자가 여러 군데 있는데, 바로 위에 있는 주석(`{/* 회원 검색 결과 모달 */}`)으로 정확한 위치를 확인하세요.)

```tsx
      {/* 회원 검색 결과 모달 */}
      {showSearchModal && (
        <div
          className="fixed inset-0 z-50 flex items-center justify-center bg-black/40 p-4"
          onClick={() => setShowSearchModal(false)}
        >
          <div
            className="w-full max-w-sm rounded-xl bg-white p-6 shadow-xl"
            onClick={(e) => e.stopPropagation()}
          >
```

이렇게 바꿔주세요.

```tsx
      {/* 회원 검색 결과 모달 */}
      {showSearchModal && (
        <div
          className="fixed inset-0 z-50 flex items-center justify-center bg-black/40 p-4"
          onClick={() => setShowSearchModal(false)}
        >
          <div
            className="w-full max-w-md rounded-xl bg-white p-6 shadow-xl"
            onClick={(e) => e.stopPropagation()}
          >
```

(`max-w-sm`은 최대 가로 폭 384px, `max-w-md`는 최대 가로 폭 448px입니다. 64px 정도 더 넓어집니다.)

### 2. 회원번호/휴대폰번호 칸의 폭도 함께 넓히기

모달이 넓어진 만큼, 회원번호와 휴대폰번호가 표시되는 칸의 폭도 살짝 넓혀서 여유 있게 잘리지 않도록 합니다.

아래 부분을 찾으세요.

```tsx
                    className="grid cursor-pointer grid-cols-[1fr_84px_112px] items-center gap-2 rounded-lg border border-neutral-200 px-3 py-2 text-left text-sm hover:bg-neutral-50"
```

이렇게 바꿔주세요.

```tsx
                    className="grid cursor-pointer grid-cols-[1fr_92px_130px] items-center gap-2 rounded-lg border border-neutral-200 px-3 py-2 text-left text-sm hover:bg-neutral-50"
```

파일을 저장하세요.

## 확인하기

1. 프런트엔드 서버를 재시작하세요. (`npm run dev`)
2. '대출/반납' 화면에서, 검색했을 때 결과가 여러 명 나오는 검색어로 회원을 검색해보세요.
3. 모달의 가로 폭이 이전보다 넓어졌는지 확인하세요.
4. 휴대폰번호(예: `010-1234-5678`)가 끝자리까지 잘리지 않고 전부 보이는지 확인하세요.
5. 회원번호도 전부 잘리지 않고 보이는지 확인하세요.
6. 이름이 아주 긴 경우에는 여전히 말줄임(`...`) 처리가 안전하게 작동하는지 확인하세요.
