# 개선156. 썸네일 사진, 여백 없이 꽉 차게 보여주기

## 목표

지금은 사진 비율에 따라 상자 안에 흰 여백이 생기는 방식(전체 사진이 잘리지 않고 다 보이되, 남는 자리는 흰색)으로 되어 있습니다. 이번에는 반대로, **사진이 상자를 항상 꽉 채우도록** 바꿉니다. (사진 비율에 따라 위아래나 좌우 일부가 잘릴 수 있지만, 여백 없이 꽉 찬 모습으로 보입니다.)

이때도 아래 조건은 그대로 유지됩니다.

- 사진 상자의 크기는 게시판의 가로형/세로형 설정에 따라 항상 일정합니다. (개선154에서 만든 "여백(padding)으로 높이를 고정하는 방식"을 그대로 사용하기 때문에, 이 부분은 코드를 바꾸지 않아도 계속 유지됩니다.)
- 제목, 본문 요약, 작성자, 키워드가 시작하는 위치도 지금처럼 항상 고정됩니다. (개선153·155에서 만든 "내용이 없어도 자리를 비워두는" 방식이 그대로 유지되기 때문에 이 부분도 코드를 바꾸지 않아도 됩니다.)
- 화면 크기(반응형)에 따라 한 줄에 보이는 카드 개수와 카드 자체의 가로 폭이 달라지는데, 사진 상자는 항상 "카드 가로 폭 기준 비율"로 높이가 정해지므로 화면 크기가 바뀌어도 비율은 그대로 유지된 채 크기만 늘어나거나 줄어듭니다.

즉, 이번 수정은 **사진이 상자를 채우는 방식**(전체 다 보이게 vs 꽉 채워서 자르기) 한 가지만 바꾸는 것이고, 나머지 고정된 부분들은 전혀 건드리지 않습니다.

```typescript
                <div
                  className="relative w-full shrink-0 overflow-hidden bg-neutral-100"
                  style={{ paddingTop: isTallThumbnail ? "133.33%" : "56.25%" }}
                >
                  {row.thumbnailUrl ? (

                      alt=""
                      className="absolute inset-0 h-full w-full object-cover"
                    />
                  ) : (

                      {t("boards.list.col.thumbnail")}
                    </div>
                  )}
                </div>
```

### 무엇이 바뀌었는지

- `object-contain`(사진 전체가 잘리지 않게, 남는 자리는 흰 여백) → `object-cover`(사진 비율은 유지한 채, 상자를 꽉 채우도록 필요한 만큼 잘라서 보여줌)로 바꿨습니다. 이제 사진 비율과 상관없이 상자 안에 여백 없이 꽉 차 보입니다.
- 바깥 상자의 배경색을 `bg-white`에서 `bg-neutral-100`(연한 회색)으로 바꿨습니다. `object-cover`는 상자를 항상 완전히 채우기 때문에 이 배경색이 실제로 보일 일은 없지만, 혹시 사진 로딩 중 잠깐 비치는 순간에도 사진 없는 카드의 회색과 자연스럽게 어울리도록 맞췄습니다.
- 사진 상자의 크기(가로세로 비율)를 정하는 `paddingTop` 부분, 그리고 반응형으로 카드 개수·폭이 조절되는 grid 부분은 전혀 건드리지 않았습니다. 화면 크기가 달라져도 상자는 항상 카드 폭을 기준으로 정확한 비율(세로형 3:4, 가로형 16:9)을 유지합니다.

## 확인하기

1. 가로형 게시판('열린 게시판', '컬렉션' 등)에서 가로가 긴 사진과 세로가 긴 사진을 나란히 확인합니다. 두 사진 모두 상자를 꽉 채우고, 흰 여백이 없는지 확인합니다.
2. 세로가 매우 긴 사진은 위아래가, 가로가 매우 긴 사진은 좌우가 일부 잘려서 보이는지 확인합니다. (이건 정상입니다 — 꽉 채우는 대신 일부가 잘리는 방식이기 때문입니다.)
3. 브라우저 창 크기를 줄였다 늘렸다 하면서(또는 휴대폰 화면으로) 카드 크기가 화면에 맞게 반응형으로 조절되는지, 그때도 사진이 상자를 꽉 채운 채로 비율이 유지되는지 확인합니다.
4. 제목·본문 요약·작성자·키워드가 시작하는 위치가 사진 비율과 상관없이 모든 카드에서 여전히 동일한지 확인합니다.
5. 세로형(한 줄 4개) 게시판도 동일하게 잘 작동하는지 확인합니다.
6. 사진을 첨부하지 않은 글은 회색 안내 상자가 그대로 나오는지 확인합니다.
