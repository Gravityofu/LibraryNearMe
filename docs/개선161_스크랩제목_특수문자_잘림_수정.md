# 개선161. 가져온 제목의 특수 문자·잘림 문제 수정

## 목표

두 가지 문제를 함께 고칩니다.

1. 제목에 `&#160;`처럼 HTML 코드가 그대로 글자로 섞여 나오는 문제
2. 제목에 작은따옴표(`'`)가 들어있으면 그 뒤가 통째로 잘려서 나오는 문제

## 원인

**1번 문제**: `&#160;`는 "줄바꿈 없는 빈칸(공백)"을 나타내는 HTML 코드입니다. 지금 코드는 `&amp;`, `&quot;`, `&#39;`, `&lt;`, `&gt;` 이렇게 딱 5가지 코드만 원래 글자로 바꿔주고 있어서, `&#160;`처럼 숫자로 된 다른 코드는 그대로 글자로 남아서 보였던 것입니다.

**2번 문제**가 더 중요한 원인인데, 지금 코드는 `content="..."` 부분의 값을 읽어올 때 "큰따옴표(")나 작은따옴표(')가 나오기 전까지"를 제목으로 읽어옵니다. 이건 원래 "content 값이 큰따옴표로 시작했으면 큰따옴표에서 끝나고, 작은따옴표로 시작했으면 작은따옴표에서 끝난다"는 걸 표현하려던 것인데, 코드가 조금 단순하게 되어 있어서 **시작할 때 어떤 따옴표를 썼는지와 상관없이 큰따옴표든 작은따옴표든 먼저 나오는 아무 따옴표에서 멈춰버립니다.** 그래서 `content="...학생들이 장관에게 건넨 '혐오 예방법'..."`처럼 **큰따옴표로 둘러싸인 값 안에 작은따옴표(')가 포함된 경우**, 그 작은따옴표를 값이 끝나는 지점으로 착각해서 그 뒤 글자를 다 잘라버린 것입니다.

## 수정 방법

`backend/src/scrap/scrap.service.ts` 파일을 여세요.

### 1. 따옴표 잘림 문제 수정

아래 코드를 찾으세요.

```typescript
  // HTML 문자열 안에서 <meta property="이름" content="값"> 형태를 찾습니다.
  private findMetaByProperty(html: string, property: string): string | null {
    const patterns = [
      new RegExp(`<meta[^>]+property=["']${property}["'][^>]*content=["']([^"']*)["']`, 'i'),
      new RegExp(`<meta[^>]+content=["']([^"']*)["'][^>]*property=["']${property}["']`, 'i'),
    ];
    for (const re of patterns) {
      const m = html.match(re);
      if (m) return this.decodeHtmlEntities(m[1]);

    return null;
```

아래로 바꿔주세요. (시작할 때 쓴 따옴표와 **똑같은** 따옴표가 다시 나올 때까지 값으로 읽도록 수정)

```typescript
  // HTML 문자열 안에서 <meta property="이름" content="값"> 형태를 찾습니다.
  private findMetaByProperty(html: string, property: string): string | null {
    const patterns = [
      new RegExp(`<meta[^>]+property=["']${property}["'][^>]*content=(["'])([\\s\\S]*?)\\1`, 'i'),
      new RegExp(`<meta[^>]+content=(["'])([\\s\\S]*?)\\1[^>]*property=["']${property}["']`, 'i'),
    ];
    for (const re of patterns) {
      const m = html.match(re);
      if (m) return this.decodeHtmlEntities(m[2]);
    }
    return null;
  }

  // HTML 문자열 안에서 <meta name="이름" content="값"> 형태를 찾습니다.
  private findMetaByName(html: string, name: string): string | null {
    const patterns = [
      new RegExp(`<meta[^>]+name=["']${name}["'][^>]*content=(["'])([\\s\\S]*?)\\1`, 'i'),
      new RegExp(`<meta[^>]+content=(["'])([\\s\\S]*?)\\1[^>]*name=["']${name}["']`, 'i'),
    ];
    for (const re of patterns) {
      const m = html.match(re);
      if (m) return this.decodeHtmlEntities(m[2]);
    }
    return null;
  }
```

**바뀐 점**: `(["'])`로 시작 따옴표가 큰따옴표인지 작은따옴표인지를 먼저 기억해두고(괄호로 묶어서 "1번 기억"으로 저장), 값 부분은 `[\s\S]*?`(어떤 글자든 상관없이, 최대한 짧게)로 읽은 다음, 마지막에 `\1`(아까 1번으로 기억해둔 것과 **완전히 같은** 따옴표)이 나올 때까지 읽도록 했습니다. 이렇게 하면 큰따옴표로 둘러싸인 값 안에 작은따옴표가 섞여 있어도(또는 그 반대도) 잘리지 않습니다.

### 2. HTML 코드가 글자로 남는 문제 수정

아래 코드를 찾으세요.

```typescript
  // HTML에 흔히 섞여 있는 &amp; &quot; 같은 기호를 원래 글자로 되돌립니다.
  private decodeHtmlEntities(text: string): string {
    return text
      .replace(/&amp;/g, '&')
      .replace(/&quot;/g, '"')
      .replace(/&#39;/g, "'")
      .replace(/&lt;/g, '<')
      .replace(/&gt;/g, '>')
      .trim();
  }
```

아래로 바꿔주세요.

```typescript
  // HTML에 흔히 섞여 있는 &amp; &quot; 같은 기호나 &#160; 같은 숫자 코드를 원래 글자로 되돌립니다.
  private decodeHtmlEntities(text: string): string {
    return text
      .replace(/&amp;/g, '&')
      .replace(/&quot;/g, '"')
      .replace(/&#39;/g, "'")
      .replace(/&apos;/g, "'")
      .replace(/&nbsp;/g, ' ')
      .replace(/&lt;/g, '<')
      .replace(/&gt;/g, '>')
      .replace(/&#(\d+);/g, (_match, code) => String.fromCharCode(parseInt(code, 10)))
      .replace(/&#x([0-9a-fA-F]+);/gi, (_match, code) => String.fromCharCode(parseInt(code, 16)))
      .replace(/\u00A0/g, ' ')
      .replace(/\s+/g, ' ')
      .trim();
  }
```

**바뀐 점**: `&#160;`처럼 숫자로 된 HTML 코드(`&#숫자;` 또는 `&#x16진수;` 형태)를 전부 원래 글자로 바꾸도록 했습니다. `&#160;`은 "줄바꿈 없는 빈 칸"이라는 특수한 공백 문자로 바뀌는데, 화면에서 일반 공백과 구분이 안 되도록 마지막에 일반 빈 칸으로 한 번 더 정리하고, 혹시 빈 칸이 여러 개 연달아 있으면 하나로 합치도록 했습니다.
