# 개선149. 참고자료 순서 변경 시 알림 추가

## 목표

참고자료 목록에서 드래그로 순서를 바꿨을 때, 순서가 정상적으로 저장되면 "순서가 변경되었습니다" 같은 알림이 뜨도록 합니다. (지금은 실패했을 때만 알림이 뜨고, 성공했을 때는 조용히 넘어갑니다.)

## 1단계. 사전(dictionary.ts)에 문구 추가하기

`frontend/src/lib/dictionary.ts` 파일을 여세요.

### 1-1. 한국어(ko) 섹션

아래 줄을 찾으세요.

```
    "boards.reference.reorderFail": "순서 저장에 실패했습니다.",
```

이 줄 **바로 위**에 아래 한 줄을 추가하세요.

```
    "boards.reference.reorderSuccess": "순서가 변경되었습니다.",
```

### 1-2. 영어(en) 섹션

아래 줄을 찾으세요.

```
    "boards.reference.reorderFail": "Failed to save the new order.",
```

이 줄 **바로 위**에 아래 한 줄을 추가하세요.

```
    "boards.reference.reorderSuccess": "Order updated.",
```

---

## 2단계. 순서 저장 성공 시 알림 띄우기

`frontend/src/app/admin/boards/reference/page.tsx` 파일을 여세요.

아래 코드를 찾으세요.

```typescript
    const token = localStorage.getItem("token");
    if (!token) return;
    const res = await fetch(`${API_URL}/post-references/reorder`, {
      method: "PATCH",
      headers: { "Content-Type": "application/json", Authorization: `Bearer ${token}` },
      body: JSON.stringify({ postId, orderedIds: next.map((r) => r.id) }),
    });
    if (!res.ok) {
      notify("❌ " + t("boards.reference.reorderFail"), "error");
      loadReferences();
    }
  }
```

아래로 바꿔주세요. (성공했을 때 알림 한 줄 추가)

```typescript
    const token = localStorage.getItem("token");
    if (!token) return;
    const res = await fetch(`${API_URL}/post-references/reorder`, {
      method: "PATCH",
      headers: { "Content-Type": "application/json", Authorization: `Bearer ${token}` },
      body: JSON.stringify({ postId, orderedIds: next.map((r) => r.id) }),
    });
    if (res.ok) {
      notify("✅ " + t("boards.reference.reorderSuccess"), "success");
    } else {
      notify("❌ " + t("boards.reference.reorderFail"), "error");
      loadReferences();
    }
  }
```
