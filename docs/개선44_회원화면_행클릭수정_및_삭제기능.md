# 개선 44: '회원' 화면 행 클릭 수정 + 회원 삭제 기능 추가

## 목표

'회원' 화면 표에서 '관리'열의 '수정' 버튼을 눌러야 수정 모달이 열리던 것을, 행을 클릭하면 바로 수정 모달이 열리도록 바꿉니다.

그리고 지금까지는 회원을 삭제하는 기능이 아예 없었는데, 이번에 추가합니다. 수정 모달 아래에 빨간색 '삭제' 버튼을 만들고, 누르면 곧바로 삭제되지 않고 "OOO님을 정말 삭제하시겠습니까? (회원이 정지된 경우에는 '상태'를 '정지'로 변경해서 처리할 수 있습니다.)"라는 확인 화면이 한 번 더 뜹니다. 여기서 '삭제'를 누르면 진짜로 삭제되고, '취소'를 누르면 확인 화면만 닫히고 원래 수정 모달로 돌아갑니다.

> 참고: 말씀하신 문구에 "탈퇴"라는 표현이 있었는데, 지금 시스템의 '상태' 값은 '활성' / '대기' / '정지' 세 가지뿐이라(24단계 이전에 만들어진 값입니다) "탈퇴" 대신 실제로 있는 값인 "정지"로 안내 문구를 만들었습니다.

안전을 위해, 이 회원이 대출한 기록(반납했든 안 했든)이 하나라도 있으면 삭제를 막고, 대신 '상태'를 '정지'로 바꾸도록 안내하는 오류 메시지를 보여줍니다. (대출 기록이 남아있는 회원을 완전히 지워버리면, 나중에 "누가 언제 이 책을 빌렸었는지" 같은 기록을 확인할 수 없게 되기 때문입니다.)

    if (!existing) {
      throw new NotFoundException('회원을 찾을 수 없습니다.');

      );
    }

    await this.prisma.user.delete({ where: { id } });
    return { success: true };
  }

- [ ] `users.controller.ts`에 `DELETE /users/:id` 엔드포인트를 추가했다.
- [ ] `dictionary.ts`에 삭제 관련 한글/영어 문구를 추가했다.
- [ ] '회원' 화면에서 '관리'열이 없어졌다.
- [ ] 표의 행을 클릭하면 수정 모달이 열린다.
- [ ] 수정 모달(등록 모달 아님)에만 빨간색 '삭제' 버튼이 보인다.
- [ ] '삭제' 버튼을 누르면 확인 모달이 한 번 더 뜬다.
- [ ] 확인 모달에서 '취소'를 누르면 수정 모달로 돌아온다.
- [ ] 확인 모달에서 '삭제'를 누르면 실제로 삭제된다.
- [ ] 대출 기록이 있는 회원은 삭제가 막히고 안내 메시지가 뜬다.
- [ ] 변경 내용을 GitHub에 커밋 및 푸시했다.
