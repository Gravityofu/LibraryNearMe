# 개선146. '자주 묻는 질문' 아코디언 목록의 모서리 테두리 지워지는 문제 수정

## 목표

'자주 묻는 질문' 게시판 질문 목록에 마우스를 올렸을 때, 둥근 네 모서리의 테두리가 사각형 회색 배경(hover 효과)에 가려서 지워지는 것처럼 보이는 문제를 고칩니다.

## 원인

바깥 상자에는 `rounded-lg`(둥근 모서리)와 `border`(테두리)가 적용되어 있는데, 그 안의 질문 버튼에 마우스를 올리면 생기는 회색 배경(`hover:bg-neutral-50`)은 각진 사각형이라서 튀어나온 모서리를 가리는 것입니다. 다른 화면들(예: 글 상세 화면의 회색 정보 상자)에는 바깥 상자에 `overflow-hidden`(밖으로 튀어나온 부분을 잘라내는 속성)이 같이 붙어있어서 이런 문제가 없는데, '자주 묻는 질문' 아코디언 목록에는 이 속성이 빠져 있었습니다.

## 수정 방법

`frontend/src/app/(site)/boards/[code]/page.tsx` 파일을 여세요.

아래 줄을 찾으세요.

```typescript
        <div className="flex flex-col divide-y divide-neutral-200 rounded-lg border border-neutral-200 bg-white">
```

아래로 바꿔주세요. (`overflow-hidden` 추가)

```typescript
        <div className="flex flex-col divide-y divide-neutral-200 overflow-hidden rounded-lg border border-neutral-200 bg-white">
```

이 한 줄만 바꾸면 됩니다.
