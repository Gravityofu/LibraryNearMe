# 개선 71: 별치기호 '(없음)' 값 항상 유지 + 청구기호에서 제외

## 목표

'별치기호' 목록에 `(없음)`이라는 값을 추가합니다. 이 값은 세 가지 특별한 규칙을 가집니다.

1. 이미 이 시스템을 쓰고 계신 도서관을 포함해서, 모든 도서관에 항상 자동으로 존재합니다. (지금 당장 안 계셔도, 이 코드를 적용하고 서버를 재시작하면 자동으로 생깁니다.)
2. 관리자가 삭제할 수 없습니다. 그리고 다른 값으로 이름을 바꿀 수도 없습니다. (이름이 바뀌면 '없음'이라는 뜻이 사라져서, 이 값에 의존하는 다른 기능들이 깨지기 때문입니다.)
3. 실물 자료를 새로 등록할 때 별치기호의 기본값으로 선택되어 있습니다. 그리고 별치기호가 `(없음)`으로 선택되어 있으면, 청구기호를 자동으로 만들 때 별치기호 부분은 통째로 빼고 분류기호부터 시작합니다.

// 별치기호가 '(없음)'이면 청구기호에서 아예 빼고 분류기호부터 시작합니다.
