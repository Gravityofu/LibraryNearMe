# 개선 56: '대출/반납일 변경' 버튼 동작 방식 변경 + 포커스 테두리 잘림 수정

## 목표

개선55에서 버튼과 날짜 입력 칸을 하나로 묶었는데, 두 가지 문제가 생겼습니다.

1. '대출/반납일 변경' 버튼을 누르면 그 버튼 자리에 브라우저 기본 달력 입력 칸이 통째로 나타나면서, '대출/반납일 변경'이라는 글자와 원래 있던 날짜 입력 칸이 순간적으로 사라져 버립니다.
2. 날짜 입력 칸을 클릭했을 때 나타나는 파란색 포커스 테두리가 오른쪽 모서리 부분에서 잘려 보입니다.

원인은 이렇습니다. 지금은 '대출/반납일 변경' 버튼을 누르면, 화면에 안 보이던 새로운 달력 입력 칸을 그 자리에 통째로 그려 넣는 방식으로 만들어져 있습니다. 그런데 이 달력 입력 칸이 놓이는 위치 계산이 버튼과 날짜 칸을 감싸고 있는 테두리 박스 바깥으로 밀려나면서, 그 박스가 가지고 있는 "테두리 밖으로 나가는 내용은 잘라서 안 보이게 한다(overflow-hidden)"는 설정 때문에 화면이 이상하게 보이는 것입니다. 이 "잘라서 안 보이게 한다"는 설정은 파란색 포커스 테두리가 모서리 부분에서 잘려 보이는 것과도 같은 원인입니다.

이번에는 방식을 바꿔서, 화면에는 보이지 않는 아주 작은(투명한) 달력 입력 칸을 미리 준비해두고, '대출/반납일 변경' 버튼을 누르면 그 보이지 않는 달력 입력 칸의 '달력 열기' 기능만 호출하도록 고칩니다. 이렇게 하면 버튼과 날짜 입력 칸은 항상 그 자리에 그대로 있고, 버튼을 눌렀을 때는 브라우저가 원래 제공하는 달력 팝업만 뜨게 됩니다. 그리고 테두리를 "잘라서 안 보이게 한다" 설정도 더 이상 필요 없게 되어 없애기 때문에, 포커스 테두리가 잘리는 문제도 함께 해결됩니다.

## 화면 수정하기: `page.tsx`

### 1. 더 이상 필요 없는 상태값 지우고, 새 준비물(ref)과 함수 추가하기

아래 부분을 찾으세요.

```tsx
  const [loanDateStr, setLoanDateStr] = useState(todayStr());
  const [showDatePicker, setShowDatePicker] = useState(false);
```

이렇게 바꿔주세요.

```tsx
  const [loanDateStr, setLoanDateStr] = useState(todayStr());
```

(더 이상 화면에 조건부로 달력 입력 칸을 그려 넣지 않기 때문에, 이걸 켜고 끄던 `showDatePicker` 상태값은 필요 없어졌습니다.)

다음으로 아래 부분을 찾으세요.

```tsx
  // 마지막으로 정상적으로 입력되었던 대출일을 기억해둡니다. (잘못된 값을 입력했을 때 되돌리기 위함입니다.)
  const lastValidLoanDateRef = useRef(todayStr());
  const [showDateFormatError, setShowDateFormatError] = useState(false);
```

이렇게 바꿔주세요.

```tsx
  // 마지막으로 정상적으로 입력되었던 대출일을 기억해둡니다. (잘못된 값을 입력했을 때 되돌리기 위함입니다.)
  const lastValidLoanDateRef = useRef(todayStr());
  const [showDateFormatError, setShowDateFormatError] = useState(false);

  // 화면에는 보이지 않지만, '대출/반납일 변경' 버튼을 누르면 이 입력 칸의 달력 팝업을 열어줍니다.
  const hiddenDateInputRef = useRef<HTMLInputElement>(null);

  // '대출/반납일 변경' 버튼을 눌렀을 때 호출됩니다. 보이지 않는 달력 입력 칸의 달력 팝업을 엽니다.
  function openDatePicker() {
    const el = hiddenDateInputRef.current;
    if (!el) return;
    if (typeof el.showPicker === "function") {
      el.showPicker();
    } else {
      // showPicker를 지원하지 않는 구형 브라우저를 위한 대안입니다.
      el.focus();
      el.click();
    }
  }
```

### 2. 버튼과 날짜 입력 칸 부분 통째로 바꾸기

아래 부분을 찾으세요.

```tsx
            <div className="flex items-stretch overflow-hidden rounded-lg border border-neutral-300">
              <button
                type="button"
                onClick={() => setShowDatePicker((v) => !v)}
                className="cursor-pointer border-r border-neutral-300 bg-neutral-100 px-3 py-2 text-sm font-medium hover:bg-neutral-200"
              >
                {t("loans.dateOverride.btn")}
              </button>
              <div className="relative">
                <input
                  type="text"
                  value={loanDateStr}
                  onChange={(e) => setLoanDateStr(formatDateInput(e.target.value))}
                  onFocus={(e) => e.target.select()}
                  onBlur={handleLoanDateBlur}
                  onKeyDown={(e) => e.key === "Enter" && e.currentTarget.blur()}
                  placeholder={t("loans.dateOverride.placeholder")}
                  className="h-full w-32 border-0 px-3 py-2 text-sm focus:outline-none focus:ring-2 focus:ring-inset focus:ring-blue-400"
                />
                {showDatePicker && (
                  <input
                    type="date"
                    autoFocus
                    value={loanDateStr}
                    onChange={(e) => {
                      const next = e.target.value || todayStr();
                      setLoanDateStr(next);
                      lastValidLoanDateRef.current = next;
                      setShowDatePicker(false);
                    }}
                    onBlur={() => setShowDatePicker(false)}
                    className="absolute left-0 top-full z-10 mt-1 rounded-lg border border-neutral-200 bg-white px-3 py-2 text-sm shadow-lg"
                  />
                )}
              </div>
            </div>
```

이렇게 바꿔주세요.

```tsx
            <div className="flex items-stretch rounded-lg border border-neutral-300">
              <button
                type="button"
                onClick={openDatePicker}
                className="cursor-pointer rounded-l-lg border-r border-neutral-300 bg-neutral-100 px-3 py-2 text-sm font-medium hover:bg-neutral-200"
              >
                {t("loans.dateOverride.btn")}
              </button>
              <div className="relative">
                <input
                  type="text"
                  value={loanDateStr}
                  onChange={(e) => setLoanDateStr(formatDateInput(e.target.value))}
                  onFocus={(e) => e.target.select()}
                  onBlur={handleLoanDateBlur}
                  onKeyDown={(e) => e.key === "Enter" && e.currentTarget.blur()}
                  placeholder={t("loans.dateOverride.placeholder")}
                  className="h-full w-32 rounded-r-lg border-0 px-3 py-2 text-sm focus:outline-none focus:ring-2 focus:ring-inset focus:ring-blue-400"
                />
                {/* 화면에는 보이지 않는 달력 입력 칸입니다. 버튼을 누르면 이 칸의 달력 팝업만 뜹니다. */}
                <input
                  ref={hiddenDateInputRef}
                  type="date"
                  value={loanDateStr}
                  onChange={(e) => {
                    const next = e.target.value || todayStr();
                    setLoanDateStr(next);
                    lastValidLoanDateRef.current = next;
                  }}
                  tabIndex={-1}
                  className="pointer-events-none absolute inset-0 h-full w-full opacity-0"
                />
              </div>
            </div>
```

무엇이 달라졌는지 설명드립니다.

- 바깥쪽 `<div>`에서 `overflow-hidden`을 없앴습니다. 대신 버튼에는 `rounded-l-lg`(왼쪽 모서리만 둥글게), 날짜 입력 칸에는 `rounded-r-lg`(오른쪽 모서리만 둥글게)를 직접 넣어서, `overflow-hidden` 없이도 두 부품이 딱 맞게 이어진 하나의 둥근 박스처럼 보이게 했습니다. 이렇게 하면 포커스 테두리가 잘릴 일이 없습니다.
- 버튼을 눌렀을 때 더 이상 화면에 새로운 입력 칸을 그려 넣지 않습니다. 대신 화면에 보이지 않는(`opacity-0`) 달력 입력 칸을 항상 준비해두고, 버튼을 누르면 그 칸의 `.showPicker()`(달력 팝업 열기)만 호출합니다. 그래서 버튼 글자와 날짜 입력 칸은 항상 그 자리에 그대로 남아있고, 브라우저의 달력 팝업만 뜹니다.
- 이 보이지 않는 달력 입력 칸에는 `pointer-events-none`을 넣어서, 마우스 클릭이 이 칸을 뚫고 지나가 바로 아래에 있는(실제 눈에 보이는) 날짜 입력 칸에 그대로 전달되도록 했습니다. `tabIndex={-1}`은 Tab 키로 화면을 이동할 때 이 보이지 않는 칸에는 커서가 가지 않도록 막아줍니다.
