# 개선 52: 대출 화면 - 날짜 직접 입력, 박스 비율 조정, 커서 자동 이동

## 목표

'대출/반납일 변경' 기능을 세 가지로 개선합니다.

1. 지금은 달력을 클릭해서만 날짜를 고를 수 있는데, 관리자가 직접 키보드로 날짜를 타이핑해서 입력할 수도 있게 합니다.
2. '회원 검색' 박스와 '회원 정보' 박스의 가로 길이 비율을 1:1이 아니라 4:6으로 바꿔서, '회원 정보' 박스가 조금 더 넓게 보이도록 합니다.
3. 회원 검색 결과가 1명이라 바로 '회원 정보'에 채워지든, 여러 명이 검색되어 모달에서 한 명을 선택하든, 회원이 선택되는 즉시 커서가 '회원 검색' 입력폼이 아니라 '자료 등록번호' 입력폼으로 자동으로 이동하게 합니다. (스캐너로 등록번호를 바로 찍을 수 있도록 하기 위함입니다.)

## 2. 화면 수정하기: `page.tsx`

`C:\projects\LibraryNearMe\frontend\src\app\admin\loans\page.tsx` 파일을 여세요.

### 2-1. 커서 이동에 쓸 준비물(ref) 추가하기

아래 부분을 찾으세요.

```tsx
  // 등록번호가 아무리 빠르게 여러 번 들어와도, 이전 처리가 끝난 뒤 순서대로 하나씩 처리되도록
  // 여기(큐)에 작업을 이어붙입니다.
  const queueRef = useRef<Promise<void>>(Promise.resolve());
```

이렇게 바꿔주세요.

```tsx
  // 등록번호가 아무리 빠르게 여러 번 들어와도, 이전 처리가 끝난 뒤 순서대로 하나씩 처리되도록
  // 여기(큐)에 작업을 이어붙입니다.
  const queueRef = useRef<Promise<void>>(Promise.resolve());

  // 회원이 선택되면 이 입력폼으로 커서를 옮기기 위해 사용합니다.
  const registrationInputRef = useRef<HTMLInputElement>(null);
```

### 2-2. 회원이 선택되면 등록번호 입력폼으로 커서 이동하기

아래 부분을 찾으세요. (검색 결과가 1명이라 바로 선택되는 경우, 모달에서 한 명을 클릭해서 선택하는 경우 모두 내부적으로 `selectedMember`를 바꾸는 방식이라, 이 한 곳만 고치면 두 경우 모두 적용됩니다.)

```tsx
  // 선택된 회원이 바뀔 때마다 대출 자료 목록을 새로 불러옵니다.
  useEffect(() => {
    if (selectedMember) {
      loadLoanedItems(selectedMember.id);
    } else {
      setLoanedItems([]);
    }
    // eslint-disable-next-line react-hooks/exhaustive-deps
  }, [selectedMember?.id]);
```

이렇게 바꿔주세요.

```tsx
  // 선택된 회원이 바뀔 때마다 대출 자료 목록을 새로 불러오고, 등록번호 입력폼으로 커서를 옮깁니다.
  useEffect(() => {
    if (selectedMember) {
      loadLoanedItems(selectedMember.id);
      registrationInputRef.current?.focus();
    } else {
      setLoanedItems([]);
    }
    // eslint-disable-next-line react-hooks/exhaustive-deps
  }, [selectedMember?.id]);
```

### 2-3. 등록번호 입력폼에 ref 연결하기

아래 부분을 찾으세요.

```tsx
                  <input
                    autoFocus
                    value={registrationNo}
                    onChange={(e) => setRegistrationNo(e.target.value)}
                    onKeyDown={(e) => e.key === "Enter" && handleRegistrationSubmit()}
                    placeholder={t("loans.registrationNo.placeholder")}
                    className="w-full rounded-lg border border-neutral-200 px-3 py-2 text-sm"
                  />
```

이렇게 바꿔주세요.

```tsx
                  <input
                    ref={registrationInputRef}
                    value={registrationNo}
                    onChange={(e) => setRegistrationNo(e.target.value)}
                    onKeyDown={(e) => e.key === "Enter" && handleRegistrationSubmit()}
                    placeholder={t("loans.registrationNo.placeholder")}
                    className="w-full rounded-lg border border-neutral-200 px-3 py-2 text-sm"
                  />
```

(`autoFocus`는 화면이 처음 열릴 때 딱 한 번만 작동해서 회원을 바꿔 선택할 때마다 커서를 옮기지는 못합니다. 대신 `ref`를 연결해서, 위 2-2에서 만든 코드가 회원이 선택될 때마다 직접 커서를 이 입력폼으로 옮기도록 했습니다.)

### 2-4. 날짜를 직접 타이핑할 수 있게 하기

아래 부분을 찾으세요.

```tsx
                <div className="relative">
                  <input
                    type="text"
                    readOnly
                    disabled
                    value={loanDateStr}
                    className="w-32 cursor-not-allowed rounded-lg border border-neutral-200 bg-neutral-100 px-3 py-2 text-sm text-neutral-500"
                  />
```

이렇게 바꿔주세요.

```tsx
                <div className="relative">
                  <input
                    type="text"
                    value={loanDateStr}
                    onChange={(e) => setLoanDateStr(e.target.value)}
                    placeholder={t("loans.dateOverride.placeholder")}
                    className="w-32 rounded-lg border border-neutral-200 px-3 py-2 text-sm"
                  />
```

(원래는 이 입력폼이 `readOnly`, `disabled`로 잠겨 있어서 달력으로만 날짜를 바꿀 수 있었습니다. 이번에 잠금을 풀어서, 관리자가 이 칸을 클릭해 `2025-01-15`처럼 직접 타이핑할 수도 있고, 옆의 '대출/반납일 변경' 버튼을 눌러 달력으로 고를 수도 있습니다. 두 방법 모두 같은 값(`loanDateStr`)을 사용하므로 서로 충돌하지 않습니다.)

### 2-5. '회원 검색'과 '회원 정보' 박스 비율을 4:6으로 바꾸기

아래 부분을 찾으세요.

```tsx
          <div className="grid w-full grid-cols-1 gap-4 md:grid-cols-2">
            {/* 왼쪽: 회원 검색 + 등록번호 입력 */}
            <div className="rounded-lg border border-neutral-200 bg-white p-4">
```

이렇게 바꿔주세요.

```tsx
          <div className="grid w-full grid-cols-1 gap-4 md:grid-cols-10">
            {/* 왼쪽: 회원 검색 + 등록번호 입력 (전체 가로폭의 4/10) */}
            <div className="rounded-lg border border-neutral-200 bg-white p-4 md:col-span-4">
```

아래 부분도 찾으세요.

```tsx
            {/* 오른쪽: 회원 정보 (항목 이름은 항상 보이고, 값만 채워지거나 "-"로 보입니다) */}
            <div className="rounded-lg border border-neutral-200 bg-white p-4">
```

이렇게 바꿔주세요.

```tsx
            {/* 오른쪽: 회원 정보 (항목 이름은 항상 보이고, 값만 채워지거나 "-"로 보입니다) (전체 가로폭의 6/10) */}
            <div className="rounded-lg border border-neutral-200 bg-white p-4 md:col-span-6">
```

마지막으로 아래 부분도 찾으세요. (그리드가 2칸에서 10칸으로 바뀌었기 때문에, 아래 '대출 자료 목록' 박스도 전체 폭을 차지하도록 칸 수를 맞춰줘야 합니다.)

```tsx
            {/* 아래: 대출 자료 목록 (두 박스를 합한 가로 길이, 연한 파란색 배경) */}
            <div className="rounded-lg border border-blue-200 bg-blue-50 p-4 md:col-span-2">
```

이렇게 바꿔주세요.

```tsx
            {/* 아래: 대출 자료 목록 (두 박스를 합한 가로 길이, 연한 파란색 배경) */}
            <div className="rounded-lg border border-blue-200 bg-blue-50 p-4 md:col-span-10">
```

파일을 저장하세요.
