# 개선26. 실물 등록 - '등록번호·상태·청구기호·별치기호·소장처' 필수 입력으로 변경

## 🎯 목표

실물 자료를 등록/수정할 때, 아래 5개 항목을 모두 **필수 입력**으로 만들게요.

- 등록번호 (이미 필수였어요)
- 상태
- 청구기호
- 별치기호
- 소장처

화면(프론트엔드)과 서버(백엔드) 양쪽에서 모두 값을 확인해서, 하나라도 비어있으면 저장이 안 되고 안내 메시지가 뜨도록 만들게요. (화면에서만 막으면 사람이 개발자 도구로 값을 억지로 비운 채 보낼 수도 있어서, 서버에서도 한 번 더 확인하는 게 안전해요.)

## 2단계. 저장하기 전에 5개 항목을 모두 확인하는 함수 만들기

같은 파일에서, 아래 두 함수(`handleAddCopy`, `handleUpdateCopy`) 바로 위에 새 함수를 하나 추가할게요.

**찾기:**

```tsx
  async function handleAddCopy() {
    if (!material) return;
    const token = localStorage.getItem("token");
    if (!token) return;
    if (!form.registrationNo.trim()) {
      notify("❌ " + t("materials.copies.regNoRequired"), "error");
      return;
    }
```

**이렇게 바꿔주세요:**

```tsx
  // 등록번호·상태·청구기호·별치기호·소장처, 이 5개 항목이 모두 채워졌는지 확인합니다.
  function validateRequiredFields(): boolean {
    if (
      !form.registrationNo.trim() ||
      !form.status.trim() ||
      !form.callNumber.trim() ||
      !form.specialCode.trim() ||
      !form.location.trim()
    ) {
      notify("❌ " + t("materials.copies.requiredFieldsMissing"), "error");
      return false;
    }
    return true;
  }

  async function handleAddCopy() {
    if (!material) return;
    const token = localStorage.getItem("token");
    if (!token) return;
    if (!validateRequiredFields()) return;
```

이번엔 `handleUpdateCopy` 함수 안의 똑같은 부분을 찾아주세요.

**찾기:**

```tsx
  async function handleUpdateCopy() {
    if (!selectedCopyId || !material) return;
    const token = localStorage.getItem("token");
    if (!token) return;
    if (!form.registrationNo.trim()) {
      notify("❌ " + t("materials.copies.regNoRequired"), "error");
      return;
    }
```

**이렇게 바꿔주세요:**

```tsx
  async function handleUpdateCopy() {
    if (!selectedCopyId || !material) return;
    const token = localStorage.getItem("token");
    if (!token) return;
    if (!validateRequiredFields()) return;
```

### 무슨 코드인가요?

- `validateRequiredFields()`: 5개 항목을 하나씩 확인해서, 하나라도 빈 값이면(공백만 있는 경우도 포함) `false`를 돌려주면서 안내 메시지를 띄워요. 다 채워져 있으면 `true`를 돌려줘요.
- `if (!validateRequiredFields()) return;`: 등록/수정 버튼을 눌렀을 때 이 함수부터 실행해서, 통과하지 못하면(`false`) 그 자리에서 멈추고 서버로 요청을 보내지 않아요.
- 등록번호 전용이었던 이전 코드(`if (!form.registrationNo.trim()) {...}`)는 이제 이 함수 안에 통합됐어요.

- 등록번호 확인 바로 다음에, 상태·청구기호·별치기호·소장처 4개도 똑같이 확인하는 코드를 추가했어요. 하나라도 비어있으면 저장 자체가 거부되고 에러 메시지가 나가요.
