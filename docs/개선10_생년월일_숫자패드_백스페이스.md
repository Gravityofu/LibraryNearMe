# 개선 (10) — 생년월일 숫자패드에 '지우기(백스페이스)' 버튼 추가

> 목표: 년도를 숫자패드로 입력하다가 잘못 눌렀을 때, 마지막 숫자 하나를 지울 수
> 있는 백스페이스 버튼을 추가합니다.
> 소요 시간: 약 5분

---

## 오늘 만드는 것 (그림으로)

```
년도 숫자패드 (수정 전)        년도 숫자패드 (수정 후)
┌───────────┐                ┌───────────┐
│ 1  2  3   │                │ 1  2  3   │
│ 4  5  6   │        →       │ 4  5  6   │
│ 7  8  9   │                │ 7  8  9   │
│    0      │                │    0  ⌫  │  ← 마지막 칸에 지우기 버튼 추가
└───────────┘                └───────────┘
```

`⌫` 버튼을 누르면 년도 칸의 마지막 숫자 하나가 지워집니다. (예: `199` → `19`)

```tsx
// 전화기 숫자패드처럼 1~9, 그리고 가운데에 0 하나만 있는 배열입니다.
const KEYPAD_ROWS = [
  ["1", "2", "3"],
  ["4", "5", "6"],
  ["7", "8", "9"],
  ["", "0", ""],
];
```

이렇게 바꿔주세요. (마지막 줄 빈칸 자리에 지우기 버튼 표시(`⌫`)를 넣었어요.)

```tsx
// 전화기 숫자패드처럼 1~9, 그리고 마지막 줄에 0과 지우기(⌫) 버튼이 있는 배열입니다.
const KEYPAD_ROWS = [
  ["1", "2", "3"],
  ["4", "5", "6"],
  ["7", "8", "9"],
  ["", "0", "⌫"],

```

### 2. 지우기 버튼 동작 함수 추가

아래 부분을 찾으세요.

```tsx
  // 숫자패드에서 숫자를 누르면 년도 칸 뒤에 이어붙입니다. 4자리가 다 차면 패널을 닫습니다.
  function pressYearDigit(digit: string) {
    const next = (value.year + digit).slice(0, 4);
    onChange({ ...value, year: next });
    if (next.length === 4) setOpen(null);
  }
```

바로 아래에 함수를 하나 추가하세요.

```tsx
  // 지우기(⌫) 버튼: 년도 칸의 마지막 글자 하나를 지웁니다.
  function pressYearBackspace() {
    onChange({ ...value, year: value.year.slice(0, -1) });
  }
```

### 3. 버튼을 눌렀을 때 숫자인지 지우기인지 구분하기

아래 부분을 찾으세요.

```tsx
        {open === "year" && (
          <div className="absolute left-0 top-full z-20 mt-1 w-32 rounded-lg border bg-white p-2 shadow-lg">
            {KEYPAD_ROWS.map((row, i) => (
              <div key={i} className="grid grid-cols-3 gap-1">
                {row.map((digit, j) =>
                  digit === "" ? (
                    <span key={j} />
                  ) : (
                    <button
                      key={j}
                      type="button"
                      onClick={() => pressYearDigit(digit)}
                      className="cursor-pointer rounded-md border py-1.5 text-sm hover:bg-neutral-100"
                    >
                      {digit}
                    </button>
                  ),
                )}
              </div>
            ))}
          </div>
        )}
```

이렇게 바꿔주세요. (`⌫`이면 지우기 함수를, 그 외 숫자면 원래대로 숫자 입력
함수를 실행하도록 나눴어요.)

```tsx
        {open === "year" && (
          <div className="absolute left-0 top-full z-20 mt-1 w-32 rounded-lg border bg-white p-2 shadow-lg">
            {KEYPAD_ROWS.map((row, i) => (
              <div key={i} className="grid grid-cols-3 gap-1">
                {row.map((digit, j) =>
                  digit === "" ? (
                    <span key={j} />
                  ) : (
                    <button
                      key={j}
                      type="button"
                      onClick={() => (digit === "⌫" ? pressYearBackspace() : pressYearDigit(digit))}
                      className="cursor-pointer rounded-md border py-1.5 text-sm hover:bg-neutral-100"
                    >
                      {digit}
                    </button>
                  ),
                )}
              </div>
            ))}
          </div>
        )}
```

## 확인하기 — 약 3분

1. "회원" → "등록" 화면에서 년도 칸을 클릭해 숫자패드를 엽니다.

   확인합니다.

4. 다시 숫자를 눌러 4자리를 채우면 패드가 자동으로 닫히는지 확인합니다.
