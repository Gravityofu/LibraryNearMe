# 개선165. 목록형 게시판 - 칼럼 너비 고정 + 가운데 정렬

## 목표

관리자 페이지와 홈페이지의 '목록형' 게시판 표(테이블)에서, 각 칼럼(번호/제목/작성자/작성일 등)의 너비가 그 안에 들어가는 글자 길이에 따라 들쭉날쭉 바뀌던 것을 고정된 비율로 바꿉니다.

- 번호는 짧게, 제목은 길게, 작성일처럼 글자 길이가 정해진 칼럼은 그 길이만큼만 배분합니다.
- 화면 크기가 줄어들어도(반응형) 칼럼끼리의 비율은 그대로 유지된 채 함께 줄어듭니다.
- 칼럼 너비보다 데이터가 길면 줄임표(...)로 표시합니다.
- 칼럼 제목과 데이터를 모두 가운데 정렬합니다.

바꾸는 파일은 2개입니다.
1. `frontend/src/app/admin/boards/page.tsx` (관리자 페이지 게시판 목록)
2. `frontend/src/app/(site)/boards/[code]/page.tsx` (홈페이지 게시판 목록)

**원리**: 표에 `table-fixed`를 적용하면, 각 칼럼(`<th>`)에 지정한 `w-[숫자%]` 비율대로 너비가 고정됩니다. 이때 '제목' 칼럼에는 너비를 따로 지정하지 않는데, 그러면 나머지 칼럼들이 차지하고 남은 공간을 제목 칼럼이 자동으로 전부 가져갑니다. 이 방식 덕분에 게시판마다 보이는 칼럼 개수가 달라도(예: 썸네일 칼럼이 있는 게시판/없는 게시판) 매번 비율을 다시 계산할 필요 없이 항상 자연스럽게 맞춰집니다.

## 확인하기

1. 관리자 페이지에서 여러 게시판(목록형: 자유게시판, 참고서비스, 1:1 상담, 자료를 신청합니다 등)을 열어서, 번호·제목·작성자·작성일·조회수 등 칼럼 너비가 게시판이 바뀌어도 일정하게 유지되는지 확인합니다.
2. 제목이나 작성자 이름이 아주 긴 글을 하나 등록해서, 칼럼 너비를 넘어가는 부분이 줄임표(...)로 표시되는지 확인합니다.
3. 브라우저 창 너비를 줄여보면서(또는 개발자 도구의 모바일 화면 보기로), 칼럼들이 비율을 유지한 채 함께 줄어드는지 확인합니다.
4. 홈페이지 쪽도 같은 방식으로 목록형 게시판 몇 개를 열어서 칼럼 너비와 가운데 정렬이 잘 적용되는지 확인합니다.
5. 참고서비스/1:1 상담 게시판의 '답변' ✅/❌ 표시와 자료를 신청합니다 게시판의 '처리상태' 칸도 가운데 정렬로 잘 보이는지 확인합니다.
6. 관리자 목록의 '참고자료' 칸 버튼과 개수 표시, '관리' 칸의 삭제 버튼도 가운데로 잘 모이는지 확인합니다.
