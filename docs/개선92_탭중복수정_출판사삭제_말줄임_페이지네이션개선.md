# 개선92: 탭 중복 수정, 출판사 열 삭제, 말줄임 표시, 숫자 페이지네이션

## 목표

이번 가이드는 네 가지를 고칩니다.

1. 개선91 적용 과정에서 탭 메뉴('대출', '반납', '예약', '대출이력')가 화면에 두 번 겹쳐서 나오는 문제를 고칩니다. (코드가 중복으로 붙여진 것이 원인입니다.)
2. '대출이력' 표에서 '출판사' 열을 삭제합니다.
3. '대출이력' 표의 '자료명', '저자' 칸에 있는 글자가 10자를 넘으면 뒷부분을 "…"(말줄임표)로 줄여서 보여줍니다. (마우스를 올리면 전체 글자를 볼 수 있도록 만듭니다.)
4. 페이지 이동 버튼을 숫자로 최대 10개까지 보여주는 방식으로 바꾸고, 10페이지가 넘어가면 앞/뒤로 10페이지씩 한 번에 이동하는 버튼(«, »)도 추가합니다. 이 새 페이지 이동 방식은 '대출이력'뿐 아니라 '회원', '목록' 메뉴에도 똑같이 적용합니다.

새로 만드는 페이지 이동 부품(파일)이 하나 있는데, 이건 기존 내용을 고치는 게 아니라 아예 새 파일이라서 통째로 복사해서 붙여넣으시면 됩니다. 나머지는 지금까지처럼 찾아서 바꾸는 방식입니다.

## 2단계: 새 페이지 이동(페이지네이션) 부품 만들기

`frontend/src/components` 폴더에 `pagination.tsx`라는 새 파일을 만들고, 아래 내용을 통째로 붙여넣어 주세요.

```typescript
"use client";

type PaginationProps = {
  page: number;
  totalPages: number;
  onPageChange: (page: number) => void;
};

// 한 번에 보여줄 페이지 번호 개수입니다.
const BLOCK_SIZE = 10;

// 페이지 번호를 최대 10개까지 숫자 버튼으로 보여줍니다.
// 전체 페이지가 10개를 넘으면, 지금 보이는 10개 묶음의 앞/뒤로 10페이지씩 한 번에 이동하는
// « » 버튼이 함께 나타납니다. '목록', '회원', '대출이력' 화면에서 공통으로 씁니다.
export default function Pagination({ page, totalPages, onPageChange }: PaginationProps) {
  if (totalPages <= 1) return null;

  // 지금 페이지가 속한 "10페이지 묶음"의 시작과 끝을 구합니다. (예: 23페이지 → 21~30 묶음)
  const blockStart = Math.floor((page - 1) / BLOCK_SIZE) * BLOCK_SIZE + 1;
  const blockEnd = Math.min(blockStart + BLOCK_SIZE - 1, totalPages);

  const pageNumbers: number[] = [];
  for (let p = blockStart; p <= blockEnd; p++) {
    pageNumbers.push(p);
  }

  const hasPrevBlock = blockStart > 1;
  const hasNextBlock = blockEnd < totalPages;

  return (
    <div className="flex flex-wrap items-center justify-center gap-1 text-sm">
      <button
        type="button"
        disabled={!hasPrevBlock}
        onClick={() => onPageChange(Math.max(1, blockStart - BLOCK_SIZE))}
        className="cursor-pointer rounded border px-2 py-1 disabled:cursor-not-allowed disabled:opacity-40"
        aria-label="이전 10페이지"
      >
        «
      </button>
      {pageNumbers.map((p) => (
        <button
          key={p}
          type="button"
          onClick={() => onPageChange(p)}
          className={`cursor-pointer rounded border px-3 py-1 ${
            p === page ? "border-[#383838] bg-[#383838] text-[#F9F6F0]" : "hover:bg-neutral-50"
          }`}
        >
          {p}
        </button>
      ))}
      <button
        type="button"
        disabled={!hasNextBlock}
        onClick={() => onPageChange(Math.min(totalPages, blockStart + BLOCK_SIZE))}
        className="cursor-pointer rounded border px-2 py-1 disabled:cursor-not-allowed disabled:opacity-40"
        aria-label="다음 10페이지"
      >
        »
      </button>
    </div>
  );
}
```

**설명:** `page`(지금 몇 페이지인지), `totalPages`(전체 페이지 수), `onPageChange`(페이지를 눌렀을 때 할 일)를 받는 부품입니다. 지금 페이지가 속한 10페이지 묶음(예: 1~10페이지, 11~20페이지)의 번호 버튼만 보여주고, 그 앞뒤로 다른 묶음이 더 있으면 «/» 버튼으로 통째로 이동할 수 있게 했습니다. 지금 페이지에 해당하는 숫자는 진하게 표시됩니다.

### 5-2. 글자를 10자에서 줄여주는 함수와, 표 칸 수를 11개로 고치기

아래 내용을 찾으세요.


이 내용을 아래 내용으로 바꿔주세요.

```typescript
const HISTORY_PAGE_SIZE_OPTIONS = [10, 20, 30, 40, 50];
const HISTORY_COLUMN_COUNT = 11;

// 글자가 max(기본 10자)를 넘으면 뒷부분을 "…"로 줄여줍니다.
function truncateText(text: string, max = 10) {
  if (!text) return text;
  return text.length > max ? `${text.slice(0, max)}…` : text;
}
```

**설명:** '출판사' 열을 지울 것이라 표의 전체 칸 수(`HISTORY_COLUMN_COUNT`)가 12에서 11로 줄어듭니다. `truncateText`는 글자 수가 10자를 넘으면 앞 10자만 남기고 뒤에 "…"을 붙여줍니다.
