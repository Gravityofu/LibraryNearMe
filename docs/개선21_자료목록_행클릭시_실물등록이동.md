# 개선21. 자료 검색 목록 - '실물 등록' 칼럼 삭제하고 행 클릭으로 이동하기

## 🎯 목표

지금 자료 검색 목록 페이지의 테이블을 보면, 맨 오른쪽에 '실물 등록' 칼럼이 있고 거기 있는 "등록" 버튼을 눌러야만 실물 등록 페이지로 이동할 수 있어요. 이번엔

- '실물 등록' 칼럼을 통째로 없애고
- 대신 **표의 행(줄) 아무 곳이나 클릭**하면 그 자료의 실물 등록 페이지로 바로 이동하도록

바꿔볼게요.

### 그림으로 보면

```
[전]                                           [후]
| 제목 | 저자 | ... | 실물 등록 |               | 제목 | 저자 | ... |
| 우리들|김철수| ... |  [등록]  |  ← 버튼 클릭    | 우리들|김철수| ... |  ← 행 아무 곳이나 클릭
                                                              (마우스를 올리면 손가락 커서로 바뀜)
```

## 수정하기

**파일**: `frontend/src/app/admin/materials/list/page.tsx`

### 1) 행을 클릭하면 이동시켜주는 기능 추가하기

파일 맨 위, `import` 부분을 찾아주세요.

**찾기:**

```tsx
import { useState } from "react";
import Link from "next/link";
```

**이렇게 바꿔주세요:**

```tsx
import { useState } from "react";
import Link from "next/link";
import { useRouter } from "next/navigation";
```

`MaterialsListPage` 함수 맨 위쪽, 아래 줄을 찾아주세요.

**찾기:**

```tsx
export default function MaterialsListPage() {
  const { notify } = useNotify();
  const { t, lang } = useI18n();
```

**이렇게 바꿔주세요:**

```tsx
export default function MaterialsListPage() {
  const router = useRouter();
  const { notify } = useNotify();
  const { t, lang } = useI18n();
```

### 2) 칼럼 개수 숫자 줄이기

**찾기:**

```tsx
const PAGE_SIZE_OPTIONS = [10, 20, 30, 40, 50];
const COLUMN_COUNT = 12;
```

**이렇게 바꿔주세요:**

```tsx
const PAGE_SIZE_OPTIONS = [10, 20, 30, 40, 50];
const COLUMN_COUNT = 11;
```

> 💡 `COLUMN_COUNT`는 "빈 화면일 때 회색 빈 칸을 몇 개 그릴지", "검색 결과가 없을 때 안내 문구를 몇 칸짜리로 합칠지"를 계산할 때 쓰는 숫자예요. 칼럼을 하나 없앴으니 12에서 11로 줄여줘야 표 모양이 안 깨져요.

### 4) 각 행에 클릭 이동 기능 추가하고, 버튼 칸 지우기

**찾기:**

```tsx
                return (
                  <tr key={row.hasCopy ? `copy-${row.id}` : `material-${row.materialId}`} className={row.hasCopy ? "" : "bg-amber-50"}>
```

**이렇게 바꿔주세요:**

```tsx
                return (
                  <tr
                    key={row.hasCopy ? `copy-${row.id}` : `material-${row.materialId}`}
                    onClick={() => router.push(`/admin/materials/copies?materialId=${row.materialId}`)}
                    className={`cursor-pointer hover:bg-neutral-100 ${row.hasCopy ? "" : "bg-amber-50"}`}
                  >
```

이제 표 안, 맨 마지막 칸(실물 등록 버튼이 있던 부분)을 찾아주세요.

**찾기:**

```tsx
                    <td className="whitespace-nowrap px-4 py-2.5">{row.location || "-"}</td>
                    <td className="whitespace-nowrap px-4 py-2.5">
                      <Link
                        href={`/admin/materials/copies?materialId=${row.materialId}`}
                        className="rounded border px-2 py-1 text-xs"
                      >
                        {t("materials.list.registerBtn")}
                      </Link>
                    </td>
                  </tr>
                );
```

**이렇게 바꿔주세요:**

```tsx
                    <td className="whitespace-nowrap px-4 py-2.5">{row.location || "-"}</td>
                  </tr>
                );
```

### 무슨 코드인가요?

- `onClick={() => router.push(...)}`: `<tr>`(표의 한 행) 전체에 클릭 이벤트를 달아서, 어디를 클릭하든 실물 등록 페이지로 이동하게 만들었어요. `useRouter()`의 `router.push(...)`는 `<Link>`와 똑같이 페이지를 이동시켜주는 함수예요.
- `cursor-pointer`: 마우스를 행 위에 올렸을 때 손가락 모양 커서로 바뀌게 해서, "여기 누르면 뭔가 된다"는 걸 시각적으로 알려줘요.
- `hover:bg-neutral-100`: 마우스를 올렸을 때 배경색이 살짝 회색으로 바뀌어서, 지금 어느 행 위에 있는지 눈으로 확인하기 쉬워졌어요.
- 기존 자료가 없는 행(주황빛 배경, `bg-amber-50`)의 색은 그대로 유지하면서 `hover:bg-neutral-100`을 같이 붙였어요. 마우스를 올리면 살짝 색이 겹쳐 보이는데, 자연스럽게 잘 어울려요.
- 마지막 칸(등록 버튼)은 통째로 지웠어요. 이제 이 버튼이 없어도 행을 클릭하면 똑같은 곳으로 이동하기 때문이에요.

## ✅ 확인하기

1. 백엔드, 프론트엔드를 실행해주세요.
2. 관리자 페이지 → 자료 목록으로 들어가서 검색을 해보세요.
3. 표 맨 오른쪽에 있던 '실물 등록' 칼럼(등록 버튼)이 사라졌는지 확인해주세요.
4. 표의 아무 행이나 (제목이든 저자든 빈칸이든) 클릭하면 그 자료의 실물 등록 페이지로 이동하는지 확인해주세요.
5. 마우스를 행 위에 올렸을 때 손가락 커서로 바뀌고, 배경색이 살짝 바뀌는지도 확인해주세요.
6. 자료가 아직 없는 주황빛 배경 행도 클릭했을 때 잘 이동하는지 확인해주세요.
