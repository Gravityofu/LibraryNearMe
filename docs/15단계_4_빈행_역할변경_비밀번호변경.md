## 1. 백엔드 — 수정 API에 비밀번호·역할 변경 추가 (약 6분)

`backend/src/users/users.service.ts` 를 엽니다. `update` 함수를 찾으세요. (14단계쯤부터 익숙한 방식이지만, 이번엔 함수 전체를 아래 내용으로 통째로 바꿔주세요 — 부분 수정보다 안전해요.)

```typescript
  // 회원/관리자 정보 수정 (이름/연락처/상태/역할/비밀번호 등). 아이디는 여기서 안 바꿉니다.
  async update(
    libraryId: number,
    id: number,
    data: {
      name?: string;
      phone?: string;
      email?: string;
      memberNo?: string;
      birthDate?: string;
      address?: string;
      status?: string;
      role?: string;
      password?: string;
    },
  ) {
    const existing = await this.prisma.user.findFirst({
      where: { id, libraryId, role: { in: [Role.MEMBER, Role.ADMIN] } },
    });
    if (!existing) {
      throw new NotFoundException('회원을 찾을 수 없습니다.');
    }

    const updateData: any = {
      name: data.name,
      phone: data.phone,
      email: data.email || undefined,
      memberNo: data.memberNo || undefined,
      birthDate: data.birthDate ? new Date(data.birthDate) : undefined,
      address: data.address || undefined,
      status: data.status ? (data.status as UserStatus) : undefined,
    };

    // 역할은 MEMBER ↔ ADMIN 사이에서만 바꿀 수 있습니다. (SUPER로는 여기서 못 바꿉니다.)
    if (data.role === 'ADMIN' || data.role === 'MEMBER') {
      updateData.role = data.role as Role;
    }

    // 비밀번호는 값을 입력했을 때만 바꿉니다. 관리자도 기존 비밀번호를 알 수 없고,
    // 오직 "새 비밀번호로 덮어쓰기"만 할 수 있습니다(암호화되어 저장되므로 원래 값은 아무도 못 봅니다).
    if (data.password && data.password.trim()) {
      updateData.passwordHash = await bcrypt.hash(data.password, 10);
    }

    try {
      return await this.prisma.user.update({
        where: { id },
        data: updateData,
        select: { id: true, name: true, role: true, status: true },
      });
    } catch (e: any) {
      if (e.code === 'P2002') {
        throw new ConflictException('이미 사용 중인 회원번호입니다.');
      }
      throw e;
    }
  }
```

- `role`은 `"ADMIN"`이나 `"MEMBER"`일 때만 반영돼요. 그 외 값(빈 값, `"SUPER"` 등)이 오면 조용히 무시하고 기존 역할을 그대로 둡니다 — 실수로라도 슈퍼 계정으로 못 올라가게 막아둔 거예요.
- `password`도 마찬가지로 **값이 있을 때만** 새로 암호화해서 저장해요. 프론트에서 이 칸을 비워두고 저장하면 비밀번호는 그대로 유지됩니다.

1. "회원" 화면에 처음 들어갔을 때(검색 전) 빈 줄 10개가 표에 미리 나오는지 확인합니다.
