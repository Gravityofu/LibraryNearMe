# 개선 42: '대출' 화면 관리열 제거 및 행 클릭으로 수정하기

## 목표

'설정' → '대출' 화면의 "기본 대출 설정"(회원 구분별)과 "자료별 대출 설정"(자료 종류별) 두 표에서, 지금은 '관리'열의 '수정' 버튼을 눌러야 수정 모달이 열립니다. 이번 가이드에서는 두 표 모두 '관리'열을 없애고, 표의 행(줄) 아무 곳이나 클릭하면 그 항목을 수정하는 모달이 바로 열리도록 바꿉니다.

다만 "자료별 대출 설정" 표의 '도서' 행에 있던 'KDC 하위 규칙' 버튼은 그대로 남겨야 합니다. 이 버튼은 관리열이 아니라, '도서' 이름 오른쪽에 약간의 여백을 두고 나란히 놓이도록 옮깁니다. (버튼을 누르면 KDC 규칙 모달이 열리고, 행을 클릭하면 자료 자체의 수정 모달이 열려야 하므로, KDC 버튼을 누를 때는 행 클릭이 같이 일어나지 않도록 처리합니다.)

**바뀐 점 요약**

- 두 표 모두 '관리'열(th)과 그 안의 '수정' 버튼(td)이 사라집니다.
- 표의 각 행(`<tr>`)에 `onClick`이 붙어서, 행 아무 곳이나 클릭하면 해당 항목의 수정 모달이 열립니다. (기존 `openMemberModal`, `openMaterialModal` 함수를 그대로 재사용합니다.)
- '도서' 행에서는 자료 이름과 'KDC 하위 규칙' 버튼이 `flex` 컨테이너 안에 `gap-3`(여백)을 두고 나란히 놓입니다. 버튼을 누르면 `e.stopPropagation()`으로 행 클릭 이벤트가 같이 일어나지 않도록 막아, KDC 모달만 열리고 자료 수정 모달은 열리지 않습니다.
- 표의 `min-w` 값을 관리열이 빠진 만큼 살짝 줄였습니다(720px→600px, 720px→560px). 표 내용이 잘려 보이면 이 숫자는 조정하셔도 됩니다.
