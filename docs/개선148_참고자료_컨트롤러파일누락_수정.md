# 개선148. 참고자료 컨트롤러 파일 누락 오류 수정

## 목표

개선147 가이드의 2-2단계에서 만들어야 했던 `backend/src/posts/post-references.controller.ts` 파일이 만들어지지 않아서 생긴 오류를 고칩니다. (`post-references.service.ts` 파일은 잘 만들어져 있는데, 컨트롤러 파일만 빠졌습니다.)

## 원인

`app.module.ts`는 `post-references.controller.ts` 파일을 가져오려고 하는데, 실제로 그 파일이 없어서 "Cannot find module './posts/post-references.controller'" 오류가 난 것입니다.

## 수정 방법

`backend/src/posts` 폴더 안에 `post-references.controller.ts` 파일이 있는지 먼저 확인해 주세요.

- **파일이 없다면**: 아래 내용 그대로 새 파일을 만들어 주세요.
- **파일이 있는데 내용이 비어있거나 이상하다면**: 아래 내용으로 전체를 바꿔주세요.

```typescript
import {
  BadRequestException,
  Body,
  Controller,
  Delete,
  Get,
  Param,
  Patch,
  Post,
  Query,
  Req,
  UseGuards,
} from '@nestjs/common';
import { PostReferencesService } from './post-references.service';
import { AdminGuard } from '../auth/admin.guard';

@Controller('post-references')
export class PostReferencesController {
  constructor(private postReferencesService: PostReferencesService) {}

  @Get()
  @UseGuards(AdminGuard)
  list(@Req() req: any, @Query('postId') postId: string) {
    return this.postReferencesService.list(req.user.libraryId, parseInt(postId, 10));
  }

  @Post()
  @UseGuards(AdminGuard)
  create(@Req() req: any, @Body() body: any) {
    return this.postReferencesService.create(req.user.libraryId, body);
  }

  @Patch('reorder')
  @UseGuards(AdminGuard)
  reorder(@Req() req: any, @Body() body: any) {
    const postId = Number(body.postId);
    const orderedIds = Array.isArray(body.orderedIds) ? body.orderedIds.map((v: any) => Number(v)) : [];
    if (!postId || orderedIds.length === 0) {
      throw new BadRequestException('postId와 orderedIds가 필요합니다.');
    }
    return this.postReferencesService.reorder(req.user.libraryId, postId, orderedIds);
  }

  @Delete(':id')
  @UseGuards(AdminGuard)
  remove(@Req() req: any, @Param('id') id: string) {
    return this.postReferencesService.remove(req.user.libraryId, parseInt(id, 10));
  }
}
```

파일 경로는 정확히 `backend/src/posts/post-references.controller.ts`여야 합니다. (같은 폴더에 있는 `post-references.service.ts`, `posts.controller.ts`, `posts.service.ts`와 나란히 있어야 합니다.)

## 확인하기

1. 파일을 저장한 뒤 백엔드 서버를 다시 켜서, `Cannot find module` 오류 없이 정상적으로 켜지는지 확인합니다.
2. 관리자 페이지 > 게시판 메뉴에서 '등록' 버튼을 눌러 참고자료 등록 화면이 잘 열리는지 확인합니다.
3. 참고자료를 하나 추가해보고, 정상적으로 등록/삭제/순서 변경이 되는지 확인합니다. (개선147의 "확인하기" 항목을 다시 한 번 점검해 보시면 좋습니다.)
