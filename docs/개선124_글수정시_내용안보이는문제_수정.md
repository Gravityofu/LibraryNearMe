# 개선124 - 글 수정 화면에서 내용이 보이지 않던 문제 수정

## 원인

글쓰기 화면(`rich-text-editor.tsx`)의 에디터는 화면이 맨 처음 열릴 때 딱 한 번만 내용을 채워 넣도록 만들어져 있었습니다.

그런데 '수정' 버튼을 눌러 들어가면, 화면이 열리자마자(내용이 아직 도착하기 전) 에디터가 먼저 만들어지고, 그 다음에 서버에서 글 내용을 불러와 화면에 전달합니다. 이 "그 다음에 도착한 내용"을 에디터에 다시 채워 넣는 코드가 빠져 있어서, 제목은 정상적으로 보이지만 본문 내용은 빈 채로 남아있었던 것입니다.

## 목표

서버에서 글 내용을 불러온 뒤에도 에디터에 그 내용이 정상적으로 채워지도록 고칩니다.

## 확인하기

1. 프론트엔드 서버를 재시작(또는 저장 시 자동 반영)합니다.
2. 아무 게시판에서나 글을 하나 작성해서 저장합니다.
3. 방금 작성한 글을 목록에서 '수정' 버튼으로 다시 열어봅니다. 제목과 함께 본문 내용도 정상적으로 보이는지 확인합니다.
4. 수정 화면에서 내용을 조금 바꾸고 저장한 뒤, 다시 열어서 바뀐 내용이 잘 보이는지 확인합니다.
5. (참고) 새 글을 쓸 때도 평소처럼 정상적으로 타이핑되는지 확인합니다.
