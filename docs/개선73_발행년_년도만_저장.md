# 개선73 - MARC 정보의 발행년(260 ▼c)에서 년도만 뽑아서 저장하기

## 목표

KOLIS-NET에서 가져온 MARC 정보 중 260 태그 ▼c(발행년) 값이 "2022.7"처럼 월(月)까지
포함되어 있는 경우가 있습니다. 지금은 이 값을 그대로 저장해서 발행년도 칸에 "2022.7"이라고
저장되는데, 이 칸에는 년도(2022)만 저장되도록 고칩니다.

### 어떻게 고치나요?

MARC 정보를 표의 각 칸 값으로 뽑아내는 함수(`extractColumns`)에서, 발행년 값을 그대로
쓰지 않고 그 값 안에서 숫자 4자리(년도)만 찾아서 그것만 저장하도록 바꿉니다. 예를 들어
"2022.7"이면 "2022"만, "c2022"면 "2022"만, "[2022]"면 "2022"만 뽑아냅니다. 만약 숫자 4자리를
전혀 찾을 수 없으면(형식이 아예 다른 경우) 원래 값을 그대로 둡니다.

## 1. `backend/src/materials/marc.util.ts` 수정하기

### 1-1. 년도만 뽑아내는 함수 추가하기

파일 위쪽에 있는 `stripRoleLabel` 함수 바로 아래(그리고 `extractColumns` 함수 바로 위)에,
아래 함수를 새로 추가해 주세요.

**찾을 코드:**

```ts
// 맨 앞에 "지은이", "지음"처럼 역할을 나타내는 흔한 말이 붙어 있으면 떼어냅니다.
// 예: "지은이: 김애란" -> "김애란"
function stripRoleLabel(value?: string): string | undefined {
  if (!value) return value;
  const cleaned = value
    .replace(/^(지은이|지음|글쓴이|저자|엮은이|엮음|편저|편|옮긴이|옮김|그림|글)\s*[:：]?\s*/, "")
    .trim();
  return cleaned || undefined;
}

// MARC 태그 목록에서 표의 각 칸 값을 뽑아냅니다.
```

**바꿀 코드:**

```ts
// 맨 앞에 "지은이", "지음"처럼 역할을 나타내는 흔한 말이 붙어 있으면 떼어냅니다.
// 예: "지은이: 김애란" -> "김애란"
function stripRoleLabel(value?: string): string | undefined {
  if (!value) return value;
  const cleaned = value
    .replace(/^(지은이|지음|글쓴이|저자|엮은이|엮음|편저|편|옮긴이|옮김|그림|글)\s*[:：]?\s*/, "")
    .trim();
  return cleaned || undefined;
}

// 발행년(260 ▼c) 값에서 4자리 숫자(년도)만 뽑아냅니다.
// 예: "2022.7" -> "2022", "c2022" -> "2022", "[2022]" -> "2022"
// 4자리 숫자를 찾지 못하면(형식이 아예 다른 경우) 원래 값을 그대로 돌려줍니다.
function extractYear(value?: string): string | undefined {
  if (!value) return value;
  const matched = value.match(/\d{4}/);
  return matched ? matched[0] : value;
}

// MARC 태그 목록에서 표의 각 칸 값을 뽑아냅니다.
```

### 1-2. `pubYear`를 뽑을 때 이 함수를 거치도록 바꾸기

**찾을 코드:**

```ts
    pubYear: one("260", "c"),                  // 발행년
```

**바꿀 코드:**

```ts
    pubYear: extractYear(one("260", "c")),      // 발행년 (월/일 등이 붙어 있으면 4자리 년도만 남깁니다)
```

   검색해서 '이 자료 가져오기'를 눌러 봅니다.
4. 발행년 칸에 "2022.7"이 아니라 "2022"만 들어오는지 확인합니다.

   그대로 "2022"가 잘 들어오는지 함께 확인해 주세요.

> 발행년을 직접 손으로 입력하실 때는 지금처럼 입력하신 값이 그대로 저장됩니다.
