# 개선81: 방금 대출 처리한 자료를 목록 맨 위에 옅은 녹색으로 표시하기

## 목표

대출/반납 화면의 "대출 자료 목록"에서, 방금 대출 처리를 완료한 자료의 행을 항상 목록 맨 위로 올리고 바탕색을 옅은 녹색으로 표시합니다. 이어서 다른 자료를 또 대출 처리하면, 이전에 강조되어 있던 행은 옅은 녹색이 사라지며 방금 처리한 행 바로 아래로 내려가고, 새로 처리한 행이 다시 맨 위에서 옅은 녹색으로 표시됩니다.

이 내용을 아래 내용으로 바꿔주세요.

```typescript
      const data = await res.json().catch(() => null);
      if (res.ok) {
        notify("✅ " + t("loans.success"), "success");
        if (data?.id) {
          setLastLoanId(data.id);
        }
        await loadLoanedItems(selectedMember.id);
      } else {
        setLoanErrorMessage(data?.message || regNo);
      }
```

**설명:** 대출 처리 API(`POST /loans`)는 성공하면 방금 만든 대출 기록의 `id`를 응답으로 돌려줍니다. 이 `id`를 `lastLoanId`에 저장해두면, 이후 목록을 새로 불러왔을 때 어느 행이 "방금 처리한 행"인지 알 수 있습니다.
