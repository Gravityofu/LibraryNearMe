# 개선127 - 에디터 이모티콘 개수 대폭 확대 (카테고리별로 정리)

## 목표

지금까지 에디터의 이모티콘은 30개만 고를 수 있었습니다. 이번 가이드에서는 무료로 쓸 수 있는 유니코드 이모티콘을 표정, 사람, 동물·자연, 음식, 활동, 여행·장소, 사물, 기호까지 8개 카테고리로 나누어 크게 늘립니다(총 약 260개). 이모티콘 버튼을 누르면 카테고리 탭이 함께 나오고, 탭을 눌러가며 원하는 카테고리의 이모티콘을 고를 수 있습니다.

(참고: 여기 쓰인 이모티콘은 전부 별도 프로그램 설치나 유료 라이브러리 없이, 텍스트로 바로 입력 가능한 표준 유니코드 이모티콘이라 항상 무료로 쓸 수 있습니다.)

### 1-2. 카테고리 선택 상태(state) 추가하기

찾기:
```tsx
  const [showEmojiPicker, setShowEmojiPicker] = useState(false);
```

교체:
```tsx
  const [showEmojiPicker, setShowEmojiPicker] = useState(false);
  const [activeEmojiCategory, setActiveEmojiCategory] = useState(EMOJI_CATEGORIES[0].key);
```

### 1-3. 이모티콘 선택 창을 카테고리 탭 + 큰 목록으로 바꾸기

찾기:
```tsx
          {showEmojiPicker && (
            <>
              <div className="fixed inset-0 z-40" onClick={() => setShowEmojiPicker(false)} />
              <div className="absolute left-0 top-full z-50 mt-1 grid w-64 grid-cols-10 gap-1 rounded-lg border border-neutral-200 bg-white p-2 shadow-lg">
                {EMOJI_LIST.map((emoji) => (
                  <button
                    key={emoji}
                    type="button"
                    onClick={() => handleEmojiPick(emoji)}
                    className="cursor-pointer rounded p-1 text-lg hover:bg-neutral-100"
                  >
                    {emoji}
                  </button>
                ))}
              </div>
            </>
          )}
```

교체:
```tsx
          {showEmojiPicker && (
            <>
              <div className="fixed inset-0 z-40" onClick={() => setShowEmojiPicker(false)} />
              <div className="absolute left-0 top-full z-50 mt-1 w-80 rounded-lg border border-neutral-200 bg-white p-2 shadow-lg">
                {/* 카테고리 탭 */}
                <div className="mb-2 flex flex-wrap gap-1 border-b border-neutral-100 pb-2">
                  {EMOJI_CATEGORIES.map((cat) => (
                    <button
                      key={cat.key}
                      type="button"
                      onClick={() => setActiveEmojiCategory(cat.key)}
                      className={`cursor-pointer rounded px-2 py-1 text-xs ${
                        activeEmojiCategory === cat.key
                          ? "bg-[#383838] text-[#F9F6F0]"
                          : "text-neutral-600 hover:bg-neutral-100"
                      }`}
                    >
                      {t(cat.labelKey)}
                    </button>
                  ))}
                </div>
                {/* 이모티콘 목록 */}
                <div className="grid max-h-56 grid-cols-10 gap-1 overflow-y-auto">
                  {EMOJI_CATEGORIES.find((c) => c.key === activeEmojiCategory)?.emojis.map((emoji, i) => (
                    <button
                      key={`${emoji}-${i}`}
                      type="button"
                      onClick={() => handleEmojiPick(emoji)}
                      className="cursor-pointer rounded p-1 text-lg hover:bg-neutral-100"
                    >
                      {emoji}
                    </button>
                  ))}
                </div>
              </div>
            </>
          )}
```

## 확인하기

1. 프론트엔드 서버를 재시작(또는 저장 시 자동 반영)합니다.
2. 글쓰기 화면에서 이모티콘 버튼을 눌러봅니다. 위쪽에 8개의 카테고리 탭이 보이는지 확인합니다.
3. 카테고리 탭을 하나씩 눌러가며 이모티콘 목록이 바뀌는지, 목록이 많아져도 스크롤로 볼 수 있는지 확인합니다.
4. 이모티콘을 하나 눌러서 글 안에 정상적으로 삽입되는지 확인합니다.
