# 개선 43: '설정' 화면에서 저장 후 탭이 그대로 유지되게 하기

## 목표

'설정' → '도서관' 화면에서 값을 바꾸고 저장하면, 저장이 잘 된 뒤에 화면이 새로고침되면서 항상 맨 처음 탭인 'KORMARC 태그'로 돌아가 버립니다. ('도서관' 탭뿐 아니라 '디자인' 탭에서 저장해도 똑같이 일어나는 현상입니다.)

원인은 이렇습니다. 저장 버튼을 누르면 저장 완료 안내창(모달)이 뜨고, 거기서 '확인'을 누르면 `window.location.reload()`로 화면 전체를 새로 불러옵니다. 이때 지금까지 어떤 탭을 보고 있었는지는 저장해두지 않고 있어서, 화면이 새로 열리면 항상 정해진 첫 번째 탭('KORMARC 태그')부터 시작하는 것입니다. (참고: 색상이나 폰트 같은 디자인 값은 화면 전체에 바로 반영되어야 해서 새로고침 자체는 필요합니다. 다만 어떤 탭에 있었는지는 기억해두어야 합니다.)

이번 가이드에서는 지금 보고 있는 탭이 무엇인지를 브라우저에 잠깐 기억해두었다가, 새로고침 후에도 그 탭으로 바로 돌아오도록 고칩니다.

## 프런트엔드 수정하기: `page.tsx`

`C:\projects\LibraryNearMe\frontend\src\app\admin\settings\page.tsx` 파일을 여세요.

### 1. 지금 보고 있는 탭을 기억하는 상태값 추가하기

아래 부분을 찾으세요.

```tsx
  const [tags, setTags] = useState<KormarcTag[]>([]);
  const [showModal, setShowModal] = useState(false);
  const [editingId, setEditingId] = useState<number | null>(null);
  const [form, setForm] = useState(EMPTY_TAG);
```

이렇게 바꿔주세요.

```tsx
  const [tags, setTags] = useState<KormarcTag[]>([]);
  const [showModal, setShowModal] = useState(false);
  const [editingId, setEditingId] = useState<number | null>(null);
  const [form, setForm] = useState(EMPTY_TAG);

  // 지금 보고 있는 탭이 무엇인지 기억해두었다가, 저장 후 새로고침되어도 같은 탭으로 돌아오게 해요.
  const [activeTab, setActiveTab] = useState("kormarcTags");

  useEffect(() => {
    const saved = sessionStorage.getItem("admin-settings-tab");
    if (saved) setActiveTab(saved);
  }, []);

  function handleTabChange(value: string) {
    setActiveTab(value);
    sessionStorage.setItem("admin-settings-tab", value);
  }
```

### 2. `Tabs`가 기억해둔 탭 값을 쓰도록 바꾸기

아래 부분을 찾으세요.

```tsx
      <Tabs defaultValue="kormarcTags">
```

이렇게 바꿔주세요.

```tsx
      <Tabs value={activeTab} onValueChange={handleTabChange}>
```

파일을 저장하세요.

**바뀐 점 요약**

- `activeTab` 상태값이 지금 보고 있는 탭을 저장하고, 브라우저의 `sessionStorage`(탭을 닫으면 사라지는 임시 저장소)에도 함께 저장합니다.
- 화면이 처음 열릴 때, `sessionStorage`에 저장된 탭이 있으면 그 탭으로 바로 이동합니다.
- 탭을 직접 클릭해서 바꿀 때도 `handleTabChange`를 통해 `sessionStorage`에 다시 저장됩니다.
- '도서관'이나 '디자인' 탭에서 저장 후 `window.location.reload()`로 새로고침되어도, `sessionStorage`에 저장된 값 덕분에 같은 탭으로 돌아옵니다.
