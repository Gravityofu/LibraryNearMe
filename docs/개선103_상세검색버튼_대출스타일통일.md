# 개선103: '목록' / '회원' / '대출이력' 상세 검색 버튼을 '대출' 페이지 스타일로 통일

## 목표

지난번 확인해드린 대로, '목록' / '회원' / '대출이력'의 '상세 검색' 버튼은 '대출' 페이지의 버튼과 스타일이 달랐습니다(배경색 명시 여부, 그림자 유무, 글자색, 좌우 여백). 이번 가이드는 '대출' 페이지 스타일을 기준으로 나머지 세 곳을 맞춥니다.

- **바꾸기 전(목록/회원/대출이력):** `rounded-lg border border-neutral-200 bg-white px-4 py-2 text-sm font-medium text-neutral-700 shadow-sm hover:bg-neutral-50`
- **바꾸기 후('대출' 스타일):** `rounded-lg border border-neutral-200 px-3 py-2 text-sm font-medium hover:bg-neutral-50`

바뀌는 내용은 흰색 배경(`bg-white`)과 그림자(`shadow-sm`)를 없애고, 고정된 글자색(`text-neutral-700`) 대신 페이지의 기본 글자색을 그대로 물려받게 하고, 좌우 여백을 `px-4`에서 `px-3`으로 살짝 줄이는 것입니다.

각 파일에서 버튼 스타일 한 줄만 바뀌기 때문에, 이번에도 그 줄만 찾아서 바꾸는 방식으로 안내드립니다.

**찾기:**

