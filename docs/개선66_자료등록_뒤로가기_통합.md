# 개선 66: '자료 등록' 화면 - 중복된 뒤로 가기 링크 정리

## 목표

'자료 등록' 화면은 1단계(실물/디지털 선택) → 2단계(세부 종류 선택) → 3단계(정보 입력)로 진행됩니다. 그런데 지금은 뒤로 갈 수 있는 방법이 두 가지 있습니다.

- 제목 오른쪽 위의 '뒤로 가기' 버튼: 어느 단계에 있든 무조건 '목록' 화면으로 이동합니다.
- 2단계, 3단계의 제목 아래에 있는 "← 구분 다시 선택" / "← 종류 다시 선택" 같은 링크: 바로 이전 단계로 잘 이동합니다.

두 개가 하는 일이 겹치니, 제목 아래에 있는 링크는 1·2·3단계 모두에서 없애고, 대신 오른쪽 위 '뒤로 가기' 버튼이 지금 몇 단계에 있는지에 따라 다르게 동작하도록 고칩니다.

- 1단계(실물/디지털 선택)에서 '뒤로 가기' → 지금처럼 '목록' 화면으로 이동
- 2단계(세부 종류 선택)에서 '뒤로 가기' → 1단계(실물/디지털 선택)로 이동
- 3단계(정보 입력)에서 '뒤로 가기' → 2단계(세부 종류 선택)로 이동

## 1. 공통 부품 수정하기: `admin-back-button.tsx`

`C:\projects\LibraryNearMe\frontend\src\components\admin-back-button.tsx` 파일을 여세요.

지금 이 버튼은 항상 정해진 주소(`href`)로 페이지 이동을 하는 링크입니다. 이번에는 주소로 이동하는 대신, 그냥 "뒤로 가는 동작(함수)"을 실행할 수도 있도록 기능을 하나 추가합니다. (기존처럼 `href`만 넘기는 다른 화면들은 지금처럼 그대로 잘 작동합니다.)

파일 전체를 아래 내용으로 바꿔주세요.

```tsx
"use client";

import Link from "next/link";
import { useI18n } from "@/components/language-provider";

type Props = {
  href?: string;
  onClick?: () => void;
};

export default function AdminBackButton({ href, onClick }: Props) {
  const { t } = useI18n();
  const className =
    "inline-flex cursor-pointer items-center gap-1 rounded-lg border border-neutral-200 bg-white px-3 py-1.5 text-sm text-neutral-600 hover:bg-neutral-50";

  // onClick이 주어지면(같은 화면 안에서 이전 단계로 돌아가는 경우) 버튼으로,
  // href만 주어지면(다른 화면으로 이동하는 경우) 기존처럼 링크로 동작합니다.
  if (onClick) {
    return (
      <button type="button" onClick={onClick} className={className}>
        ← {t("admin.backButton")}
      </button>
    );
  }

  return (
    <Link href={href || "#"} className={className}>
      ← {t("admin.backButton")}
    </Link>
  );
}
```

파일을 저장하세요.
