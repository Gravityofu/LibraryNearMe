# 개선93: 표(목록/회원/대출/반납/대출이력)의 기본 글자 색상을 '설정'에서 관리하기

## 목표

'목록', '회원', '대출', '반납', '대출이력' 화면의 표를 보면 어떤 칸은 진한 검정에 가까운 색(`lab(7.78 0 0)`)으로, 어떤 칸은 좀 더 옅은 회색(`lab(48.496 0 0)`)으로 서로 다르게 나오고 있었습니다. 이번 가이드는 이 두 가지를 회색(`lab(48.496 0 0)`, 16진수로는 `#737373`)으로 통일하면서, 이 색상 값을 코드에 직접 박아넣지(하드코딩) 않고 **'설정 → 도서관' 화면에서 관리자가 바꿀 수 있는 값**으로 만듭니다.

**동작 방식(요약):**
1. `Library`(도서관 설정) 테이블에 `defaultTextColor`(기본 글자색)라는 항목을 새로 만듭니다. 처음 값은 `#737373`(=`lab(48.496 0 0)`)입니다.
2. '설정 → 도서관' 화면에 이 색을 바꿀 수 있는 색상 선택 칸을 추가합니다.
3. 화면 전체가 이 색을 "기본 글자색"으로 쓰도록 연결합니다. 지금까지 진하게 나오던 칸은 이 기본색을 그대로 물려받게 되고, 회색으로 하드코딩되어 있던 칸들도 이 설정값을 가져다 쓰도록 바꿉니다.
4. 나중에 관리자가 '설정 → 도서관'에서 이 색을 바꾸면, 표의 모든 기본 글자색이 한 번에 같이 바뀝니다.

**참고:** 빨간색(정지 회원 상태 등)이나 초록색(방금 처리된 항목 강조) 같이 **의미가 있는 색**은 이번 변경과 관계없이 그대로 유지됩니다. 이번에 통일하는 것은 "특별한 의미 없이 그냥 기본으로 보이는 글자색"만입니다.

```

**주의:** 이 파일에는 `--sidebar-border`, `--sidebar-ring`이 두 번(밝은 화면용 `:root { }`, 어두운 화면용 `.dark { }`) 나옵니다. 반드시 **첫 번째로 나오는 것**(파일 위쪽의 `:root { }` 블록 안에 있는 것)만 바꿔주세요. `.dark { }` 블록 안의 것은 그대로 두시면 됩니다.

```

**설명:** 웹페이지가 서버에서 실제 설정값을 아직 받아오기 전(아주 짧은 순간)에도 글자색이 비어보이지 않도록, `:root`(전체 페이지 기본값)에도 같은 회색을 미리 등록해뒀습니다. 서버에서 값을 받아오면 4단계에서 만든 코드가 이 값을 실제 설정값으로 덮어씁니다.

## 8단계: '대출/반납' 화면에서 회색으로 하드코딩되어 있던 칸들 한 번에 연결하기

`frontend/src/app/admin/loans/page.tsx` 파일을 여세요.

이 파일에는 같은 모양의 코드(`px-3 py-2 text-neutral-500`)가 대출 화면과 반납 화면의 '대출 자료 목록' 표에 걸쳐 총 14번 나오고, 대출이력 표에는 `px-4 py-2.5 text-neutral-500`이 3번 나옵니다. 전부 같은 이유(회색이 코드에 직접 박혀 있음)로 나오는 것이라, 에디터의 "찾아서 모두 바꾸기(Find & Replace All)" 기능을 이용해 한 번에 바꾸는 것을 추천합니다.

### 8-1. 대출/반납 표의 회색 칸 14곳 바꾸기

**찾기:**
```
px-3 py-2 text-neutral-500
```

**바꾸기:**
```
px-3 py-2 text-[color:var(--default-text-color)]
```

에디터에서 "모두 바꾸기"를 누르면 총 14곳이 한 번에 바뀝니다. (VS Code 기준: `Ctrl+H`를 누르고 위 찾기/바꾸기 내용을 입력한 뒤, 이 파일이 열려 있는 상태에서 "모두 바꾸기" 버튼을 누르시면 됩니다.)

### 8-2. 대출이력 표의 회색 칸 3곳 바꾸기

**찾기:**
```
px-4 py-2.5 text-neutral-500
```

**바꾸기:**
```
px-4 py-2.5 text-[color:var(--default-text-color)]
```

같은 방식으로 "모두 바꾸기"를 누르면 총 3곳이 바뀝니다.

**바꾸고 나서 꼭 확인해 주세요:** 두 번의 "모두 바꾸기"를 마친 뒤, 파일에서 `text-neutral-500`이라는 글자가 더 이상 남아있지 않은지 확인해 주세요(표 상단의 회색 제목 줄(`bg-neutral-100 text-neutral-500`)은 표 데이터가 아니라 제목 디자인이므로 그대로 남아있는 게 정상입니다).

**설명:** 대출/반납 화면의 '대출 자료 목록' 표(청구기호, 권차, 사본번호, 대출일, 반납예정일, 자료상태, 갱신횟수 칸)와, 대출이력 표(대출일, 반납예정일, 반납일 칸)에 회색이 코드에 직접 박혀 있던 부분을 전부 CSS 변수로 바꿨습니다.
