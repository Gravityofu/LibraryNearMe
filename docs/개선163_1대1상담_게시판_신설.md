# 개선163. '1:1 상담' 게시판 신설 + 로그인 필요·본인 글만 열람

## 목표

'1:1 상담'이라는 새 게시판을 만듭니다.

- 위치: 홈페이지 '내 도서관' 메뉴 밑, '자료를 신청합니다' 다음 순서
- 회원만 글쓰기 가능 (비회원 불가), 댓글 기능 없음
- **로그인해야만** 목록·글 내용을 볼 수 있습니다. 로그인한 회원이어도 **본인이 쓴 글만** 목록에 보이고, 다른 회원의 글은 주소를 직접 입력해서 들어가려 해도 볼 수 없습니다. (관리자는 예외로 모두 볼 수 있습니다 — 이 부분은 이미 관리자 페이지가 별도 화면이라 자연히 그렇게 됩니다.)
- 관리자 페이지에는 이 게시판만 '새 글쓰기' 버튼이 없습니다. (질문은 항상 홈페이지에서 회원이 먼저 씁니다. 답변을 다는 기능은 다음 가이드에서 만듭니다.)

이번 가이드는 게시판을 만들고 접근 권한을 거는 것까지만 다룹니다. 질문에 답변을 다는 기능, 키워드 없는 답변, 참고자료 등록, 답변 여부 이모지 표시는 다음 가이드에서 이어서 만듭니다.

바꾸는 파일은 8개입니다.
1. `backend/src/settings/boards.service.ts`
2. `backend/src/posts/posts.service.ts`
3. `backend/src/public-boards/public-boards.controller.ts`
4. `backend/src/public-boards/public-posts.controller.ts`
5. `frontend/src/lib/site-nav.ts`
6. `frontend/src/lib/dictionary.ts`
7. `frontend/src/app/admin/layout.tsx`
8. `frontend/src/app/admin/boards/page.tsx`, `frontend/src/app/admin/boards/write/page.tsx`, `frontend/src/app/(site)/boards/[code]/page.tsx`, `frontend/src/app/(site)/boards/[code]/[id]/page.tsx`

## 3단계. 컨트롤러에서 로그인 정보를 함께 넘기기

### 3-1. `backend/src/public-boards/public-boards.controller.ts` 파일을 여세요.

전체 내용을 아래로 바꿔주세요.

```typescript
import { Controller, Get, NotFoundException, Param, Query, Req } from '@nestjs/common';
import { JwtService } from '@nestjs/jwt';
import { PrismaService } from '../prisma.service';
import { BoardsService } from '../settings/boards.service';
import { PostsService } from '../posts/posts.service';

// 로그인 없이 누구나 볼 수 있는 게시판 목록/글목록 API입니다. (홈페이지에서 씁니다)
// 다만 '1:1 상담' 게시판의 글 목록은 예외로, 로그인한 회원 본인의 글만 보입니다.
@Controller('public/boards')
export class PublicBoardsController {
  constructor(
    private prisma: PrismaService,
    private boardsService: BoardsService,
    private postsService: PostsService,
    private jwt: JwtService,
  ) {}

  // 지금은 도서관이 하나뿐인 시스템이라, 로그인 정보 없이도 첫 번째 도서관을 그대로 씁니다.
  private async getLibraryId() {
    const library = await this.prisma.library.findFirst();
    if (!library) {
      throw new NotFoundException('도서관 정보를 찾을 수 없습니다.');
    }
    return library.id;
  }

  // 로그인한 사용자면 userId를, 로그인하지 않았거나 토큰이 잘못됐으면 null을 돌려줍니다.
  private async getOptionalUserId(req: any): Promise<number | null> {
    const authHeader = req.headers['authorization'];
    const token = authHeader && authHeader.startsWith('Bearer ') ? authHeader.slice(7) : null;
    if (!token) return null;
    try {
      const payload = await this.jwt.verifyAsync(token, { secret: process.env.JWT_SECRET });
      return payload.sub;
    } catch {
      return null;
    }
  }

  // 게시판 목록
  @Get()
  async list() {
    const libraryId = await this.getLibraryId();
    return this.boardsService.list(libraryId);
  }

  // 특정 게시판의 글 목록 (예: /public/boards/notice/posts?page=1)
  @Get(':code/posts')
  async listPosts(@Req() req: any, @Param('code') code: string, @Query('page') page = '1') {
    const libraryId = await this.getLibraryId();
    const viewerUserId = await this.getOptionalUserId(req);
    return this.postsService.listPublic(libraryId, code, parseInt(page, 10) || 1, viewerUserId);
  }

  // '자료를 신청합니다' 게시판 글쓰기 화면에서 자료 종류 드롭다운에 쓸 목록을 내려줍니다.
  // (로그인하지 않은 사람도 봐야 하므로 공개 API로 둡니다.)
  @Get(':code/material-request-options')
  async materialRequestOptions(@Param('code') code: string) {
    const libraryId = await this.getLibraryId();
    const board = await this.prisma.board.findFirst({ where: { code, libraryId } });
    if (!board) {
      throw new NotFoundException('게시판을 찾을 수 없습니다.');
    }
    return this.postsService.getMaterialRequestOptions(libraryId);
  }
}
```

## 확인하기

1. 백엔드 서버를 다시 켜주세요.
2. 관리자 페이지 > 게시판 메뉴에 '1:1 상담' 탭이 새로 생겼는지 확인합니다. (기존에 게시판이 이미 세팅되어 있던 도서관이라도, 게시판 목록을 불러오는 순간 자동으로 추가됩니다.) 이 탭에는 '새 글쓰기' 버튼이 없는지 확인합니다.
3. 홈페이지 '내 도서관' 메뉴 밑에 '자료를 신청합니다' 다음 순서로 '1:1 상담'이 보이는지 확인합니다.
4. 로그아웃한 상태에서 '1:1 상담' 게시판에 들어가면, 목록 대신 "로그인이 필요한 게시판입니다" 문구와 로그인 링크가 나오는지 확인합니다.
5. 회원으로 로그인해서 '1:1 상담'에 글을 하나 써보세요. 글쓰기 화면이 정상적으로 열리고 저장되는지 확인합니다.
6. 다른 회원 계정으로 로그인해서 '1:1 상담' 목록을 보면, 방금 쓴 글이 보이지 않는지 확인합니다. (본인 글만 보여야 합니다.) 그 글의 주소(`/boards/counsel/글번호`)를 직접 입력해서 들어가 봐도 "글을 찾을 수 없습니다"로 나오는지 확인합니다.
7. 글쓴이 본인 계정으로 다시 로그인해서 그 글을 열어보면 정상적으로 보이는지, 댓글 영역이 아예 나오지 않는지 확인합니다.
8. 다른 게시판(참고서비스, 열린 게시판 등)은 이전처럼 로그인 없이도 목록·상세를 볼 수 있고 댓글도 정상적으로 나오는지 확인합니다.
