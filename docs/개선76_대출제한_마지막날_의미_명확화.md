# 개선76 - '대출 제한' 날짜의 의미를 명확하게 바꾸기 (마지막 제한일 + 실제 로직 수정)

## 목표

지금까지는 '대출 제한' 기능에서 입력한 날짜가 "그 날짜부터 대출이 다시 가능해지는 날"
(해제일)이라는 뜻으로 동작하고 있었습니다. 이번에는 이 날짜의 의미를 "그 날짜까지는
대출이 안 되고, 그다음 날부터 대출이 가능한 날"(제한 마지막 날)로 명확하게 바꿉니다.

화면에 보이는 문구뿐 아니라, 실제로 대출을 막고 풀어주는 내부 로직도 함께 바꿔서,
화면 문구와 실제 동작이 정확히 일치하도록 합니다.

- 등록 화면('회원 정보 수정' 모달): 항목 이름을 '제한 종료일' → '제한 마지막 날'로 바꿉니다.
- '대출/반납' 화면의 정지 안내 배지: '(제한 마지막 날 + 1일)부터 대출 가능'으로 바꿉니다.
- 정지 이력 목록의 칸 이름: '종료일' → '마지막 날'로 바꿉니다.
- 대출 실패 안내 모달: '대출 제한 중입니다. (대출 가능일: 2026-08-03부터)'와 같은 형태로
  바꿉니다.
- (여기부터는 화면에 보이지 않지만) 실제로 회원의 대출을 막고 풀어주는 계산 방식도,
  입력한 날짜까지는 확실히 막고 그다음 날부터 정확히 풀리도록 바꿉니다.

## 1. 백엔드 - 실제 대출 제한/해제 로직 수정하기

### 1-1. `backend/src/loan-restrictions/loan-restrictions.service.ts` 수정하기

지금까지는 "지금 이 순간(시:분:초)"과 종료일을 비교해서, 종료일 당일 자정이 지나자마자
바로 대출이 풀렸습니다. 이제부터는 "오늘 날짜"와 종료일을 비교해서, 종료일 당일 하루
전체는 계속 막혀 있고, 그다음 날이 되어야 풀리도록 바꿉니다.

**찾을 코드:**

```ts
  // 지금 이 회원에게 아직 끝나지 않은(유효한) 대출제한이 있는지 확인합니다.
  async findActiveRestriction(libraryId: number, userId: number) {
    const now = new Date();
    return this.prisma.loanRestriction.findFirst({
      where: { libraryId, userId, endDate: { gte: now } },
      orderBy: { endDate: 'desc' },
    });
  }

  // 매일 자정에 자동으로 실행됩니다: 대출제한이 끝났는데도 '정지' 상태로 남아있는 회원을 찾아 '활성'으로 되돌립니다.
  @Cron(CronExpression.EVERY_DAY_AT_MIDNIGHT)
  async releaseExpiredRestrictions() {
    const now = new Date();
    const suspendedUsers = await this.prisma.user.findMany({
      where: { status: 'SUSPENDED' },
      select: { id: true },
    });

    let releasedCount = 0;
    for (const u of suspendedUsers) {
      const stillActive = await this.prisma.loanRestriction.findFirst({
        where: { userId: u.id, endDate: { gte: now } },
      });
      if (!stillActive) {
        await this.prisma.user.update({ where: { id: u.id }, data: { status: 'ACTIVE' } });
        releasedCount++;
      }
    }

    if (releasedCount > 0) {
      this.logger.log(`대출제한이 끝난 회원 ${releasedCount}명을 '활성' 상태로 되돌렸습니다.`);
    }
  }
```

**바꿀 코드:**

```ts
  // 오늘 날짜의 자정(00:00) 시각을 구합니다.
  // "제한 마지막 날"은 그 날짜 하루 전체 동안은 계속 막혀 있어야 하므로, 시:분:초가 섞인
  // "지금 이 순간"이 아니라 "오늘 날짜(자정 기준)"으로 비교해야 정확합니다.
  private todayStart(): Date {
    const d = new Date();
    d.setUTCHours(0, 0, 0, 0);
    return d;
  }

  // 지금 이 회원에게 아직 끝나지 않은(유효한) 대출제한이 있는지 확인합니다.
  // "제한 마지막 날"이 오늘이거나 오늘보다 나중이면 아직 제한 중인 것으로 봅니다.
  async findActiveRestriction(libraryId: number, userId: number) {
    const today = this.todayStart();
    return this.prisma.loanRestriction.findFirst({
      where: { libraryId, userId, endDate: { gte: today } },
      orderBy: { endDate: 'desc' },
    });
  }

  // 매일 자정에 자동으로 실행됩니다: 대출제한이 끝났는데도 '정지' 상태로 남아있는 회원을 찾아 '활성'으로 되돌립니다.
  @Cron(CronExpression.EVERY_DAY_AT_MIDNIGHT)
  async releaseExpiredRestrictions() {
    const today = this.todayStart();
    const suspendedUsers = await this.prisma.user.findMany({
      where: { status: 'SUSPENDED' },
      select: { id: true },
    });

    let releasedCount = 0;
    for (const u of suspendedUsers) {
      const stillActive = await this.prisma.loanRestriction.findFirst({
        where: { userId: u.id, endDate: { gte: today } },
      });
      if (!stillActive) {
        await this.prisma.user.update({ where: { id: u.id }, data: { status: 'ACTIVE' } });
        releasedCount++;
      }
    }

    if (releasedCount > 0) {
      this.logger.log(`대출제한이 끝난 회원 ${releasedCount}명을 '활성' 상태로 되돌렸습니다.`);
    }
  }
```

### 1-2. `backend/src/loans/loans.service.ts` 수정하기

대출을 시도할 때 나오는 안내 문구를, "해제 예정일"(기존 종료일 그대로) 대신 "대출
가능일"(제한 마지막 날 + 1일)로 계산해서 보여주도록 바꿉니다.

**찾을 코드:**

```ts
    const activeRestriction = await this.loanRestrictionsService.findActiveRestriction(libraryId, userId);
    if (activeRestriction) {
      throw new BadRequestException(
        `대출 제한 중입니다. (해제 예정일: ${activeRestriction.endDate.toISOString().slice(0, 10)})`,
      );
    }
```

**바꿀 코드:**

```ts
    const activeRestriction = await this.loanRestrictionsService.findActiveRestriction(libraryId, userId);
    if (activeRestriction) {
      // 제한 마지막 날 다음 날부터 대출이 가능하므로, 하루를 더해서 안내합니다.
      const availableFrom = new Date(activeRestriction.endDate);
      availableFrom.setUTCDate(availableFrom.getUTCDate() + 1);
      throw new BadRequestException(
        `대출 제한 중입니다. (대출 가능일: ${availableFrom.toISOString().slice(0, 10)}부터)`,
      );
    }
```

## 3. `frontend/src/app/admin/loans/page.tsx` 수정하기

### 3-1. "지금 정지 중인지" 판단 기준을 오늘 날짜 기준으로 바꾸기

**찾을 코드:**

```ts
  // 정지 이력 중에서 "지금 아직 끝나지 않은" 것이 있으면 그것을 씁니다. (상태 값 아래에 작게 보여주기 위함)
  const activeRestriction = restrictions.find((r) => new Date(r.endDate) >= new Date()) || null;
```

**바꿀 코드:**

```ts
  // 오늘 날짜의 자정(00:00) 시각을 구합니다. 백엔드와 같은 기준으로 "지금 제한 중인지"를 판단하기 위함입니다.
  function todayStartUTC() {
    const d = new Date();
    d.setUTCHours(0, 0, 0, 0);
    return d;
  }

  // 날짜 문자열에 하루를 더한 "YYYY-MM-DD" 문자열을 돌려줍니다. (제한 마지막 날 다음 날 = 대출 가능일)
  function addOneDay(dateStr: string) {
    const d = new Date(dateStr.slice(0, 10) + "T00:00:00Z");
    d.setUTCDate(d.getUTCDate() + 1);
    return d.toISOString().slice(0, 10);
  }

  // 정지 이력 중에서 "제한 마지막 날이 오늘이거나 오늘보다 나중인" 것이 있으면 그것을 씁니다.
  const activeRestriction = restrictions.find((r) => new Date(r.endDate) >= todayStartUTC()) || null;
```

## 확인하기

1. 파일을 모두 저장합니다.
2. 백엔드/프론트엔드 서버를 재시작합니다.
3. '회원 관리'에서 회원 한 명에게 '제한 마지막 날'을 내일 날짜로 해서 정지 기록을 등록합니다.
4. '대출/반납' 메뉴에서 이 회원을 검색해서, '상태' 아래에 "(모레 날짜)부터 대출 가능,
   사유: ..." 라고 나오는지 확인합니다. (등록한 날짜 + 1일이 나와야 합니다.)
5. 이 회원 이름으로 대출을 시도해서, "대출 제한 중입니다. (대출 가능일: (모레
   날짜)부터)" 안내가 뜨는지 확인합니다.
6. '정지 이력 보기' 모달에서 칸 이름이 '마지막 날'로 바뀌었는지, 값은 등록할 때 입력한
   날짜(모레가 아니라 원래 입력한 날짜) 그대로 나오는지 확인합니다.
7. (선택) 정말로 "제한 마지막 날" 당일에는 계속 대출이 막혀 있고, 그다음 날에는 정상적으로
   대출이 되는지 실제 날짜가 지날 때 확인해 보시면 가장 확실합니다. 당장 확인이 어려우시면,
   일단 3~6번 확인으로도 충분합니다.
