# 개선164. 참고서비스·1:1상담 - 질문·답변 구조 만들기

## 목표

'참고서비스'와 '1:1 상담' 두 게시판에, 회원(또는 비회원)이 쓴 질문에 관리자가 답변을 다는 기능을 만듭니다.

- 관리자 페이지에서 글을 열면, 위에는 질문 내용(수정 가능한 입력폼), 가로줄 아래에는 관리자가 답변을 쓰는 영역이 따로 있습니다. 참고서비스는 답변에 키워드도 함께 넣고, 1:1상담은 답변에 키워드 없이 내용만 넣습니다.
- 답변을 저장할 때마다 '답변 작성 시간'이 그 순간으로 새로 기록됩니다.
- 답변이 한 번이라도 등록되면, 질문을 쓴 회원(또는 비회원)은 더 이상 그 글을 수정·삭제할 수 없습니다. 관리자는 언제든 자유롭게 수정할 수 있습니다.
- 관리자 페이지·홈페이지 글 목록 테이블 끝(관리 버튼 바로 앞)에 '답변' 칸이 생겨서, 답변이 있으면 ✅, 없으면 ❌로 보여줍니다.
- 홈페이지 글 상세 화면에서, 질문 내용 아래 답변이 등록되어 있으면 색이 다른 별도 박스로 답변이 보입니다.
- 참고자료 등록 기능은 이미 게시판 구분 없이 작동하고 있어서, 이번 가이드에서 따로 손댈 부분이 없습니다.

8. 관리자 계정으로는 답변이 등록된 뒤에도 질문·답변을 계속 자유롭게 수정할 수 있는지 확인합니다.
9. '1:1 상담' 게시판의 관리자 글쓰기 화면에서는 질문 부분에 '키워드' 칸이 아예 나오지 않는지 확인합니다. (참고서비스는 그대로 나와야 합니다.)
10. 관리자 페이지에서 새 글을 만들 때(참고서비스)는 먼저 질문을 저장한 뒤, 그 글을 다시 열어서 답변까지 작성할 수 있는지 확인합니다.
