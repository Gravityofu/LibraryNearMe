# 20단계_4. 저장 확인 모달의 '확인'을 눌러야만 새로고침되게 수정

## 🎯 목표

지난번(20단계_3)에 넣은 자동 새로고침은 "저장" 버튼을 누른 뒤 무조건 0.6초 뒤에 새로고침되는 방식이었어요. 그래서 저장 완료 모달(팝업)이 떠 있는 동안 "확인"을 누르기도 전에 화면이 바뀌어버리는 문제가 있었죠.

원인은, 저장 완료 메시지를 보여주는 `notify(...)` 함수와 새로고침이 서로 **연결되어 있지 않고 따로따로 실행**됐기 때문이에요. `notify(...)`는 그냥 모달을 띄우기만 하고, 새로고침은 `setTimeout`으로 시간이 지나면 알아서 실행되는 별개의 코드였어요.

이번엔 이 둘을 제대로 연결해서, **모달에서 "확인" 버튼을 눌렀을 때만** 새로고침이 실행되도록 고칠게요.

### 그림으로 보면

```
[전]
저장 버튼 클릭 → 모달이 뜸 ⎫
                          ⎬ 이 둘이 따로 움직임 (모달을 안 눌러도 0.6초 뒤 새로고침됨)
                0.6초 후 → 새로고침 ⎭

[후]
저장 버튼 클릭 → 모달이 뜸 → "확인" 버튼 클릭 → 그때 새로고침
```

## 1단계. 알림 모달이 "확인 눌렀을 때 할 일"도 기억하게 만들기

**파일**: `frontend/src/components/notify-provider.tsx`

전체 내용을 아래로 통째로 바꿔주세요.

```tsx
"use client";

import { createContext, useContext, useState } from "react";

type NotifyType = "success" | "error" | "info";

const NotifyContext = createContext<{
  notify: (message: string, type?: NotifyType, onClose?: () => void) => void;
} | null>(null);

export function NotifyProvider({ children }: { children: React.ReactNode }) {
  const [state, setState] = useState<{ message: string; type: NotifyType; onClose?: () => void } | null>(null);

  function notify(message: string, type: NotifyType = "info", onClose?: () => void) {
    setState({ message, type, onClose });
  }

  // 모달을 닫을 때 실행됩니다. "확인" 버튼을 누르거나 바깥을 클릭했을 때 모두 여기로 옵니다.
  function handleClose() {
    const callback = state?.onClose;
    setState(null);
    callback?.();
  }

  return (
    <NotifyContext.Provider value={{ notify }}>
      {children}

      {/* 알림이 있을 때만 화면 가운데에 팝업을 띄웁니다 */}
      {state && (
        <div
          className="fixed inset-0 z-50 flex items-center justify-center bg-black/40 p-4"
          onClick={handleClose}
        >
          <div
            className="w-full max-w-sm rounded-xl bg-white p-6 shadow-xl"
            onClick={(e) => e.stopPropagation()}
          >
            <p className="whitespace-pre-line text-center text-[15px] leading-relaxed text-neutral-800">
              {state.message}
            </p>
            <button
              onClick={handleClose}
              className="mt-5 w-full cursor-pointer rounded-lg bg-[#383838] py-2.5 text-sm font-semibold text-[#F9F6F0]"
            >
              확인
            </button>
          </div>
        </div>
      )}
    </NotifyContext.Provider>
  );
}

export function useNotify() {
  const ctx = useContext(NotifyContext);
  if (!ctx) throw new Error("NotifyProvider 안에서 사용하세요.");
  return ctx;
}
```

### 무슨 코드인가요?

- `notify(message, type, onClose)`: 이제 세 번째로 `onClose`라는 함수를 추가로 받을 수 있어요. "이 알림 모달이 닫힐 때 실행해줬으면 하는 동작"을 여기에 넣어줄 수 있어요.
- `handleClose()`: "확인" 버튼을 누르거나 모달 바깥의 어두운 부분을 클릭하면 이 함수가 실행돼요. 모달을 먼저 닫고(`setState(null)`), 그다음 아까 전달받은 `onClose` 함수를 실행해요. `onClose`를 전달하지 않았다면(`callback?.()`) 아무 일도 일어나지 않아요.

## 2단계. 디자인 탭 - 저장 성공 시, 모달의 onClose로 새로고침 넘기기

**파일**: `frontend/src/components/design-settings-form.tsx`

**찾기:**

```tsx
    if (res.ok) {
      notify(t("admin.settings.saved"), "success");
      setTimeout(() => window.location.reload(), 600);
    } else {
```

**이렇게 바꿔주세요:**

```tsx
    if (res.ok) {
      notify(t("admin.settings.saved"), "success", () => window.location.reload());
    } else {
```

```tsx
    } else {
```

### 무슨 코드인가요?

`notify(...)`의 세 번째 자리에 `() => window.location.reload()`라는 함수를 넘겨줬어요. 이 함수는 저장 즉시 실행되는 게 아니라, `NotifyProvider`에 저장돼 있다가 사용자가 모달의 "확인"(또는 바깥 클릭)을 눌러서 모달이 닫히는 바로 그 순간에 실행돼요.

## ✅ 확인하기

1. 백엔드, 프론트엔드를 실행해주세요.
2. 관리자 페이지 → 설정 → 디자인 탭에서 아무 색상이나 하나 바꾸고 "저장"을 눌러주세요.
3. "저장되었습니다" 모달이 뜨는데, 이때 **새로고침이 되지 않고 모달이 계속 떠 있는지** 확인해주세요. (몇 초를 기다려도 안 사라져야 정상이에요.)
4. 모달의 "확인" 버튼을 눌러보세요. 그 순간 페이지가 새로고침되면서 바뀐 색상이 반영되는지 확인해주세요.
5. 도서관 탭에서도 똑같이 확인해주세요.
6. (선택) 모달 바깥의 어두운 부분을 클릭해서 닫아도 마찬가지로 새로고침되는지 확인해주세요.
