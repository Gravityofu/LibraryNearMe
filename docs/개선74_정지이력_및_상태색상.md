# 개선74 - 회원의 정지(대출제한) 이력 확인 기능 + 검색 결과 상태 색상

## 목표

'대출/반납' 화면에서 회원을 검색했을 때, 다음 두 가지를 추가합니다.

1. 회원을 선택했을 때 보이는 '회원 정보' 카드에, 지금 정지 중이면 "언제까지, 어떤 사유로"
   정지된 것인지 상태 값 바로 아래에 작게 보여줍니다. (지금 바로 눈에 띄게)
2. '회원 정보' 카드 오른쪽 위에 '정지 이력 보기' 버튼을 추가해서, 누르면 그 회원의 정지
   이력 전체(과거 것 포함)를 모달로 볼 수 있게 합니다. (필요할 때만 열어보게)
3. 회원을 여러 명 검색했을 때 뜨는 '회원 검색 결과' 목록에도 '상태' 칸을 추가하고,
   '대출가능'은 파란색, '대기'는 노란색, '정지'는 주황색, '탈퇴'는 빨간색으로 색을 입혀서
   한눈에 상태를 파악할 수 있게 합니다.

> 참고: 회원을 한 명만 선택했을 때 나오는 '회원 정보' 카드의 상태 글자 색은 이미 개선61에서
> 이 색상 그대로(파란색/노란색/주황색/빨간색) 적용되어 있습니다. 이번에는 여러 명이 함께
> 나오는 '회원 검색 결과' 목록 쪽에 같은 색상 규칙을 새로 추가하는 것입니다.

### 1-2. `backend/src/loan-restrictions/loan-restrictions.controller.ts` 새로 만들기

```ts
import { Controller, Get, Param, Req, UseGuards } from '@nestjs/common';
import { LoanRestrictionsService } from './loan-restrictions.service';
import { AdminGuard } from '../auth/admin.guard';

@Controller('loan-restrictions')
export class LoanRestrictionsController {
  constructor(private loanRestrictionsService: LoanRestrictionsService) {}

  // 특정 회원의 대출제한 이력 전체를 돌려줍니다. (최신순)
  @Get(':userId')
  @UseGuards(AdminGuard)
  findHistory(@Req() req: any, @Param('userId') userId: string) {
    return this.loanRestrictionsService.findHistory(req.user.libraryId, parseInt(userId, 10));
  }
}
```

6. 정지 이력이 한 번도 없는 회원을 선택해서 같은 버튼을 눌렀을 때 "정지 이력이 없습니다."
   라는 안내가 나오는지 확인합니다.
