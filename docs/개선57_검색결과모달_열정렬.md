# 개선 57: 회원 검색 결과 목록에서 회원번호/휴대폰번호 위치 맞추기

## 목표

회원을 검색했을 때 여러 명이 검색되면 모달 안에 목록이 뜨는데, 지금은 "회원번호 · 휴대폰번호"를 하나의 글자로 붙여서 오른쪽 정렬로 보여주고 있습니다. 그래서 회원번호나 휴대폰번호의 글자 길이가 사람마다 다르면, 전체 글자 뭉치의 시작 위치가 사람마다 달라져서 세로로 나란히 비교하기 불편합니다.

이번에는 이름 / 회원번호 / 휴대폰번호를 각각 정해진 위치(칸)에 왼쪽 정렬로 나눠서 보여주도록 바꿉니다. 이렇게 하면 글자 길이가 달라도 회원번호는 항상 같은 위치에서 시작하고, 휴대폰번호도 항상 같은 위치에서 시작합니다.

## 화면 수정하기: `page.tsx`

`C:\projects\LibraryNearMe\frontend\src\app\admin\loans\page.tsx` 파일을 여세요.

아래 부분을 찾으세요.

```tsx
              <div className="flex flex-col gap-1">
                {results.map((m) => (
                  <button
                    key={m.id}
                    type="button"
                    onClick={() => selectMember(m)}
                    className="flex cursor-pointer items-center justify-between rounded-lg border border-neutral-200 px-3 py-2 text-left text-sm hover:bg-neutral-50"
                  >
                    <span className="font-medium">{m.name}</span>
                    <span className="text-neutral-500">
                      {m.memberNo ?? "-"} · {m.phone ?? "-"}
                    </span>
                  </button>
                ))}
              </div>
```

이렇게 바꿔주세요.

```tsx
              <div className="flex flex-col gap-1">
                {results.map((m) => (
                  <button
                    key={m.id}
                    type="button"
                    onClick={() => selectMember(m)}
                    className="grid cursor-pointer grid-cols-[1fr_84px_112px] items-center gap-2 rounded-lg border border-neutral-200 px-3 py-2 text-left text-sm hover:bg-neutral-50"
                  >
                    <span className="truncate font-medium">{m.name}</span>
                    <span className="truncate text-neutral-500">{m.memberNo ?? "-"}</span>
                    <span className="truncate text-neutral-500">{m.phone ?? "-"}</span>
                  </button>
                ))}
              </div>
```

무엇이 달라졌는지 설명드립니다.

- 기존에는 `justify-between`으로 "이름"과 "회원번호 · 휴대폰번호(하나로 합쳐진 글자)" 이렇게 두 덩어리만 좌우로 배치했습니다. 그래서 오른쪽 덩어리 전체의 길이가 사람마다 달라지면 시작 위치도 함께 밀렸습니다.
- 이제는 `grid grid-cols-[1fr_84px_112px]`를 사용해서, 이름 칸(남는 공간을 다 씀) / 회원번호 칸(84px 고정) / 휴대폰번호 칸(112px 고정), 이렇게 세 칸의 폭을 미리 정해두었습니다. 각 값은 자기 칸 안에서 왼쪽 정렬로 표시되기 때문에, 글자 길이가 달라도 회원번호는 항상 같은 자리에서 시작하고 휴대폰번호도 항상 같은 자리에서 시작합니다.
- `truncate`는 혹시라도 글자가 칸 폭보다 길어질 경우, 화면이 깨지지 않도록 자연스럽게 말줄임(`...`) 처리해주는 안전장치입니다.

파일을 저장하세요.
