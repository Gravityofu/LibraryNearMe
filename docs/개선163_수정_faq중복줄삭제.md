# 개선163 수정. 게시판 목록 화면 빌드 오류 수정 (faq 중복 줄 삭제)

## 목표

개선163의 9-3단계 설명이 조금 헷갈리게 되어 있어서, `{code === "faq" ? (` 부분이 중복으로 남는 실수가 생겼습니다. 이번 가이드로 그 중복된 한 줄을 지워서 빌드 오류를 없앱니다.

## 원인

개선163의 9-3단계에서 "이 줄 바로 위에 추가하고, 원래 있던 `code === "faq" ?` 부분은 지우지 마세요"라고 설명한 부분이 오해를 부르기 쉬웠습니다. 실제로는 새로 추가한 코드 블록 끝에 이미 `) : code === "faq" ? (`가 포함되어 있어서, 그 아래에 원래 있던 `{code === "faq" ? (` 줄까지 그대로 남으면 같은 조건문이 중복돼서 문법 오류가 났습니다.

## 수정 방법

`frontend/src/app/(site)/boards/[code]/page.tsx` 파일을 여세요.

아래 코드를 찾으세요. (168~170번째 줄 부근)

```typescript
      ) : code === "faq" ? (

      {code === "faq" ? (
        // '자주 묻는 질문' 게시판: 질문을 누르면 그 아래로 아코디언 형태로 답변이 펼쳐집니다.
```

아래로 바꿔주세요. (빈 줄과 중복된 `{code === "faq" ? (` 줄만 지우고, 나머지는 그대로 둡니다)

```typescript

```
