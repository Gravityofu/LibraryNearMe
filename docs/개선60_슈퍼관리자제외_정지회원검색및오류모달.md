# 개선 60: 슈퍼 관리자 검색 제외, 정지 회원은 검색 가능 + 대출 실패 시 모달 안내

## 목표

세 가지를 고칩니다.

1. 개선59에서 회원 검색의 역할(role) 제한을 완전히 없앴는데, 그러다 보니 '슈퍼 관리자(SUPER)'까지 검색되게 되었습니다. 슈퍼 관리자는 시스템 설정만 관리하는 계정이라 도서관 이용자 검색에는 나오면 안 되므로, 슈퍼 관리자만 다시 제외합니다. ('일반 이용자'와 '관리자'는 계속 검색됩니다.)
2. 지금은 상태가 '대출가능(ACTIVE)'인 회원만 검색되는데, '정지(SUSPENDED)' 상태인 회원도 검색은 되어야 합니다. (정지된 회원에게 실제로 대출을 해줄 수는 없지만, 정지 상태인지 확인하고 안내해주려면 우선 검색이 되어야 하기 때문입니다.) '대기(PENDING)'와 '탈퇴(WITHDRAWN)' 상태는 지금처럼 계속 검색되지 않습니다.
3. 정지된 회원을 선택한 상태에서 등록번호를 입력해 대출을 시도하면, 지금은 화면 한쪽 구석에 잠깐 나타났다 사라지는 작은 알림(토스트)으로만 "대출 제한 중입니다. (해제 예정일: ...)"라고 안내됩니다. 이걸 놓치기 쉬우므로, 이 경우에는 모달(화면 가운데 뜨는 알림창)로 안내가 나오도록 바꿉니다.

1. 백엔드와 프런트엔드 서버를 재시작하세요.
2. '회원' 화면에서 회원 한 명의 상태를 '정지'로 바꿔보세요. (이미 정지 상태인 회원이 있다면 그 회원을 사용해도 됩니다.)
3. '대출/반납' 화면에서 그 회원을 이름이나 회원번호로 검색했을 때, 이제 검색 결과에 나타나는지 확인하세요.
4. 그 회원을 선택하고 자료 등록번호를 입력해 대출을 시도해보세요. 화면 가운데에 모달이 뜨면서 "대출할 수 없습니다"라는 제목과 함께, 대출이 제한된 이유와 해제 예정일이 안내되는지 확인하세요.
