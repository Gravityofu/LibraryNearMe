# 개선120 - 게시판 글쓰기 화면: 제목/저자 입력란 배경색을 흰색으로 변경

## 목표

게시판 글쓰기 화면에서 '제목' 입력란과 ('자료를 신청합니다' 게시판의 경우) '저자' 입력란의 배경색을 흰색으로 명확하게 지정합니다.

---

## 1단계: '제목' 입력란 수정하기

`frontend/src/app/admin/boards/write/page.tsx` 파일을 엽니다.

찾기:
```tsx
          <input
            value={title}
            onChange={(e) => setTitle(e.target.value)}
            className="w-full rounded-lg border border-neutral-200 px-3 py-2 text-sm"
          />
```

교체:
```tsx
          <input
            value={title}
            onChange={(e) => setTitle(e.target.value)}
            className="w-full rounded-lg border border-neutral-200 bg-white px-3 py-2 text-sm"
          />
```

## 2단계: '저자' 입력란 수정하기

같은 파일 안에서 이어서 찾습니다.

찾기:
```tsx
              <input
                value={requestAuthor}
                onChange={(e) => setRequestAuthor(e.target.value)}
                className="w-full rounded-lg border border-neutral-200 px-3 py-2 text-sm"
              />
```

교체:
```tsx
              <input
                value={requestAuthor}
                onChange={(e) => setRequestAuthor(e.target.value)}
                className="w-full rounded-lg border border-neutral-200 bg-white px-3 py-2 text-sm"
              />
```

저장합니다.

---

## 확인하기

1. 프론트엔드 서버를 재시작(또는 저장 시 자동 반영)합니다.
2. 관리자 페이지에서 아무 게시판이나 '+ 글쓰기'를 열어 '제목' 입력란 배경이 흰색인지 확인합니다.
3. '자료를 신청합니다' 게시판의 글쓰기 화면에서 '저자' 입력란 배경도 흰색인지 확인합니다.
