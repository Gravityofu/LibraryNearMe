# 개선 62: 등록번호 안내 문구를 '가장 큰 번호' 기준으로 변경 + 소장처 '세부 위치' 필수 입력

## 목표

두 가지를 고칩니다.

1. 실물 자료를 새로 등록할 때 등록번호 입력 칸 옆에 "(최근 저장된 등록번호: 2)"라고 안내 문구가 나오는데, 이 값은 지금 '가장 최근에 저장(등록)된 자료'의 등록번호를 보여주는 것이라서, 예를 들어 나중에 등록번호 10번인 자료를 먼저 저장하고 그 뒤에 등록번호 2번인 자료를 저장하면 "최근 저장된 등록번호: 2"라고 나옵니다. 이걸 '등록 순서'가 아니라 '등록번호 중에서 가장 큰 숫자'를 기준으로 보여주도록 바꾸고, 문구도 "(마지막 등록번호: 10)"처럼 바꿉니다. 그리고 실제 등록번호 입력 칸에는 이 가장 큰 숫자보다 1 큰 값(예: 10이 가장 크면 11)이 자동으로 채워지도록 합니다.
2. '설정 → 목록' 화면의 '소장처' 항목은 '층'과 '세부 위치'를 함께 등록하는 방식인데, 지금은 '세부 위치'를 비워둬도 저장이 됩니다. 앞으로는 '세부 위치'에 값을 입력해야만 저장되도록 막습니다.

## 1. 백엔드 수정하기: `materials.service.ts`

`C:\projects\LibraryNearMe\backend\src\materials\materials.service.ts` 파일을 여세요.

아래 부분을 찾으세요.

```ts
  async getLatestRegistrationNo(libraryId: number) {
    const latest = await this.prisma.copy.findFirst({
      where: { libraryId },
      orderBy: { createdAt: 'desc' },
      select: { registrationNo: true },
    });
    return { registrationNo: latest?.registrationNo ?? null };
  }
```

이렇게 바꿔주세요.

```ts
  async getLatestRegistrationNo(libraryId: number) {
    // 등록번호는 1,2,3...처럼 순수 숫자입니다. '가장 최근에 저장된 것'이 아니라
    // '등록번호 중 가장 큰 숫자'를 찾아서 돌려줍니다.
    const copies = await this.prisma.copy.findMany({
      where: { libraryId },
      select: { registrationNo: true },
    });

    let maxRegistrationNo: string | null = null;
    let maxValue = -Infinity;
    for (const copy of copies) {
      const value = parseInt(copy.registrationNo, 10);
      if (!Number.isNaN(value) && value > maxValue) {
        maxValue = value;
        maxRegistrationNo = copy.registrationNo;
      }
    }

    return { registrationNo: maxRegistrationNo };
  }
```

파일을 저장하세요.

(프런트엔드는 이미 이 값을 받아서 "숫자 + 1"을 등록번호 입력 칸에 자동으로 채우고 있습니다. 그래서 백엔드가 돌려주는 값만 '가장 큰 등록번호'로 바뀌면, 입력 칸에는 자동으로 그다음 숫자(예: 10 → 11)가 채워집니다.)
