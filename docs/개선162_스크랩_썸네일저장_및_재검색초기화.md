# 개선162. 스크랩 게시판 - 썸네일 사진 저장 + 재검색 시 이전 정보 지우기

## 목표

두 가지를 추가/수정합니다.

1. '가져오기'를 누르면 기사의 첫 번째 사진 주소도 함께 읽어와서 저장합니다. (홈페이지 목록에서 썸네일로 쓸 수 있도록, 기존에 다른 게시판들이 쓰고 있는 '대표 이미지' 칸을 그대로 함께 씁니다. 이 칸은 이미 있는 칸이라 DB를 새로 손댈 필요가 없습니다.)
2. 주소를 입력해서 '가져오기'를 눌렀는데 실패하면, 화면에 남아있던 이전 가져오기 결과(제목·매체·기자·날짜·사진)를 깨끗이 지웁니다. 다만 방금 입력하신 **기사 주소(링크) 칸은 그대로 남겨둡니다.** (실패해도 원문 링크는 유효할 수 있으니까요.)

바꾸는 파일은 3개입니다.
1. `backend/src/scrap/scrap.service.ts` (사진 주소도 읽어오기)
2. `backend/src/posts/posts.service.ts` (사진 주소를 글의 대표 이미지로 저장)
3. `frontend/src/app/admin/boards/write/page.tsx` (화면)

## 확인하기

1. 백엔드 서버를 다시 켜주세요.
2. 스크랩 게시판 글쓰기 화면에서 기사 주소로 '가져오기'를 눌러보세요. 매체·기자·날짜와 함께, 기사의 대표 사진이 작은 미리보기로 나오는지 확인합니다.
3. 등록 후 홈페이지 썸네일형 목록(또는 관리자 목록)에서 이 사진이 대표 이미지로 나오는지 확인합니다.
4. '가져오기'로 성공한 뒤, 주소 칸의 내용을 존재하지 않는 주소로 바꾸고 다시 '가져오기'를 눌러보세요. 실패 알림과 함께, 이전에 채워져 있던 제목·매체·기자·날짜·사진 미리보기가 전부 지워지는지 확인합니다. 이때 주소 입력 칸에 방금 입력한 주소는 그대로 남아있는지 확인합니다.
5. 사진이 없는 기사(대표 이미지가 없는 기사)로 가져오기를 하면, 다른 정보(제목 등)는 정상적으로 채워지고 사진 미리보기만 안 나오는지 확인합니다.
6. 등록된 글을 '수정하기'로 다시 열었을 때 사진이 그대로 불러와지는지 확인합니다.
