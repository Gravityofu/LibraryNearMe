# 개선 64 (긴급 수정): '목록' 화면 문법 오류 고치기

## 목표

방금 겪으신 오류의 원인을 찾았습니다.

```
Parsing ecmascript source code failed
Expected '}', got '<eof>'
```

이 오류는 코드 어딘가에서 여는 중괄호 `{`는 있는데 그것을 닫는 중괄호 `}`가 하나 빠져 있을 때 나는 오류입니다. 확인해보니 `fetchList`라는 함수의 마지막에 닫는 중괄호(`}`) 한 개가 빠져 있었습니다. (개선63을 적용하실 때 그 부분의 닫는 중괄호가 실수로 함께 지워진 것으로 보입니다.) 이번에는 그 중괄호 하나만 다시 넣어드리겠습니다.

## 참고: 앞으로 이런 오류를 만났을 때

이런 "Expected '}', got '<eof>'" 같은 오류는 대부분 코드를 옮겨 적는 과정에서 중괄호(`{` `}`)나 괄호(`(` `)`) 중 하나가 실수로 빠지거나 중복돼서 생깁니다. 이런 오류가 뜨면, 오류 메시지에 나온 파일 이름과 줄 번호를 알려주시면 제가 원인을 찾아서 바로 수정 방법을 알려드릴 수 있습니다.
